Enumeration Block 1:
བཞི་པ་ཇི་ལྟར་རྟོགས་པའི་རིམ་པ་ལ་གསུམ། དཔེ་དགུས་མཚོན་ཚུལ་མདོར་བསྟན་པ། དེའི་དོན་སོ་སོར་དབྱེ་བ། ཕྱེས་པའི་ངོ་བོ་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 2:
གསུམ་པ་རྒྱས་པར་བཤད་པ་ལ་བཞི། ཆོས་སྐུའི་དཔེ་དོན། དེ་བཞིན་ཉིད་ཀྱི་དཔེ་དོན། རིགས་ཀྱི་དཔེ་དོན། དེ་དག་དད་པས་རྟོགས་ཚུལ་ལོ། །དང་པོ་ལ་གཉིས། ཆོས་སྐུའི་རྣམ་དབྱེ་བསྟན་པ། དེ་དག་དཔེ་དང་སྦྱར་བའོ། །
Enumeration Block 3:
གསུམ་པ་རིགས་ཀྱི་དཔེ་དོན་ལ་གསུམ། རིགས་གཉིས་དཔེར་བསྟན། དེ་ལས་སྐུ་གསུམ་ཐོབ་ཚུལ་བཤད། དེ་རྣམས་དཔེ་དང་སྦྱར་བའོ། །
Enumeration Block 4:
ལྔ་པ་སྙིང་པོ་ཉིད་བསྟན་པ་ལ་གཉིས། ངོ་བོ་དང། སྟོང་མི་སྟོང་གི་ཚུལ་ལོ། །
Enumeration Block 5:
རྩ་བའི་བཞི་པ་ཁམས་བསྟན་པའི་དགོས་པ་བསྟན་པ་ལ་གཉིས། དྲིས་ལན་གྱི་མདོར་བསྟན། དེའི་དོན་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གཉིས། དྲི་བ་དང་ལན་ནོ། །
Enumeration Block 6:
གཉིས་པ་རྒྱས་བཤད་ལ་གསུམ། བཀའ་བར་པར་ཇི་ལྟར་བསྟན་པའི་དགོངས་པ། ཐ་མར་ཁམས་བསྟན་པའི་རྒྱུ་མཚན། དེ་རྒྱས་བཤད་དོ། །དང་པོ་ལ་གཉིས། མདོར་བསྟན། རྒྱས་བཤད་དོ། །
Enumeration Block 7:
གསུམ་པ་དེ་རྒྱས་པར་བཤད་པ་ལ་གཉིས། ཉེས་པ་ལྔ་ཇི་ལྟར་འབྱུང་ཚུལ། སྐྱོན་ལྔ་སྤངས་པས་ཡོན་ཏན་ཐོབ་ཚུལ་ལོ། །
Enumeration Block 8:
སྤྱི་དོན་གཉིས་པ་རྟོགས་པ་བྱང་ཆུབ་བསྟན་པ་ལ་གསུམ། བཤད་བྱ་དོན་གྱི་ངོ་བོ་མདོར་བསྟན། འཆད་ཚུལ་སྡོམ་དུ་བསྡུ། དེ་དག་སྦྱར་ཏེ་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 9:
གསུམ་པ་ལ་བདུན། ངོ་བོ་དང་རྒྱུ་རྒྱས་པར་བཤད་པ། འབྲས་བུ། ལས། ལྡན་པ། འཇུག་པ། རྟག་པ། བསམ་གྱིས་མི་ཁྱབ་པ་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གཉིས། དག་པ་འཐོབ་ཚུལ་མདོར་བསྟན། དེའི་དོན་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 10:
གཉིས་པ་རྒྱས་བཤད་ལ་བཞི། ངོ་བོ་ཉིད་དང། ཡོན་ཏན་ལྡན་པའི་ཚུལ་དང། སྒྲིབ་པའི་དོན་དང། དེ་བྲལ་བའི་རྒྱུའོ། །
Enumeration Block 11:
གཉིས་པ་འབྲས་བུ་རྒྱས་པར་བཤད་པ་ལ་གཉིས། དྲི་མེད་དཔེ་ཡིས་མདོར་བསྟན། དེའི་རྒྱུ་མཚན་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལའང་གཉིས། ཉོན་སྒྲིབ་གྲོལ་འབྲས་དང། ཤེས་སྒྲིབ་གྲོལ་འབྲས་སོ། །
Enumeration Block 12:
གཉིས་པ་རྒྱས་བཤད་ལ་གསུམ། མཉམ་གཞག་དང་རྗེས་ཐོབ་ཀྱིས་ཐོབ་པའི་འབྲས་བུ། དུག་གསུམ་དག་པའི་འབྲས་བུ། དོན་དཔེ་དགུ་དང་སྦྱར་བའོ། །
Enumeration Block 13:
གསུམ་པ་ལས་རྒྱས་པར་བཤད་པ་ལ་གཉིས༑དོན་གཉིས་འགྲུབ་ཚུལ་མདོར་བསྟན། དེའི་དོན་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གཉིས། ངོ་བོ་ཉིད་ཀྱི་ལས་དང། ཆོས་ཐམས་ཅད་ཀྱིས་དག་པའི་ལས། །
Enumeration Block 14:
གཉིས་པ་རྒྱས་བཤད་ལ་གསུམ། དོན་གཉིས་འགྲུབ་ཚུལ་རྣམ་དབྱེ་བཅས་སྦྱར་བསྟན། རང་དོན་ཕུན་ཚོགས་དང། གཞན་དོན་ཕུན་ཚོགས་ཁྱད་པར་དུ་བཤད་པའོ། །
Enumeration Block 15:
བཞི་པ་ལྡན་པའི་དོན་ལ་གཉིས། མིང་གི་རྣམ་གྲངས་མདོར་བསྟན། དེའི་དོན་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 16:
གཉིས་པ་རྒྱས་པར་བཤད་པ་ལ་གཉིས། ཡོན་ཏན་གང་ལ་ལྡན་ཚུལ་གྱི་མདོར་བསྟན། ལྡན་པའི་ཡོན་ཏན་ངེས་པར་བྱ་བའོ། །གཉིས་པ་ལའང་གཉིས། ཟབ་པའི་རྒྱུ་མཚན་རྒྱས་པར་བཤད་པ་དང། ཕྱི་མ་རྣམས་ཀྱི་རྒྱུ་མཚན་བཤད་པའོ། །དེའི་དང་པོ་ལ་གསུམ། བསམ་མི་ཁྱབ་ཚུལ་སྤྱིར་བསྟན། ཁྱད་པར་རྒྱས་པར་བཤད། རྒྱུ་མཚན་དཔེ་དང་སྦྱར་བའོ། །
Enumeration Block 17:
གཉིས་པ་ཕྱི་མ་རྣམས་ཀྱི་རྒྱུ་མཚན་བཤད་པ་ལ་གསུམ། མི་འགྱུར་བའི་ཡོན་ཏན། སྤངས་རྟོགས་ཀྱི་ཡོན་ཏན། དག་པའི་ཡོན་ཏན་བཤད་པའོ། །
Enumeration Block 18:
ལྔ་པ་འཇུག་པའི་དོན་ལ་གཉིས། མཚན་ཉིད་ཀྱི་རྣམ་གྲངས་མདོར་བསྟན། དེའི་དོན་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་བཞི། ངོ་བོ་གང་གིས་རྟོགས་པ་དང། ཆོས་སྐུ་ལོངས་སྐུ་སྤྲུལ་སྐུའི་ཁྱད་པར་མདོར་བསྟན་པའོ། །
Enumeration Block 19:
གཉིས་པ་དོན་རྒྱས་པར་བཤད་པ་ལ་གསུམ། ཐུན་མོང་གི་དབྱེ་བ། སོ་སོའི་རྣམ་གཞགདེ་དག་གི་དོན་བསྡུ་བའོ། །
Enumeration Block 20:
གཉིས་པ་རྣམ་བཞག་ལ་གསུམ། ངོ་བོ་ཆོས་སྐུ། ལོངས་སྤྱོད་རྫོགས་སྐུ། སྤྲུལ་པ་སྐུའི་རྣམ་བཞག་གོ ། དང་པོ་ལའང་གཉིས། མཚན་ཉིད་དང་ཡོན་ཏན་མདོར་བསྟན། དེ་དག་གི་ངོ་བོ་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 21:
གཉིས་པ་རྒྱས་བཤད་ལ་གཉིས། མཚན་ཉིད་ལྔ་བཤད་པ། ཡོན་ཏན་ལྔ་བཤད་པའོ། །
Enumeration Block 22:
གཉིས་པ་ལོངས་སྐུ་བཤད་པ་ལ་གསུམ། རྣམ་བཞག་རྒྱས་པར་བཤད་པ། ཆོས་ལྔ་བསྡུས་ཏེ་བསྟན་པ། ཁྱད་པར་རྐྱེན་ལས་སྣང་ཚུལ་ལོ། །
Enumeration Block 23:
གསུམ་པ་སྤྲུལ་སྐུའི་རྣམ་བཞག་ལ་གཉིས་མཆོག་གི་སྤྲུལ་སྐུས་མཛད་པ་བཅུ་གཉིས་སྟོན་ཚུལ། དེའི་བྱེད་ལས་གདུལ་བྱ་རིམ་གྱིས་འདྲེན་ཚུལ་ལོ། །
Enumeration Block 24:
གཉིས་པ་ལ་གསུམ། ཕལ་པ་ཐེག་དམན་ལ་འཇུག་ཚུལ། ཐེག་དམན་ཐེག་ཆེན་གྱིས་སྨིན་ཚུལ། ཐེག་ཆེན་རྣམ་གྲོལ་ལ་སྦྱོར་ཚུལ་ལོ། །
Enumeration Block 25:
གསུམ་པ་དོན་བསྡུ་བ་ལ་གཉིས། རྒྱུ་མཚན་དང་སྦྱར་ཏེ་གསུམ་དུ་བསྡུ་བ། གནས་ཚུལ་དང་སྦྱར་ཏེ་གཉིས་སུ་བསྡུ་བའོ། །
Enumeration Block 26:
དྲུག་པ་རྟག་པའི་དོན་བཤད་པ་ལ་གསུམ། རྒྱུ་མཚན་མདོར་བསྟན། དེ་དོན་རྒྱས་པར་བཤད། སྤྱིའི་དོན་བསྡུ་བའོ། །
