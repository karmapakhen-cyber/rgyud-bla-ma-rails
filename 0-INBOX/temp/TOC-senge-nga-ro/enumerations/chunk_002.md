Enumeration Block 1:
གཉིས་པ་བསྟན་བཅོས་དངོས་བཤད་པ་ལ་གསུམ། ལུས་རྣམ་པར་བཞག་པ། ཡན་ལག་རྒྱས་པར་བཤད་པ། བཤད་པ་ཡོངས་སུ་རྫོགས་པའི་བྱ་བའོ། །དང་པོ་ལ་གསུམ། བསྟན་བཅོས་ཀྱི་ལུས་རྡོ་རྗེའི་གནས་བདུན་དུ་བསྟན་པ། དེའི་ཁུངས་མདོ་དང་སྦྱར་བ། གོ་རིམ་གྱིས་འབྲེལ་བསྟན་པའོ།
Enumeration Block 2:
གཉིས་པ་ཡན་ལག་རྒྱས་པར་བཤད་པ་ལ་གཉིས། ཐོབ་བྱ་དཀོན་མཆོག་གསུམ། ཐོབ་ཚུལ་གནས་བཞིའི་ཡན་ལག་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་བཞི། སྟོན་པ་སངས་རྒྱས། བསྟན་པ་དམ་ཆོས། དེ་འཛིན་དགེ་འདུན་གྱི་ངོ་བོ། སྐྱབས་གསུམ་གྱི་རྣམ་དབྱེ་བསྟན་པའོ། །དེའི་དང་པོ་ལ་གསུམ། བསྟོད་པའི་སྒོ་ནས་དངོས་པོ་བརྗོད་པ། དེའི་དོན་ཕྱེ་སྟེ་བཤད་པ། དེ་དག་སྦྱར་ཏེ་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 3:
གཉིས་པ་ཆོས་བཤད་པ་ལ་བཞི། བསྟོད་པའི་སྒོ་ནས་དངོས་པོ་བརྗོད་པ། དེའི་དོན་ཕྱེ་སྟེ་བཤད་པ། དེ་དག་འགོག་ལམ་གཉིས་སུ་བསྡུ་བ། དེ་རྣམས་སྦྱར་ཏེ་རྒྱུ་མཚན་བཤད་པའོ། །
Enumeration Block 4:
གསུམ་པ་དགེ་འདུན་བཤད་པ་ལ་གསུམ། བསྟོད་པའི་སྒོ་ནས་དངོས་པོ་བརྗོད་པ། ཡོན་ཏན་དེ་དག་གཉིས་སམ་དྲུག་ཏུ་སྒྲུབ་པ། དེ་རྣམས་སྦྱར་ཏེ་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 5:
གསུམ་པ་ལ་བཞི། ཇི་ལྟ་རྟོགས་ཚུལ། ཇི་སྙེད་རྟོགས་ཚུལ། རྣམ་དག་གི་ཁྱད་པར། དེ་སྐྱབས་གནས་ཀྱི་མཆོག་ཏུ་བཤད་པའོ། །
Enumeration Block 6:
བཞི་པ་སྐྱབས་གསུམ་གྱི་རྣམ་དབྱེ་བསྟན་པ་ལ་གསུམ། སྐྱབས་གསུམ་དུ་བཞག་པའི་དགོས་པ། མཐར་ཐུག་གི་སྐྱབས་ཡིན་མིན། དཀོན་མཆོག་གི་སྒྲ་དོན་བཤད་པའོ། །
Enumeration Block 7:
རྩ་བའི་གཉིས་པ་ཐོབ་ཚུལ་གནས་བཞིའི་ཡན་ལག་རྒྱས་པར་བཤད་པ་ལ་གཉིས། ཐུན་མོང་སྤྱིར་བསྟན་པ། བྱེ་བྲག་སོ་སོར་བཤད་པའོ། །དང་པོ་ལ་བཞི། གནས་བཞི་སངས་རྒྱས་ཀྱི་ཡུལ་བསྟན་པ། དེ་བསམ་གྱིས་མི་ཁྱབ་པ་བསྟན་པ། དེའི་རྒྱུ་མཚན། རྟོགས་ཚུལ་རྒྱུ་རྐྱེན་གྱིས་དོན་བསྡུ་བའོ།
Enumeration Block 8:
གཉིས་པ་གནས་བཞི་སོ་སོའི་ངོ་བོ་བཤད་པ་ལ་བཞི། རྟོགས་བྱ་ཁམས། རྟོགས་པ་བྱང་ཆུབ། ཡན་ལག་ཡོན་ཏན། བྱེད་པ་ཕྲིན་ལས་ཀྱི། དེའི་དང་པོ་ཁམས་ཀྱི་ངོ་བོ་བཤད་པ་ལ་བཞི། ཁམས་ཀྱི་དོན་མདོར་བསྟན་པ། དགོངས་དོན་རྒྱས་པར་བཤད་པ། ངོ་བོ་མི་འགྱུར་ཡང་དྲི་མ་སྦྱོང་བ་དཔེས་བསྟན་པ། ཁམས་བསྟན་པའི་དགོས་པའོ། །
Enumeration Block 9:
གཉིས་པ་ལ་གསུམ། སྡོམ་ཚིག་གིས་མདོར་བསྟན། དེའི་དོན་རྒྱས་པར་དབྱེ། བཤད་པའི་དོན་བསྡུ་བའོ། །
Enumeration Block 10:
གཉིས་པ་ལ་བརྒྱད། ངོ་བོ་དང་རྒྱུའི་དོན། འབྲས་བུ་དང་ལས་ཀྱི་དོན༑ ལྡན་པའི། འཇུག་པའི། གནས་སྐབས་ཀྱི། ཀུན་ཏུ་འགྲོ་བའི། མི་འགྱུར་བའི། དབྱེ་བ་མེད་པའི་ཡོན་ཏན་གྱི་དོན་ནོ། །དང་པོ་ལ་གཉིས། དག་བྱ་དག་བྱེད་ཐུན་མོང་དུ་བསྟན། སོ་སོའི་ངོ་བོ་བྱེ་བྲག་ཏུ་བཤད་པའོ། །
Enumeration Block 11:
གཉིས་པ་ལ་གཉིས། དག་བྱ་ངོ་བོའི་དོན། དག་བྱེད་རྒྱུའི་དོན་ནོ། །
Enumeration Block 12:
གཉིས་པ་ལ་གཉིས། སྤོང་བྱ་སྒྲིབ་པ་བཞི་སྤོང་ཚུལ་དང། གཉེན་པོས་རྒྱལ་སྲས་སུ་འགྱུར་ཚུལ་ལོ། །
Enumeration Block 13:
གཉིས་པ་འབྲས་བུ་དང་ལས་ཀྱི་དོན་ལ་གཉིས། འཐོབ་བྱ་འཐོབ་བྱེད་ཐུན་མོང་དུ་བསྟན་པ་དང། སོ་སོའི་ངོ་བོ་ཁྱད་པར་དུ་བཤད་པའོ། །
Enumeration Block 14:
གཉིས་པ་ལ་གཉིས། ཐོབ་བྱ་འབྲས་བུའི་དོན་དང། ཐོབ་བྱེད་ལས་ཀྱི་དོན་ནོ། །དང་པོ་ལ་གསུམ། སྤང་བྱ་ཕྱིན་ཅི་ལོག་སྤོང་ཚུལ། སྤང་པས་འབྲས་བུ་བཞི་འཐོབ་ཚུལ། ཐོབ་པས་མཐའ་གཉིས་ལས་གྲོལ་ཚུལ་ལོ།
Enumeration Block 15:
གཉིས་པ་ཐོབ་བྱེད་ལས་ཀྱི་དོན་ལ་གཉིས། རིགས་ཀྱི་ལས་ལྡོག་པའི་སྒོ་ནས་བསྟན་པ་དང། ནུས་པའི་ཁྱད་པར་རྗེས་འགྲོའི་ཚུལ་གྱིས་བསྟན་པའོ། །
Enumeration Block 16:
གསུམ་པ་ལྡན་པའི་དོན་ལ་གཉིས། རྒྱུ་འབྲས་གྱི་ཡོན་ཏན་ཐུན་མོང་དུ་བསྟན། སོ་སོའི་ངོ་བོ་ཁྱད་པར་བཤད་པའོ།
Enumeration Block 17:
གཉིས་པ་ལ་གཉིས། རྒྱུའི་ལྡན་པ་དང། འབྲས་བུའི་ལྡན་པའོ། །
Enumeration Block 18:
བཞི་པ་འཇུག་པའི་དོན་ལ་གཉིས། རྒྱུ་མཚན་མདོར་བསྟན་པ། དེ་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 19:
ལྔ་པ་གནས་སྐབས་ཀྱི་དོན་ལ་གཉིས། སྐབས་གསུམ་དུ་མིང་འདོགས་ཚུལ་དང། མིང་གསུམ་གྱིས་དོན་དྲུག་བསྡུས་ཚུལ་ལོ། །
Enumeration Block 20:
དྲུག་པ་ཀུན་ཏུ་འགྲོ་བའི་དོན་ལ་གཉིས། ངོ་བོ་བསྟན་པ་དང། རྣམ་དབྱེ་བཤད་པའོ། །
Enumeration Block 21:
བདུན་པ་མི་འགྱུར་བའི་དོན་ལ་གཉིས། ངོ་བོ་མདོར་བསྟན་པ། གནས་སྐབས་གསུམ་དུ་མི་འགྱུར་བའི་རྒྱས་བཤད་དོ། །
Enumeration Block 22:
གཉིས་པ་ལ་གསུམ། མ་དག་པའི། མ་དག་ལ་དག་པའི། ཤིན་ཏུ་དག་པའི་གནས་སྐབས་སུ་མི་འགྱུར་པའོ། །དང་པོ་ལ་བཞི། ངོ་བོ་ལ་དྲི་མས་མ་གོས་པ། ཆོས་ཅན་ལ་སྐྱེ་འཇིག་སྣང་བ་དང། ཆོས་ཉིད་ལ་འཇིགས་པས་མི་གནོད་པ་དང། རྟེན་ཅིང་འབྲེལ་བར་འབྱུང་བ་རྒྱས་བཤད་དོ། །
Enumeration Block 23:
བཞི་པ་རྟེན་ཅིང་འབྲེལ་བར་འབྱུང་བ་རྒྱས་པར་བཤད་པ་ལ་གསུམ། དཔེ་དོན་སྦྱར་ཏེ་བསྐྱེད་པའི་ཚུལ་བསྟན། ངོ་བོ་མཐའ་བྲལ་དྲི་མེད་བཤད། སྐྱེ་འཇིག་དཔེ་དོན་བསྡུ་བའོ། །དང་པོ་ལ་བཞི། དཔེ། དོན། དེ་གཉིས་སྦྱར་བ། བསྐྱེད་པའི་ཚུལ་ལོ། །
Enumeration Block 24:
གཉིས་པ་ལ་གཉིས། ངོ་བོ་སྐྱེ་འགག་མེད་པ་དང། དེ་ལ་དྲི་མས་དག་པའི་ཚུལ་ལོ། །
Enumeration Block 25:
གསུམ་པ་ལ་གཉིས། སྐྱེ་འཇིག་བྲལ་བའི་ཚུལ་བསྡུ་བ་དང། འཇིག་ཚུལ་བསྡུ་བའོ། །
