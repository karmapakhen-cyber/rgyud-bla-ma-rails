Enumeration Block 2:
རྒྱས་པར་བཤད་པ་ལ་གསུམ་སྟེ། དཔེ་གསུམ་གྱིས་ཆོས་སྐུ་དང༌། གཅིག་གིས་དེ་བཞིན་ཉིད། ལྔས་རིགས་འབྲས་བུ་དང་བཅས་པ་མཚོན་པའོ། །དང་པོ་ལ་གཉིས་ཏེ། ཆོས་སྐུའི་དབྱེ་བ་དང༌། དེ་དཔེ་གསུམ་དང་ཆོས་མཐུན་པར་སྟོན་པའོ། །
Enumeration Block 3:
ཆོས་ཀྱི་སྐུ་ནི་རྟོགས་པ་དང་བསྟན་པ་རྣམ་པ་གཉིས་སུ་ཤེས་པར་བྱ་སྟེ།
Enumeration Block 4:

Enumeration Block 5:

Enumeration Block 6:
བཞི་པ་ཁམས་དེ་རྟོགས་པར་དཀའ་བའི་ཚུལ་ལ་གསུམ་ལས། སྙིང་པོ་གང་ཟག་བཞིས་མི་རྟོགས་པའི་ཚུལ། སྙིང་པོའི་རང་བཞིན་གཏན་ལ་དབབ་པ། དེ་བསྟན་པའི་དགོས་པའོ། །
Enumeration Block 7:
གསུམ་པ་ལ་གཉིས་ཏེ། དྲི་བ་དང་། ལན་ནོ། །
Enumeration Block 8:

Enumeration Block 9:
རྒྱས་པར་བཤད་པ་ལ་གཉིས་ཏེ། ཆོས་ཐམས་ཅད་རྫུན་པ་སྤྲིན་སོགས་དང་འདྲ་བར་བསྟན་པའི་དགོངས་པ། བདེན་པ་བདེ་གཤེགས་སྙིང་པོ་གསུངས་པའི་དགོངས་པའོ། །

Enumeration Block 11:

Enumeration Block 12:
དྲི་མ་མེད་པའི་བྱང་ཆུབ་ལ་གཉིས་ཏེ། སྤྱི་དོན་དང་། གཞུང་དོན་ནོ། །དང་པོ་ལ་གཉིས་ཏེ། ཐེག་དམན་དང༌། ཐེག་ཆེན་གྱི་ལུགས་སོ། །
Enumeration Block 13:
གཉིས་པ་ལ་གསུམ་སྟེ། སངས་རྒྱས་ཐོབ་པའི་རྒྱུ། ཐོབ་པའི་ཚུལ། སངས་རྒྱས་ཀྱི་རང་བཞིན་གཏན་ལ་དབབ་པའོ། །དང་པོ་ལ་གཉིས་ཏེ། ངོ་བོ་དང་། དུས་སོ། །
Enumeration Block 14:
ཐུབ་པ་འདི་ཉིད་ལ་མཚོན་ན་གཉིས་ཏེ། དུས་ནམ་གྱི་ཚེ་སངས་རྒྱས་པ་དང་། གནས་གང་དུ་ཚུལ་ཇི་ལྟར་སངས་རྒྱས་པའོ། །
