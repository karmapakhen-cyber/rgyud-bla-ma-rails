Enumeration Block 1:
གསུམ་པ་དོན་བསྡུ་བ་ལ་གསུམ་སྟེ། དཔེ་དགུ་བསྟན་པའི་དགོས་པ། དཔེ་དོན་གྱི་ཆོས་མཐུན་བསྟན་པ། དཔེ་ལས་ཁྱད་པར་དུ་འཕགས་པའི་དོན་བསྟན་པའོ། །དང་པོ་ལ་བཞི་སྟེ། ཕྲིན་ལས་འབད་མེད་ལ་མོས་པ་བསྐྱེད་པའི་དོན་དུ་དཔེ་དགུ་བཀོད་པ། དེ་སྟོན་པའི་མདོའི་མཚན་གྱི་དགོས་པ་བསྟན་པ། དཔེ་དགུའི་དོན་བསྡུས་ཏེ་བསྟན་པ། ཕྲིན་ལས་འབད་མེད་རང་བཞིན་གྱི་རྟགས་ཀྱིས་སྒྲུབ་པའོ། །

Enumeration Block 4:
གཉིས་པ་ལ་གསུམ་སྟེ། གཟུགས་སྐུ་འཆར་ནུབ་གདུལ་བྱའི་དབང་གིས་འབྱུང་བ། ཆོས་སྐུ་ལ་སྐྱེ་འཇིག་མེད་པ། དེ་གཉིས་ཀྱི་དོན་བསྡུ་བའོ། །
Enumeration Block 5:

Enumeration Block 6:
གསུམ་པ་དེ་དག་ལ་མོས་པའི་ཕན་ཡོན་ལ་གཉིས་ཏེ། བཤད་བྱ་དགོད་པ་དང༌། དེ་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གཉིས་ཏེ། མོས་པའི་ཡུལ་དང༌། དེ་ལ་མོས་པའི་བསོད་ནམས་སོ། །
Enumeration Block 7:
གཉིས་པ་ལ་གསུམ་ཏེ། བསྟན་པ་དང༌། བཤད་པ་དང༌། དེའི་འཐད་པའོ། །
Enumeration Block 8:
གཉིས་པ་ལ་གསུམ་སྟེ། སྦྱིན་པ་དང༌། ཚུལ་ཁྲིམས་དང༌། བསྒོམས་པ་ལས་བྱུང་བའི་བསོད་ནམས་ལས་ལྷག་པའོ། །
Enumeration Block 9:
གཉིས་པ་ལ་གཉིས་ཏེ། གནས་བཞི་ལ་མོས་པ་མྱུར་དུ་སངས་རྒྱས་ཐོབ་པའི་རྒྱུར་བསྟན་པ། ཐོས་པ་བསོད་ནམས་ཚོགས་ལས་ཁྱད་པར་དུ་འཕགས་པར་བསྟན་པའོ། །

Enumeration Block 10:
གཉིས་པ་ལ་གཉིས་ཏེ། ཁྱད་པར་དུ་བྱ་བའི་ཡུལ་དང་། ཁྱད་པར་དུ་འཕགས་པའི་རྒྱུ་མཚན་ནོ། །
དང་པོ་ལ་གཉིས་ཏེ། བསོད་ནམས་མཐར་ཕྱིན་པའི་རྒྱུ་ཐོས་པར༌བསྟན༌པ་དང༌། བསོད་ནམས་ཀྱི་ཚོགས་ཀྱི་རིགས་བསྡུ་བའོ། །
Enumeration Block 11:
མཐར་ཕྱིན་པའི་དོན་ལ་གཉིས་ཏེ། དངོས་དང༌། དོན་བསྡུ་བའོ། །དང་པོ་ལ་གསུམ་སྟེ། གསུང་རབ་ཇི་ལྟར་བཤད་པའི་ཚུལ། ཆོས་སྤོང་གི་ལས་སྤང་བ། གསུང་རབ་བཤད་པའི་བསོད་ནམས་བསྔོ་བའོ། །
དང་པོ་ལ་བཞི་སྟེ། རྒྱུ་དང་དགོས་ཆེད་བསྟན་པ་དང༌། ཚུལ་ཇི་ལྟར་བཤད་པ་དང༌། བཤད་བྱ་བཀའི་མཚན་ཉིད་དང་། དེ་དང་རྗེས་སུ་མཐུན་པའི་བསྟན་བཅོས་ཀྱང་བླང་བྱར་བསྟན་པའོ། །
Enumeration Block 12:
