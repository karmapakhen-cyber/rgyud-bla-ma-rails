Enumeration Block 1:
བཞི་པ་ལ་ལྔ་སྟེ། གཞན་དོན་ལ་བསམ་པ་འབད་མེད་དུ་འཇུག་པ། སྦྱོར་བ་ཐབས་ལ་མཁས་པས་འཇུག་པ། ཡུལ་དཔག་མེད་ལ་འཇུག་པ། གཞན་དོན་ལ་སངས་རྒྱས་དང་ཁྱད་པར་མེད་པ། །རང་དོན་ལ་ཁྱད་པར་ཡོད་པའོ། །
Enumeration Block 2:
གསུམ་པ་དག་པའི་གནས་སྐབས་ན་མི་འགྱུར་བའི་དོན་ལ་གསུམ་སྟེ། རྟག་སོགས་ཀྱི་དོན་དགོད་པ། དེ་དག་སྐྱེ་མེད་སོགས་སུ་སྒྲུབ་པ། དོན་དང་ཐ་སྙད་སྦྱར་བའོ། །
Enumeration Block 3:
གཉིས་པ་ལ་གཉིས་ཏེ། རྟག་ཆོས་སོ་སོར་བསྟན་པ། སྦྱར་ཏེ་བཤད་པའོ། །
Enumeration Block 4:
གསུམ་པ་ལ་གཉིས་ལས།
Enumeration Block 5:
དབྱེར་མེད་པའི་དོན་ལ་གཉིས་ལས།
Enumeration Block 6:
རྒྱས་པར་བཤད་པ་ལ་གསུམ་སྟེ། ཁམས་དག་པའི་རྣམ་གྲགས་བཞི་བསྟན་པ། ཐམས་ཅད་སངས་རྒྱས་ཀྱི་ཆོས་སྐུ་ལ་འདུས་པ། དེས་ན་མྱང་འདས་གཅིག་ཏུ་བསྒྲུབ་པའོ། །
Enumeration Block 7:
དང་པོ་ལ་གཉིས་ལས།
Enumeration Block 8:
གཉིས་པ་ལ་བཞི་སྟེ། སྤངས་རྟོགས་ཀྱི་ཡོན་ཏན་དབྱེར་མེད་དུ་བསྟན་པ། ཐར་པའི་དོན་ངོས་བཟུང་བ། ཡོན་ཏན་འགྲུབ་པའི་རྒྱུ། ཡོན་ཏན་དབྱེར་མེད་པའི་དཔེའོ། །
Enumeration Block 9:
གསུམ་པ་དེས་སེམས་ཅན་ལ་ཁྱབ་པ་དཔེས་བསྟན་པ་ལ་གཉིས་ཏེ། དྲི་མ་དགུ་བསལ་ན་སྙིང་པོ་མངོན་དུ་འགྱུར་བ་དཔེས་མཚོན་པ་དང༌། དཔེ་རྣམས་ཀྱིས་མཚོན་པའི་དོན་སོ་སོར་བཤད་པའོ། །དང་པོ་ལ་གསུམ་སྟེ། བསྟན། བཤད། བསྡུ་བའོ། །དང་པོ་ལ་གསུམ་སྟེ། མཚམས་སྦྱར་བའི་སྒོ་ནས་མདོར་བསྟན་པ། སྙིང་པོ་དང་དྲི་མའི་དཔེ་དོན་སྦྱར་ཏེ་བཤད་པ། སོ་སོར་བཤད་པའོ། །

Enumeration Block 11:

Enumeration Block 20:
གཉིས་པ་དཔེ་དེ་རྣམས་ཀྱི་མཚོན་པའི་དོན་བཤད་པ་ལ་གཉིས་ཏེ། དྲི་མ་དང༌། སྙིང་པོའི་རང་བཞིན་ནོ། །དང་པོ་ལ་བཞི་སྟེ། དྲི་མ་དགུ་ངོས་བཟུང་བ། དེ་དག་གང་ཟག་གང་ལ་ཡོད་པར་སྟོན་པ། དཔེ་དོན་ཆོས་མཐུན་སྦྱར་བ། དོན་བསྡུ་བའོ། །
Enumeration Block 21:
སྙིང་པོའི་རང་བཞིན་ལ་གཉིས་ལས།
Enumeration Block 22:
རྒྱས་པར་བཤད་པ་ལ་གསུམ་སྟེ། དཔེ་གསུམ་གྱིས་ཆོས་སྐུ་དང༌། གཅིག་གིས་དེ་བཞིན་ཉིད། ལྔས་རིགས་འབྲས་བུ་དང་བཅས་པ་མཚོན་པའོ། །དང་པོ་ལ་གཉིས་ཏེ། ཆོས་སྐུའི་དབྱེ་བ་དང༌། དེ་དཔེ་གསུམ་དང་ཆོས་མཐུན་པར་སྟོན་པའོ། །
Enumeration Block 23:
གཉིས་པ་ལ་གཉིས་ཏེ། རིགས་ཀྱི་དཔེ་གཉིས་དང༌། དེའི་འབྲས་བུའི་དཔེ་གསུམ་དང་། ཆོས་མཐུན་པར་བསྟན་པའོ། །
