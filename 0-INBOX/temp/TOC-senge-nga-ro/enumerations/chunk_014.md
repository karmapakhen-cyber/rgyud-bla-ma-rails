Enumeration Block 1:
གཞུང་དོན་ལ་གཉིས་ཏེ། བཤད་བྱ་དགོད། དེ་བཤད་པའོ། །
Enumeration Block 2:
གཉིས་པ་ལ། ངོ་བོ་དང་རྒྱུ་སྟབས་ཅིག་ཏུ་བྱས་ཤིང་གཞན་རྣམས་སོ་སོར་བྱས་ནས་བདུན་ལས། དང་པོ་ངོ་བོ་དང་རྒྱུའི་དོན་ལ་གཉིས་ལས།
Enumeration Block 3:
རྒྱས་པར་བཤད་པ་ལ་གཉིས༌ལས།
Enumeration Block 4:
འབྲས་བུའི་དོན་ལ་གསུམ་སྟེ། སྒྲིབ་གཉིས་དང་བྲལ་བའི་འབྲས་བུ་མདོར་བསྟན། དེ་དག་མཉམ་རྗེས་གཉིས་ཀྱི་འབྲས་བུར་བསྟན། དཔེ་དང་ཆོས་མཐུན་གྱི་སྒོ་ནས་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གཉིས་ལས།
Enumeration Block 5:
གསུམ་པ་ལ་གཉིས་ལས།
Enumeration Block 6:
ལས་ཀྱི་དོན་ལ་གསུམ་སྟེ། བཤད་བྱ་དགོད་པ། སྐུ་གཉིས་རང་གཞན་གྱི་དོན་བྱེད་པ་མཉམ་རྗེས་གཉིས་ཀྱི་ལས་སུ་བསྟན་པ། སྐུ་གཉིས་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གཉིས་ཏེ། རང་དོན་དང༌། གཞན་དོན་ནོ། །
Enumeration Block 7:
གསུམ་པ་ལ་གཉིས་ཏེ། སྐུ་གཉིས་ཀྱི་དབྱེ་བ། སོ་སོའི་རང་བཞིན་ནོ། །
Enumeration Block 8:
གཉིས་པ་ལ་གཉིས་ཏེ། རྣམ་གྲོལ་དང༌། ཆོས་ཀྱི་སྐུའོ། །
Enumeration Block 9:
གཉིས་པ་ལ་གཉིས་ཏེ། སྦྱང་བྱ་ཆོས་སྐུའི་ཡོན་ཏན། སྦྱོང་བྱེད་གཟུགས་སྐུའི་ཡོན་ཏན་ནོ། །དང་པོ་ལ་གཉིས་ལས།
Enumeration Block 10:
ལྡན་པའི་དོན་ལ་གསུམ་སྟེ། ཡོན་ཏན་བཅོ་ལྔ་མདོར་བསྟན། དེ་སྐུ་གཉིས་ལ་ལྡན་པར་བསྟན། ཡོན་ཏན་བཅོ་ལྔ་སོ་སོར་བཤད་པའོ། །དང་པོ་ནི། བྱང་ཆུབ་ལ་བྲལ་བ་དང༌། རྣམ་སྨིན་གྱི་ཡོན་ཏན་གཉིས་ལྡན་པ་ལས།
Enumeration Block 11:
གསུམ་པ་ལ་དྲུག་སྟེ། ཟབ་པ། རྟག་པ། བདེ་བ། ཡེ་ཤེས་སྤངས་པ། རང་བཞིན་ནོ། །དང་པོ་ལ་གཉིས་ཏེ། སྤྱིར་བསྟན་པ། བྱེ་བྲག་ཏུ་བཤད་པའོ། །
Enumeration Block 12:
གཉིས་པ་ལ་གཉིས་ཏེ། བྱིས་པས་མི་རྟོགས་པ་དང་། སངས་རྒྱས་མ་ཡིན་པའི་འཕགས་པས་ཀྱང་རྫོགས་པར་མི་རྟོགས་པའི་ཚུལ་ལོ། །
Enumeration Block 13:
འཇུག་པའི་དོན་ལ་གཉིས་ཏེ། བཤད་བྱ་དགོད། དེ་བཤད་པའོ། །དང་པོ་ལ་གསུམ་སྟེ། ཆོས་སྐུ། ལོངས་སྐུ། སྤྲུལ་སྐུའོ། །
Enumeration Block 14:
དང་པོ་ལ་གཉིས་ལས།
Enumeration Block 15:
གཉིས་པ་ལ་བསྟན། བཤད། བསྡུ་བ་གསུམ་ལས།
Enumeration Block 16:
གཉིས་པ་ལ་གསུམ་སྟེ། ཆོས་སྐུ། ལོངས་སྐུ། སྤྲུལ་སྐུའོ། །
Enumeration Block 17:
རྒྱས་པར་བཤད་པ་ལ་གཉིས་ལས། མཚན་ཉིད། ཡོན་ཏན།
Enumeration Block 18:
ལོངས་སྐུ་ལ་གསུམ་སྟེ། ཡོན་ཏན་སོ་སོར་བཤད་པ། དོན་བསྡུ། དཔེ་དང་སྦྱར་བའོ། །
Enumeration Block 19:
སྤྲུལ་སྐུ་ལ་གསུམ་སྟེ། མཛད་པ་བཅུ་གཉིས་སྟོན་པའི་ཚུལ། གནས་སྐབས་སུ་ཐེག་པ་ཆེ་ཆུང་གི་ལམ་ལ་དགོད་པ། མཐར་ཐུག་ཐེག་ཆེན་གྱི་ལམ་ལ་དགོད་པའོ། །
Enumeration Block 20:
གསུམ་པ་ལ་གཉིས་ཏེ། སྤྱི་དོན། གཞུང་དོན་ནོ། །དང་པོ་ལ་གསུམ་སྟེ། སྡོག་བྱའི་ས་མཚམས། འཇུག་བྱའི་ས་མཚམས། འཇུག་པའི་ཚུལ་ལོ། །
Enumeration Block 21:
མི་སློབ་པ་འཇུག་ཚུལ་གཉིས་ལས།
