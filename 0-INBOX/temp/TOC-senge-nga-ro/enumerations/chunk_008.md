Enumeration Block 1:
གཉིས་པ་གཞུང་གི་དོན་ལ་གསུམ། ལུས་རྣམ་པར་བཞག་པ། ཡན་ལག་རྒྱས་པར་བཤད་པ། བརྩམས་པ་མཐར་ཕྱིན་པའི་དོན་ནོ། །དང་པོ་ལ་གསུམ། དགོས་དོན། བསྡུས་དོན། ཚིག་དོན་ནོ། །
Enumeration Block 2:
གསུམ་པ་ལ་གསུམ་སྟེ། བསྟན་བཅོས་ཀྱི་ལུས་རྡོ་རྗེའི་གནས་བདུན་དུ་བསྡུ་བ། དེ་མདོ་དང་སྦྱར་བ། དེ་དག་གི་འབྲེལ་བསྟན་པའོ། །དང་པོ་ལ་གཉིས་ཏེ། དོན་བདུན་སོ་སོར་བཤད་པ་དང༌། རྡོ་རྗེ་དང་དེའི་གནས་ཀྱི་རྒྱུ་མཚན་ནོ། །དང་པོ་ལ་གཉིས་ཏེ། དཀོན་མཆོག་གསུམ་དང༌། ཁམས་སོགས་བཞི་བཤད་པའོ། །དང་པོ་ལ་གཉིས་ཏེ། དངོས༌དང༌། ལུང༌དང་སྦྱར་བའོ། །
Enumeration Block 3:
གཉིས་པ་ལ་བཞི་སྟེ། ཁམས། བྱང་ཆུབ། ཡོན་ཏན། ཕྲིན་ལས་སོ། །
Enumeration Block 4:
ཇི་ལྟར་ཞེ༌ན༌གཉིས་ཏེ། དཀོན་མཆོག་གསུམ་དང༌། ཁམས་སོགས་བཞི་གསུངས་ཚུལ་ལོ། །དང་པོ་ལ་གསུམ་སྟེ། མདོ་དགོད། དེའི་དོན་བཤད། དཀོན་མཆོག་གི་ཡོན་ཏན་བསྟན་ཚུལ་ལོ། །
Enumeration Block 5:
གསུམ་པ་ལ་གཉིས་ཏེ། ཡོན་ཏན་གྱི་རྣམ་པར་དབྱེ་བ་དང༌། བླ་ན་མེད་པའི་ཡོན་ཏན་བསྟན་པའོ། །
Enumeration Block 6:
དེ་ལ་བཞི་ལས།
Enumeration Block 7:
གཉིས་པ་ཡན་ལག་རྒྱས་པར་བཤད་པ་ལ་གཉིས་ཏེ། འབྲས་བུ་དཀོན་མཆོག་གསུམ་དང༌། རྒྱུ་ཁམས་སོགས་བཞི་བཤད་པའོ། །དང་པོ་ལ་གཉིས་ཏེ། དངོས་དང༌། དེ་ལ་སྐྱབས་སུ་འགྲོ་ཚུལ་ལོ། །དང་པོ་ལ་བཞི། སྐྱབས་གནས་ངོས་བཟུང་བ། གནས་སྐབས་ཀྱི་སྐྱབས་གསུམ་དུ་དབྱེ་བ། མཐར་ཐུག་གི་སྐྱབས་གནས་གཅིག་ཏུ་སྒྲུབ་པ། དཀོན་མཆོག་གི་སྒྲ་དོན་བཤད་པའོ། །དང་པོ་ལ་གསུམ་སྟེ། སངས་རྒྱས། ཆོས། དགེ་འདུན་རྣམ་པར་བཞག་པའོ། །དང་པོ་ལ་གཉིས་ཏེ། བཤད་བྱ་དགོད་པ་དང༌། དེའི་རང་བཞིན་གཏན་ལ་དབབ་པའོ། །
Enumeration Block 8:
གཉིས་པ་ལ་བསྟན་བཤད་བསྡུ་བ་གསུམ་ལས།
Enumeration Block 9:
གཉིས་པ་ལ་གཉིས་ཏེ། བཤད་བྱ་དགོད་པ་དང༌། དེའི་རང་བཞིན་གཏན་ལ་དབབ་པའོ། །དང་པོ་ལ་འགོག་ལམ་གཉིས་ལས།
Enumeration Block 10:
གཉིས་པ་ལ་བསྟན་བཤད་གཉིས་ལས།
Enumeration Block 11:
གསུམ་པ་ལ་བཞི། བཤད་བྱ་དགོད་པ་དང༌། དེའི་རང་བཞིན་གཏན་ལ་དབབ་པ། རིག་པ་དང་གྲོལ་བའི་རྒྱུ་མཚན། དེས་ན་སྐྱབས་གནས་སུ་སྒྲུབ་པའོ། །
