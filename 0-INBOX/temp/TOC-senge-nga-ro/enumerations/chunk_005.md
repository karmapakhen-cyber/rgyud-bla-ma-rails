Enumeration Block 1:
གཉིས་པ་རྣམ་བཞག་ལ་གསུམ། ངོ་བོ་ཆོས་སྐུ། ལོངས་སྤྱོད་རྫོགས་སྐུ། སྤྲུལ་པ་སྐུའི་རྣམ་བཞག་གོ ། དང་པོ་ལའང་གཉིས། མཚན་ཉིད་དང་ཡོན་ཏན་མདོར་བསྟན། དེ་དག་གི་ངོ་བོ་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 2:
གཉིས་པ་རྒྱས་བཤད་ལ་གཉིས། མཚན་ཉིད་ལྔ་བཤད་པ། ཡོན་ཏན་ལྔ་བཤད་པའོ། །
Enumeration Block 3:
གཉིས་པ་ལོངས་སྐུ་བཤད་པ་ལ་གསུམ། རྣམ་བཞག་རྒྱས་པར་བཤད་པ། ཆོས་ལྔ་བསྡུས་ཏེ་བསྟན་པ། ཁྱད་པར་རྐྱེན་ལས་སྣང་ཚུལ་ལོ། །
Enumeration Block 4:
གསུམ་པ་སྤྲུལ་སྐུའི་རྣམ་བཞག་ལ་གཉིས་མཆོག་གི་སྤྲུལ་སྐུས་མཛད་པ་བཅུ་གཉིས་སྟོན་ཚུལ། དེའི་བྱེད་ལས་གདུལ་བྱ་རིམ་གྱིས་འདྲེན་ཚུལ་ལོ། །
Enumeration Block 5:
གཉིས་པ་ལ་གསུམ། ཕལ་པ་ཐེག་དམན་ལ་འཇུག་ཚུལ། ཐེག་དམན་ཐེག་ཆེན་གྱིས་སྨིན་ཚུལ། ཐེག་ཆེན་རྣམ་གྲོལ་ལ་སྦྱོར་ཚུལ་ལོ། །
Enumeration Block 6:
གསུམ་པ་དོན་བསྡུ་བ་ལ་གཉིས། རྒྱུ་མཚན་དང་སྦྱར་ཏེ་གསུམ་དུ་བསྡུ་བ། གནས་ཚུལ་དང་སྦྱར་ཏེ་གཉིས་སུ་བསྡུ་བའོ། །
Enumeration Block 7:
དྲུག་པ་རྟག་པའི་དོན་བཤད་པ་ལ་གསུམ། རྒྱུ་མཚན་མདོར་བསྟན། དེ་དོན་རྒྱས་པར་བཤད། སྤྱིའི་དོན་བསྡུ་བའོ། །
Enumeration Block 8:
གཉིས་པ་རྒྱས་བཤད་ལ་གཉིས། གཟུགས་སྐུ་རྟག་པའི་རྒྱུ་བདུན། ཆོས་སྐུ་རྟག་པའི་རྒྱུ་གསུམ་བཤད་པའོ། །
Enumeration Block 9:
བདུན་པ་བསམ་མི་ཁྱབ་པའི་དོན་བཤད་པ་ལ་གཉིས། བསམ་མི་ཁྱབ་ཚུལ་མདོར་བསྟན་པ། དེའི་རྒྱུ་མཚན་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 10:
གཉིས་པ་རྒྱས་བཤད་ལ་གསུམ། གཏན་ཚིག་བརྒྱད་རིམ་པར་བཤད། རྒྱུ་དྲུག་གི་དོན་བསྡུ། དེ་རྟོགས་པར་དཀའ་བའི་ཚུལ་བཤད་པའོ། །
Enumeration Block 11:
སྤྱི་དོན་གསུམ་པ་དེའི་ཡན་ལག་ཡོན་ཏན་བཤད་པ་ལ་གཉིས། སྐུ་གཉིས་དང་སྦྱར་ཏེ་གྲངས་ཀྱི་དབྱེ་བ་མདོར་བསྟན། ཕྱེ་བའི་ཡོན་ཏན་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལའང་གཉིས། སྐུ་དང་ཡེ་ཤེས་ཕྱེ་སྟེ་བསྟན། དེ་དག་སོ་སོར་སྦྱར་བའོ། །
Enumeration Block 12:
གཉིས་པ་ཡོན་ཏན་རྒྱས་པར་བཤད་པ་ལ་བཞི། དཔེ་དོན་སྦྱར་ཏེ་སྡོམ་གྱིས་མདོར་བསྟན། སོ་སོའི་རྣམ་བཞག་རྒྱས་པར་བཤད་པ། དེ་དག་སྟོན་པའི་ལུང་ལས་རྟོགས་ཚུལ། སླར་ཡང་དཔེ་དོན་བསྡུས་ཏེ་བསྟན་པའོ། །
Enumeration Block 13:
གཉིས་པ་ལ་གཉིས། བྲལ་འབྲས་བཤད་པ། སྨིན་འབྲས་བཤད་པའོ། །དེའི་དང་པོ་ལའང་གསུམ། སྟོབས་བཅུ། མི་འཇིགས་པ་བཞི། མ་འདྲེས་པ་བཅོ་བརྒྱད་བཤད་པའོ། །
Enumeration Block 14:
དང་པོ་ལ་གཉིས། མཚོན་བྱ་དོན་གྱི་ངོ་བོ་ངོས་བཟུང། མཚོན་བྱེད་དཔེ་ཡིས་ངེས་པར་བྱེད་པའོ། །
Enumeration Block 15:
གཉིས་པ་མི་འཇིགས་པ་བཤད་པ་ལ་གསུམ། ངོ་བོ་མདོར་བསྟན། བྱེད་ལས་རྒྱས་པར་བཤད། དཔེ་ཡིས་ངེས་པར་བྱེད་པའོ། །
Enumeration Block 16:
གསུམ་པ་མ་འདྲེས་པ་བཤད་པ་ལ་གསུམ། ངོ་བོ་མདོར་བསྟན། བྱེད་ལས་རྒྱས་བཤད་དཔེ་ཡིས་ངེས་པར་བྱ་བའོ། །
Enumeration Block 17:
གཉིས་པ་སྨིན་འབྲས་བཤད་པ་ལ་གཉིས། མཚོན་བྱ་མཚན་གྱི་དབྱེ་བ། མཚོན་བྱེད་དཔེ་ཡིས་བསྡུ་བའོ། །
Enumeration Block 18:
བཞི་པ་སླར་ཡང་དཔེ་དོན་བསྡུས་ཏེ་བསྟན་པ་ལ་གཉིས། དཔེ་དོན་མཚུངས་པའི་རྒྱུ་མཚན་སྤྱིར་བསྟནསྦྱར་ཏེ་སོ་སོར་བཤད་པའོ། །
Enumeration Block 19:
གཉིས་པ་ལ་གཉིས། བྲལ་འབྲས་དང༌། སྨིན་འབྲས་བཤད་པའོ། །དེའི་དང་པོ་ལའང་བཞི། སྟོབས། མི་འཇིགས། མ་འདྲེས་པ་རྣམས་ཕྱེ་སྟེ་དཔེ་ཡིས་མཚོན་ཚུལ། བསྡུས་ཏེ་དབྱེ་བ་མེད་ཚུལ་ལོ། །དང་པོ་སྟོབས་ལའང་གཉིས། སོ་སོར་དང། ཐུན་མོང་གི་མཚོན་ཚུལ་ལོ། །
Enumeration Block 20:
གཉིས་པ་མི་འཇིགས་པའི་མཚོན་ཚུལ་ལ་གཉིས། མདོར་བསྟན། རྒྱས་བཤད་དོ། །
Enumeration Block 21:
གཉིས་པ་སྨིན་འབྲས་བཤད་པ་ལ་གཉིས། མཚན་རྣམས་སྐུ་གཉིས་ལ་གནས་ཚུལ། གཟུགས་སྐུ་ཟླ་བའི་དཔེས་མཚོན་ཚུལ་ལོ། །
Enumeration Block 22:
སྤྱི་དོན་བཞི་པ་བྱེད་པ་ཕྲིན་ལས་བཤད་པ་ལ་གསུམ། མདོར་བསྟན་པ། རྒྱས་པར་བཤད་པ། དཔེ་དང་སྦྱར་ཏེ་ཤིན་ཏུ་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གཉིས། ལྷུན་གྲུབ་ཀྱིས་མདོར་བསྟན། རྒྱུན་མི་འཆད་པའི་མདོར་བསྟན་ནོ། །
Enumeration Block 23:
གཉིས་པ་རྒྱས་བཤད་ལ་གཉིས། ལྷུན་གྲུབ་ཀྱི་དོན་བསྡུས་ཏེ་བསྟན། རྒྱུན་མི་འཆད་པའི་དོན་ཕྱེ་སྟེ་བཤད་པའོ། །དང་པོ་ལ་གཉིས། རྣམ་པར་མི་རྟོག་པ་དང། ཡུལ་དུས་མི་འགལ་བར་འཇུག་པའོ། །
Enumeration Block 24:
རྩ་བའི་གསུམ་པ་དཔེ་དང་སྦྱར་ཏེ་ཤིན་ཏུ་རྒྱས་པར་བཤད་པ་ལ་གཉིས། དཔེའི་དབྱེ་བ་མདོར་བསྟན་པ། དཔེ་དོན་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 25:
གཉིས་པ་རྒྱས་བཤད་ལ་གསུམ། སོ་སོའི་ངོ་བོ་དཔེ་དོན་སྦྱར། དགོས་པ་བརྗོད་དེ་སྐབས་དོན་བསྡུ། སླར་ཡང་བསྡུས་ཏེ་ཁྱད་པར་བཤད་པའོ། །དང་པོ་ལ་དགུསྐུ་རྣམ་འཕྲུལ་སྟོན་པ། གསུང་གདམས་ངག་བརྗོད་པ། ཐུགས་མཁྱེན་བརྩེས་ཁྱབ་ཚུལ། སྤྲུལ་པ་སྤྲོ་བ། ཡེ་ཤེས་འཇུག་ཚུལ། ཐུགས་ཀྱི་གསང་བ། གསུང་གི་གསང་བ། སྐུའི་གསང་བ། ཐུགས་རྗེ་འཇུག་ཚུལ་བཅས་ཀྱི་དཔེ་དོན་སྦྱར་བའོ། །དེའི་དང་པོ་ལ་ལྔ། དཔེ་བསྟན་པ། དོན་བཤད་པ། དཔེ་རྒྱས་བཤད། དོན་ངོས་གཟུང་བ། བསྡུས་ཏེ་སྐྱེ་འགག་མེད་ཚུལ་བསྟན་པའོ། །དང་པོ་ལའང་གསུམ། སྣང་ཚུལ། བྱེད་ལས། དོན་དུ་གྱུར་པའོ། །
Enumeration Block 26:
གཉིས་པ་དོན་བཤད་པ་ལ་གསུམ། སྣང་ཚུལ། དོན་གཉེར། མི་རྟོག་ཀྱང་དོན་བྱེད་པའོ། །
Enumeration Block 27:
