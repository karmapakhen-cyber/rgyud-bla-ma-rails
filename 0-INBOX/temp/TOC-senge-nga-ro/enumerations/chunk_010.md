Enumeration Block 1:
གང་ཟག་གསུམ་གྱི་གནས་སྐབས་ཀྱི་དབྱེ་བ་ལ་གཉིས་ལས།
Enumeration Block 2:
ཀུན་ཏུ་འགྲོ་བའི་དོན་ལ་གཉིས་ཏེ།
Enumeration Block 3:
མི་འགྱུར་བའི་དོན་ལ་གཉིས་ལས།
Enumeration Block 4:
རྒྱས་པར་བཤད་པ་ལ་གསུམ་སྟེ། སོ་སོའི་སྐྱེ་བོ་དང༌། འཕགས་པའི་སློབ་པ་དང༌། སངས་རྒྱས་ཀྱི་གནས་སྐབས་ན་མི་འགྱུར་བའོ། །དང་པོ་ལ་བཞི་སྟེ། ཉེས་པས་མ་གོས་པ་སྐྱེ་འཇིག་དང་བྲལ་བ། དེ་དག་གི་དོན་བསྡུ་བ། ཕུང་པོ་འཇིག་པའི་རྒྱུ་བཤད་པའོ། །
Enumeration Block 5:
གཉིས་པ་ལ་གཉིས་ཏེ། བསྟན་པ་དང༌། བཤད་པའོ། །
Enumeration Block 6:
གཉིས་པ་ལ་གཉིས་ཏེ། འཇིག་པ་མེད་པ་དང་། སྐྱེ་བ་མེད་པའོ། །
Enumeration Block 7:
གཉིས་པ་ལ་གཉིས་ཏེ། དབྱིངས་ལ་འཁོར་བ་བརྟེན་ལ་འཁོར་བ་ལ་དབྱིངས་མི་བརྟེན་པ་དང༌། སེམས་ཀྱི་རང་བཞིན་སྐྱེ་འཇིག་མེད་པར་བསྟན་པའོ། །དང་པོ་ལ་གསུམ། དཔེ་དང༌། དོན་དང༌། ཆོས་མཐུན་བཤད་པའོ། །
Enumeration Block 8:
དོན༌བསྡུ༌བ༌ལ༌གཉིས་ལས།
Enumeration Block 9:
འཕགས་པ་སློབ་པའི་གནས་སྐབས་ན་མི་འགྱུར་བ་ལ་གཉིས་ལས།
Enumeration Block 10:
རྒྱས་པར་བཤད་པ་ལ་གསུམ་སྟེ། བྱང་སེམས་འཕགས་པ་ཤེས་རབ་ཀྱིས་འཁོར་བའི་སྐྱེ་སོགས་ལས་གྲོལ་བ། སྙིང་རྗེས་སྐྱེ་སོགས་སྟོན་པ། ས་མཚམས་ཀྱིས་ཕྱེ་བའི་དག་པའི་ཡོན་ཏན་ནོ། །
Enumeration Block 11:
གསུམ་པ་ལ་བཞི་སྟེ། དོན་དམ་པའི་སེམས་དང་པོ་བསྐྱེད་པ་དང༌། མ་གོས་པའི་སྤྱོད་པ་ལ་ཞུགས་པ་དང༌། རྣམ་པ་ཐམས་ཅད་དུ་ཕྱིར་མི་ལྡོག་པ་དང་། སྐྱེ་བ་གཅིག་གིས་ཐོགས་པའི་ཡོན་ཏན་ནོ། །
Enumeration Block 12:
བཞི་པ་ལ་ལྔ་སྟེ། གཞན་དོན་ལ་བསམ་པ་འབད་མེད་དུ་འཇུག་པ། སྦྱོར་བ་ཐབས་ལ་མཁས་པས་འཇུག་པ། ཡུལ་དཔག་མེད་ལ་འཇུག་པ། གཞན་དོན་ལ་སངས་རྒྱས་དང་ཁྱད་པར་མེད་པ། །རང་དོན་ལ་ཁྱད་པར་ཡོད་པའོ། །
Enumeration Block 13:
གསུམ་པ་དག་པའི་གནས་སྐབས་ན་མི་འགྱུར་བའི་དོན་ལ་གསུམ་སྟེ། རྟག་སོགས་ཀྱི་དོན་དགོད་པ། དེ་དག་སྐྱེ་མེད་སོགས་སུ་སྒྲུབ་པ། དོན་དང་ཐ་སྙད་སྦྱར་བའོ། །
Enumeration Block 14:
གཉིས་པ་ལ་གཉིས་ཏེ། རྟག་ཆོས་སོ་སོར་བསྟན་པ། སྦྱར་ཏེ་བཤད་པའོ། །
