Enumeration Block 1:
དེ་ལ་མོས་པ་བསྐྱེད་པ་ལ་གསུམ་སྟེ། བསྟན། བཤད། བསྡུ་བའོ། །
Enumeration Block 2:
རྒྱས་པར་བཤད་པ་ལ་མདོར་བསྟན་གྱི་གོ་རིམ་བཞིན་དུ་དགུ་ལས། དང་པོ་སྐུ་བརྒྱ་བྱིན་དང་འདྲ་བ་ལ་གཉིས་ཏེ། རྣམ་རྟོག་མེད་པ་དང་། སྐྱེ་འགག་མེད་པའོ། །དང་པོ་ལ་གཉིས། དཔེ་དང༌། དོན་ནོ། །དང་པོ་ལ་གསུམ་སྟེ། ས་གཞི་དག་པ་ལ་ལྷའི་གཟུགས་བརྙན་མཐོང་བ། དེས་རྐྱེན་བྱས་ནས་ལྷར་སྐྱེ་བ། གཟུགས་བརྙན་ལ་རྟོག་པ་མེད་ཀྱང་གཞན་དོན་དུ་འགྱུར་ཚུལ་ལོ། །
Enumeration Block 3:
དོན་ལ་བཞི་སྟེ། སེམས་དག་པ་ལ་སངས་རྒྱས་ཀྱི་གཟུགས་བརྙན་སྣང་བ་དང༌། དེ་སངས་རྒྱས་ཀྱི་རྒྱུར་འགྱུར་བ་དང༌། སངས་རྒྱས་ཀྱི་གཟུགས་བརྙན་ལ་རྟོག་པ་མེད་ཀྱང་གཞན་དོན་བྱེད་པ་དང༌། གཟུགས་སྐུ་མཐོང་བ་ལ་བརྟེན་ནས་ཆོས་སྐུ་མཐོང་བའི་ཚུལ་ལོ། །
Enumeration Block 4:
གཉིས་པ་སྐྱེ་འགག་མེད་པ་ལ་གཉིས་ཏེ། དཔེ་དང༌། དོན་ནོ། །དང་པོ་ལ་གཉིས་ཏེ། སྐྱེ་འགག་ཏུ་སྣང་བའི་ཚུལ། སྣང་བའི་བྱེད་པ་པོའོ། །
Enumeration Block 5:
དོན་ལ་གསུམ་སྟེ། སྐུ་གཟུགས་སྣང་བའི་བྱེད་པ། རྐྱེན་སྐུ་གཟུགས་སྣང་བའི་ཚུལ། སེམས་ཀྱི་དབང་གིས་སྐྱེ་འགག་དུ་སྣང་བའོ། །
Enumeration Block 6:
གཉིས་པ་གསུང་ལྷའི་རྔ་དང་འདྲ་བ་ལ་གསུམ་སྟེ། ཆོས་ཀྱི་རྔ་དང་མཚུངས་པ། ལྷ་རྫས་ཀྱི་སིལ་སྙན་གཞན་དང་མི་མཚུངས་པ། རྒྱུད་དག་པ་ལ་ལྟོས་པའོ། །དང་པོ་ལ་གཉིས་ཏེ། བག་མེད་པ་ལས་སྐྱོབ་པ་དང༌། འཇིགས་པ་ལས་སྐྱོབ་པའོ། །དང་པོ་ལ་གསུམ་སྟེ། དཔེ་དོན་སོ་སོར་བཤད་པ། སྒྲ་ཐོས་པའི་རྒྱུ། ཐོས་པའི་བྱེད་པའོ། །
Enumeration Block 7:
གཉིས་པ་ལ་གཉིས་ཏེ། མདོར་བསྟན་པ། རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 8:
ཐུགས་སྤྲིན་དང་འདྲ་བ་ལ་བཞི་སྟེ། གདུལ་བྱ་སྨིན་པར་བྱེད་པ། སྣོད་ཀྱི་བྱེ་བྲག་གིས་ཐ་དད་དུ་འགྱུར་བ། ཕན་གནོད་ལ་མི་རྟོག་པ། སྡུག་བསྔལ་ཞི་བར་བྱེད་པའོ། །
Enumeration Block 9:
དང་པོ་ལ་ངོ་བོ་དང༌། རྒྱུ་གཉིས་ལས།
Enumeration Block 10:
གསུམ་པ་ལ་གཉིས་ཏེ། བྱ་བ་སྣ་ཚོགས་བྱེད་པ་དང༌། དེ་དག་ལ་མི་རྟོག་པའོ། །
Enumeration Block 11:
བཞི་པ་ལ་གཉིས་ལས།
Enumeration Block 12:
རྒྱས་པར་བཤད་པ་ལ་གཉིས་ཏེ། བདེན་བཞི་རྟོགས་ཚུལ་དང༌། དཔེའི་སྒོ་ནས་བདེན་བཞི་གཏན་ལ་དབབ་པའོ། །
Enumeration Block 13:
བཞི་པ་སྤྲུལ་པ་སྟོན་པ་ཚངས་པ་དང་འདྲ་བ་ལ་གཉིས་ཏེ། སྐལ་ལྡན་ལ་སྣང་ཚུལ་དང་། སྐལ་མེད་ལ་མི་སྣང་བའི་ཚུལ་ལོ། །
Enumeration Block 14:
དང་པོ་ལ་བསྟན། བཤད། བསྡུ་བ་གསུམ་ལས།
Enumeration Block 15:
ལྔ་པ་ཡེ་ཤེས་སྤྲོ་བ་ཉི་མ་དང་འདྲ་བ་ལ་གཉིས་ཏེ། དཔེ་དོན་ཆོས་མཐུན་པ་དང་། དཔེ་ལས་ཁྱད་པར་དུ་འཕགས་པ་བསྟན་པའོ། །དང་པོ་ལ་གསུམ་སྟེ། རྟོག་མེད་དུ་འཇུག་པ་དང༌། དག་པ་ལ་སྣང་བ་རིམ་གྱིས་འཇུག་པའོ། །དང་པོ་ལ་གཉིས་ཏེ། བསྟན། བཤད། བསྡུ་བའོ། །
Enumeration Block 16:
དྲུག་པ་ཐུགས་ཀྱི་གསང་བ་ཡིད་བཞིན་གྱི་ནོར་བུ་དང་འདྲ་བ་ལ་གཉིས་ཏེ། སྐལ་ལྡན་ལ་འབད་མེད་དུ་དགོས་འདོད་སྩོལ་བ་དང༌། སྐལ་མེད་ཀྱིས་རྙེད་པར་དཀའ་བའོ། །དང་པོ་ལ་གཉིས་ཏེ། ཡུལ་མང་པོའི་བྱ་བ་སྒྲུབ་པ་དང༌། དུས་རྟག་ཏུ་སྒྲུབ་པའོ། །
Enumeration Block 17:
གསུམ་པ་དོན་བསྡུ་བ་ལ་གསུམ་སྟེ། དཔེ་དགུ་བསྟན་པའི་དགོས་པ། དཔེ་དོན་གྱི་ཆོས་མཐུན་བསྟན་པ། དཔེ་ལས་ཁྱད་པར་དུ་འཕགས་པའི་དོན་བསྟན་པའོ། །དང་པོ་ལ་བཞི་སྟེ། ཕྲིན་ལས་འབད་མེད་ལ་མོས་པ་བསྐྱེད་པའི་དོན་དུ་དཔེ་དགུ་བཀོད་པ། དེ་སྟོན་པའི་མདོའི་མཚན་གྱི་དགོས་པ་བསྟན་པ། དཔེ་དགུའི་དོན་བསྡུས་ཏེ་བསྟན་པ། ཕྲིན་ལས་འབད་མེད་རང་བཞིན་གྱི་རྟགས་ཀྱིས་སྒྲུབ་པའོ། །
Enumeration Block 18:
བཞི་པ་ལ་གསུམ་ལས།
Enumeration Block 19:
གཉིས་པ་ལ་གཉིས་ཏེ། དངོས་དང༌། རྩོད་པ་སྤང་བའོ། །
Enumeration Block 20:
གཉིས་པ་ལ་གསུམ་སྟེ། གཟུགས་སྐུ་འཆར་ནུབ་གདུལ་བྱའི་དབང་གིས་འབྱུང་བ། ཆོས་སྐུ་ལ་སྐྱེ་འཇིག་མེད་པ། དེ་གཉིས་ཀྱི་དོན་བསྡུ་བའོ། །
