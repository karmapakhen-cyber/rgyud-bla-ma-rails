Enumeration Block 1:
གཉིས་པ་ལ་གཉིས། རྩ་བ་དང༌། འགྲེལ་པའོ། །དང་པོ་ལ་གཉིས། སོ་སོ་རང་གིས་རིག་པ་དང༌། ཆགས་པ་དང་ཐོགས་པའི་སྒྲིབ་པ་ལས་གྲོལ་བའོ། །
Enumeration Block 2:
གཉིས་པ་ལ་གཉིས། སོ་སོ་རང་གིས་རིག་པ་དང༌། ཆགས་ཐོགས་ཀྱི་སྒྲིབ་པ་ལས་གྲོལ་བའོ། །
Enumeration Block 3:
གསུམ་པ་ལ་གཉིས། རྩ་བ་དང༌། འགྲེལ་པའོ། །
Enumeration Block 4:
གསུམ་པ་ལ་གཉིས། མདོར་བསྟན་པ་དང། རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 5:
གཉིས་པ་ལ་གསུམ། ཉན་ཐོས་དང་བྱང་ཆུབ་སེམས་དཔའི་དགེ་འདུན་གྱི་ཁྱད་པར་དང། ཁྱད་པར་དེ་འཐད་པའི་རྒྱུ་མཚན་དང། ལུང་དང་སྦྱར་བའོ། །
Enumeration Block 6:
གཉིས་པ་སྐྱབས་ཀྱི་དོན་བཤད་པ་ལ་གཉིས། སྤྱིའི་དོན་དང། ཡན་ལག་གི་དོན་ནོ། །དང་པོ་ལ་གསུམ། གང་ལ་སྐྱབས་སུ་འགྲོ་བའི་ཡུལ་གྱི་དབྱེ་བ་དང། དེ་ལ་སྐྱབས་སུ་སོང་བའི་ཚུལ་དང། ཤེས་བྱེད་དགོད་པའོ། །
Enumeration Block 7:
གཉིས་པ་ཡན་ལག་གི་དོན་ལ་གཉིས། ཀུན་རྫོབ་པའི་སྐྱབས་རྣམ་པར་བཞག་པ་དང། དོན་དམ་པའི་སྐྱབས་རྣམ་པར་བཞག་པའོ། །དང་པོ་ལ་གཉིས། དྲི་བ་དང། ལན་ནོ། །
Enumeration Block 8:
གཉིས་པ་ལ་གསུམ། རྩ་བ་དང། འགྲེལ་པ་དང། དོན་བསྡུ་བའོ། །
Enumeration Block 9:
གཉིས་པ་ལ་གཉིས། སངས་རྒྱས་མ་ཡིན་པའི་སྐྱབས་དོན་དམ་པའི་སྐྱབས་མ་ཡིན་པར་བསྒྲུབ་པ་དང། ཡང་དག་པར་རྫོགས་པའི་སངས་རྒྱས་ཉག་ཅིག་དོན་དམ་པའི་སྐྱབས་སུ་བསྒྲུབ་པའོ། །དང་པོ་ལ་གཉིས། རྩ་བ་དང། འགྲེལ་པའོ། །
Enumeration Block 10:
གཉིས་པ་ལ་གཉིས། ལུང་གི་ཆོས་དོན་དམ་པའི་སྐྱབས་མ་ཡིན་པར་བསྟན་པ་དང། རྟོགས་པའི་ཆོས་དོན་དམ་པའི་སྐྱབས་མ་ཡིན་པར་བསྟན་པའོ། །
Enumeration Block 11:
རྒྱས་པར་བཤད་པ་ལ་བཞི། འཇིགས་པ་དང་བཅས་པ་དང། སྐྱབས་སུ་སོང་བ་དང། ངེས་པར་འབྱུང་བ་ཚོལ་བ་དང། སློབ་པའི་ཕྱིར་བྱང་ཆུབ་ལ་ཞུགས་པའོ། །
Enumeration Block 12:
གཉིས་པ་ལ་གཉིས། རྩ་བ་དང། འགྲེལ་པའོ། །
Enumeration Block 13:
གསུམ་པ་དཀོན་མཆོག་གི་མིང་དོན་བཤད་པ་ལ་གཉིས། རྩ་བ་དང། འགྲེལ་པའོ། །
Enumeration Block 14:
གཉིས་པ་དེ་ཐོབ་བྱེད་ཀྱི་རྒྱུ་རྐྱེན་རྣམ་པར་བཞག་པ་ལ་གཉིས། སྤྱིའི་རྣམ་པར་བཞག་པ་དང། སོ་སོའི་རྣམ་པར་དབྱེ་བའོ། །དང་པོ་ལ་གསུམ། སྤྱིའི་མཚམས་སྦྱར་བ་དང། བསམ་གྱིས་མི་ཁྱབ་པའི་དོན་དང། རྒྱུ་རྐྱེན་སོ་སོར་རྣམ་པར་བཞག་པའོ། །
Enumeration Block 15:
གཉིས་པ་ལ་གཉིས། བསྟན་པ་དང། བཤད་པའོ། །
Enumeration Block 16:
གཉིས་པ་ལ་གཉིས། དྲི་བ་དང། ལན་ནོ། །
Enumeration Block 17:
གཉིས་པ་ལ་གཉིས། བསམ་གྱིས་མི་ཁྱབ་ཅིང་སངས་རྒྱས་ཉག་ཅིག་གི་ཡུལ་དུ་བསྟན་པ་དང། བསམ་གྱིས་མི་ཁྱབ་པའི་སྒྲུབ་བྱེད་དོ། །དང་པོ་ལ་གཉིས། རྩ་བ་དང། འགྲེལ་པའོ། །
Enumeration Block 18:
གཉིས་པ་ལ་གཉིས། དྲི་བ་དང་། ལན་ནོ། །
Enumeration Block 19:
གཉིས་པ་ལ་གཉིས། རྩ་བ་དང་། འགྲེལ་པའོ། །
Enumeration Block 20:
གཉིས་པ་ལ་བཞི་ཡོད་པའི་དང་པོ་དྲི་མ་དང་བཅས་པའི་དེ་བཞིན་ཉིད་རྟོགས་པར་དཀའ་བ་ལ་གཉིས། དངོས་ཀྱི་དོན་དང། ལུང་དང་སྦྱར་བའོ། །
Enumeration Block 21:
གཉིས་པ་དྲི་མ་མེད་པའི་དེ་བཞིན་ཉིད་རྟོགས་པར་དཀའ་བ་ལ་གཉིས། དངོས་ཀྱི་དོན་དང། ལུང་དང་སྦྱར་བའོ། །
Enumeration Block 22:
གསུམ་པ་དྲི་མ་མེད་པའི་ཡོན་ཏན་རྟོགས་པར་དཀའ་བ་ལ་གསུམ་གྱི་དམ་བཅའ་དང༌། སྒྲུབ་བྱེད་དང། ལུང་དང་སྦྱར་བའོ། །
Enumeration Block 23:
གསུམ་པ་ལ་གཉིས། དཔེ་དང་། དོན་ནོ། །
Enumeration Block 24:
བཞི་པ་རྒྱལ་བའི་མཛད་པ་རྟོགས་པར་དཀའ་བ་ལ་གཉིས། དངོས་ཀྱི་དོན་དང། ལུང་དང་སྦྱར་བའོ། །
Enumeration Block 25:
གསུམ་པ་རྒྱུ་རྐྱེན་སོ་སོར་རྣམ་པར་བཞག་པ་ལ་གཉིས། རྩ་བ་དང། འགྲེལ་པའོ། །
Enumeration Block 26:
གཉིས་པ་ལ་གཉིས། རྒྱུ་རྐྱེན་ངོས་བཟུང་བ་དང། རྒྱུ་རྐྱེན་དུ་འགྱུར་བའི་ཚུལ་ལོ། །
