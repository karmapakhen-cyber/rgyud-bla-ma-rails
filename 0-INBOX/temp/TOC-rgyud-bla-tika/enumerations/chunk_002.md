Enumeration Block 1:
གཉིས་པ་ཡན་ལག་རྒྱས་པར་བཤད་པ་ལ་གཉིས། རྟོགས་པར་བྱ་བའི་དོན་རྣམ་པ་བདུན་གཏན་ལ་དབབ་པ་དང༌། དེ་ལ་མོས་པའི་ཕན་ཡོན་བཤད་པའོ། །དང་པོ་ལ་གཉིས། འབྲས་བུ་དཀོན་མཆོག་གསུམ་བཤད་པ་དང་། དེ་ཐོབ་བྱེད་ཀྱི་རྒྱུ་རྐྱེན་རྣམ་པར་བཞག་པའོ། །དང་པོ་ལ་གསུམ། དངོས་ཀྱི་དོན་དང༌། སྐྱབས་ཀྱི་དོན་བཤད་པ་དང༌། དཀོན་མཆོག་གི་མིང་དོན་བཤད་པའོ། །དང་པོ་ལ་གཉིས། སྤྱིའི་མཚམས་སྦྱར་བ་དང༌། སོ་སོའི་དོན་བཤད་པའོ། །
Enumeration Block 2:
གཉིས་པ་ལ་གསུམ། སངས་རྒྱས་དཀོན་མཆོག་དང༌། ཆོས་དཀོན་མཆོག་དང༌། དགེ་འདུན་དཀོན་མཆོག་བཤད་པའོ། །དང་པོ་ལ་བཞི། མཚམས་སྦྱར་བ་དང༌། བསྟན་པ་དང༌། བཤད་པ་དང༌། བསྟན་བཤད་སྦྱར་བའོ། །
Enumeration Block 3:
གསུམ་པ་ལ་གཉིས། དྲི་བ་དང༌། ལན་ནོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གཉིས། རྩ་བ་དང་འགྲེལ་པའོ། །
Enumeration Block 5:
སངས་རྒྱས་དཀོན་མཆོག་གི་ཡོན་ཏན་གཉིས་སུ་འདུས་ཏེ། རང་དོན་ཆོས་ཀྱི་སྐུ་དང༌། གཞན་དོན་གཟུགས་ཀྱི་སྐུའོ། །དང་པོ་ལ་གཉིས། དབྱིངས་དང༌། རིག་པའོ། །
Enumeration Block 6:
བཞི་པ་ལ་གཉིས། རྩ་བ་དང༌། འགྲེལ་པའོ། །
Enumeration Block 7:
གཉིས་པ་ལ་གཉིས། སོ་སོར་བཤད་པ་དང༌། བསྡུས་ཏེ་བསྟན་པའོ། །
དང་པོ་ལ་གཉིས། དངོས་ཀྱི་དོན་དང༌། ཤེས་བྱེད་ལུང་དང་སྦྱར་བའོ། །དང་པོ་ལ་གཉིས། རང་དོན་ཆོས་སྐུ་བཤད་པ་དང༌། གཞན་དོན་གཟུགས་སྐུ་བཤད་པའོ། །དང་པོ་ལ་བཞི། རང་བཞིན་རྣམ་དག་དང༌། གློ་བུར་རྣམ་དག་དང༌། ཇི་ལྟ་བ་རིགས་པ་དང༌། འབད་རྩོལ་མེད་ཀྱང་འཕྲིན་ལས་འཇུག་པ་མི་འགལ་བའོ། །
Enumeration Block 8:
གཉིས་པ་ལ་གསུམ། ཇི་སྙེད་པ་མཁྱེན་པའི་ཡེ་ཤེས་དང༌། ཐུགས་རྗེ་དང༌། མཁྱེན་བརྩེ་གཉིས་ཀྱི་ནུས་པ་བཤད་པའོ། །
Enumeration Block 9:
གསུམ་པ་ལ་གསུམ། ནུས་པའི་དཔེ་བསྟན་པ་དང༌། སྤང་བྱ་ངོས་བཟུང་བ་དང༌། དཔེ་དོན་ཆོས་མཐུན་བཤད་པའོ། །
Enumeration Block 10:
གཉིས་པ་ལ་གཉིས། སྤྱིར་བསྟན་པ་དང༌། སོ་སོར་བཤད་པའོ། །
Enumeration Block 11:
གཉིས་པ་ལ་གཉིས། རང་དོན་ཆོས་སྐུའི་ཤེས་བྱེད་དང༌། གཞན་དོན་གཟུགས་སྐུའི་ཤེས་བྱེད་དོ། །དང་པོ་ལ་གསུམ། རང་བཞིན་རྣམ་དག་དང༌། གློ་བུར་རྣམ་དག་དང༌། ཇི་ལྟ་བ་རིག་པའི་ཤེས་བྱེད་དོ། །
Enumeration Block 12:
གཉིས་པ་ལ་གསུམ། ཇི་སྙེད་པ་མཁྱེན་པའི་ཡེ་ཤེས་དང༌། ཐུགས་རྗེ་དང༌། ནུས་པའི་ཤེས་བྱེད་དོ། །དང་པོ་ལ་གཉིས། ལུང་དགོད་པ་དང༌། དེའི་དོན་བཤད་པའོ། །
Enumeration Block 13:
གཉིས་པ་ལ་གཉིས། དོན་དྲུག་ལ་དོན་གཉིས་ཀྱི་སྐུར་དབྱེ་བ་དང༌། ཕྱི་མ་གསུམ་ལ་དབྱེ་བའོ། །
Enumeration Block 14:
གཉིས་པ་ཆོས་དཀོན་མཆོག་ལ་གཉིས། མཚམས་སྦྱར་བ་དང༌། དོན་བཤད་པའོ། །
Enumeration Block 15:
གཉིས་པ་ལ་གསུམ། བསྟན་པ་དང༌། བཤད་པ་དང་། བསྟན་བཤད་སྦྱར་བའོ། །
Enumeration Block 16:
གཉིས་པ་ལ་གཉིས། རྩ་བ་མེད་པ་དང༌། གཞི་མེད་པའོ། །
Enumeration Block 17:
གཉིས་པ་ལ་གཉིས། དྲི་བ་དང༌། ལན་ནོ། །
Enumeration Block 18:
གཉིས་པ་ལ་གཉིས། རྩ་བ་དང༌། འགྲེལ་པའོ། །
Enumeration Block 19:
གཉིས་པ་ལ་གཉིས། སྤྱིར་བཤད་པ་དང༌། སོ་སོར་བཤད་པའོ། །དང་པོ་ལ་གཉིས། རྩ་བ་དང༌། འགྲེལ་པའོ། །
Enumeration Block 20:
གཉིས་པ་ལ་གཉིས། རྩ་བ་དང༌། འགྲེལ་པའོ། །
Enumeration Block 21:
གཉིས་པ་ལ་གཉིས། འགོག་པའི་བདེན་པ་བཤད་པ་དང༌། ལམ་གྱི་བདེན་པ་བཤད་པའོ། །དང་པོ་ལ་གཉིས། རང་བཞིན་རྣམ་དག་གི་ཆ་བཤད་པ་དང༌། གློ་བུར་རྣམ་དག་བཤད་པའོ། །དང་པོ་ལ་གཉིས། སྤྱིར་བསྟན་པ་དང༌། སོ་སོར་བཤད་པའོ། །
Enumeration Block 22:
གཉིས་པ་ལ་གཉིས། དགག་བྱ་གློ་བུར་གྱི་དྲི་མ་ངོས་བཟུང་བ་དང༌། འགོག་བདེན་གྱི་རང་བཞིན་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གཉིས། དྲི་བ་དང༌། ལན་ནོ། །
Enumeration Block 23:
གཉིས་པ་ལ་གཉིས། ལུང་དང་སྦྱར་བ་དང༌། ལུང་གི་དོན་བཤད་པའོ། །
Enumeration Block 24:
གཉིས་པ་ལ་གཉིས། ངོ་བོ་ངོས་བཟུང་བ་དང༌། ལུང་དང་སྦྱར་བའོ། །དང་པོ་ལ་གཉིས། རང་བཞིན་གྱིས་སྟོང་པ་རང་བཞིན་གྱིས་འགོག་པ་དང་གློ་བུར་དྲི་མས་དབེན་པ་གློ་བུར་དྲི་བྲལ་གྱི་འགོག་བདེན་དུ་བསྟན་པ་དང༌། དངོས་པོའི་ཞིག་པ་འགོག་བདེན་ཡིན་པ་དགག་པའོ། །
Enumeration Block 25:
གཉིས་པ་ལ་གཉིས། དོན་སྔ་མ་ལུང་དང་སྦྱར་ནས་འཁོར་བ་ལྡོག་པའི་རིམ་པ་ངོས་བཟུང་བ་དང༌། དོན་ཕྱི་མ་ལུང་དང་སྦྱར་ནས་དྲི་མ་དང་བཅས་པའི་དེ་བཞིན་ཉིད་དེ་བཞིན་གཤེགས་པའི་སྙིང་པོར་བསྟན་པའོ། །
Enumeration Block 26:
གཉིས་པ་ལ་གསུམ། མདོར་བསྟན་པ་དང༌། རྒྱས་པར་བཤད་པ་དང༌། ལུང་དང་སྦྱར་བའོ། །
Enumeration Block 27:
གཉིས་པ་ལ་གསུམ། ཉི་མ་དང་ཆོས་མཐུན་སྦྱར་བ་དང༌། སྤང་བྱ་ངོས་བཟུང་བ་དང༌། དེ་འཇོམས་བྱེད་གཉེན་པོ་ངོས་བཟུང་བའོ། །
Enumeration Block 28:
གཉིས་པ་ལ་གཉིས། འཁོར་བར་འཇུག་པའི་རིམ་པ་བསྟན་པ་དང༌། འཁོར་བའི་རྒྱུའི་གཙོ་བོ་ངོས་བཟུང་བའོ། །
Enumeration Block 29:
གསུམ་པ་ལ་གསུམ། བདེན་སྟོང་སྤྲོས་བྲལ་དང་པོར་རྟོགས་པའི་སྐབས་དང༌། བརྟགས་པ་ལས་མངོན་སུམ་དུ་གྱུར་པའི་དོན་དང༌། བསལ་བཞག་མེད་པའི་གནས་ལུགས་མངོན་སུམ་དུ་རྟོགས་པའི་ཡེ་ཤེས་གེགས་ཀྱི་གཉེན་པོར་བསྟན་པའོ། །
Enumeration Block 30:
གསུམ་པ་དགེ་འདུན་དཀོན་མཆོག་བཤད་པ་ལ་གསུམ། མཚམས་སྦྱར་བ་དང༌། དངོས་ཀྱི་དོན་དང༌། ཉན་ཐོས་ཀྱི་དགེ་འདུན་དཀོན་མཆོག་འདིར་དངོས་སུ་མ་སྨོས་པའི་རྒྱུ་མཚན་ནོ། །
Enumeration Block 31:
གཉིས་པ་ལ་གསུམ། བསྟན་པ་དང༌། བཤད་པ་དང༌། བསྟན་བཤད་སྦྱར་ཏེ་བཤད་པའོ། །
Enumeration Block 32:

Enumeration Block 33:
གཉིས་པ་ལ་གཉིས། རྩ་བ་དང༌། འགྲེལ་པའོ། །
Enumeration Block 34:
གསུམ་པ་ལ་གསུམ། ཇི་ལྟ་བ་དང་ཇི་སྙེད་པ་གཟིགས་པ་ཡོན་ཏན་དང༌། སོ་སོ་རང་གི་རིག་པ་དང་ཆགས་ཐོགས་ཀྱི་སྒྲིབ་པ་ལས་གྲོལ་བའི་ཡོན་ཏན་དང༌། དམན་པའི་སྒྲིབ་པ་ལས་གྲོལ་བའི་ཡོན་ཏན་ནོ། །དང་པོ་ལ་གཉིས། ཇི་ལྟ་བ་རིག་པ་དང༌། ཇི་སྙེད་པ་རིག་པའོ། །དང་པོ་ལ་གཉིས། རྩ་བ་དང་། འགྲེལ་པའོ། །
Enumeration Block 35:
གཉིས་པ་ལ་གསུམ། ཇི་ལྟ་བ་རིག་པའི་ངོ་བོ་དང༌། རྒྱུ་དང༌། སྒྲུབ་བྱེད་དོ། །
Enumeration Block 36:

Enumeration Block 37:

Enumeration Block 38:
གཉིས་པ་ལ་གཉིས། རྩ་བ་དང༌། འགྲེལ་པའོ། །དང་པོ་ལ་གཉིས། སོ་སོ་རང་གིས་རིག་པ་དང༌། ཆགས་པ་དང་ཐོགས་པའི་སྒྲིབ་པ་ལས་གྲོལ་བའོ། །
Enumeration Block 39:
གཉིས་པ་ལ་གཉིས། སོ་སོ་རང་གིས་རིག་པ་དང༌། ཆགས་ཐོགས་ཀྱི་སྒྲིབ་པ་ལས་གྲོལ་བའོ། །
Enumeration Block 40:
གསུམ་པ་ལ་གཉིས། རྩ་བ་དང༌། འགྲེལ་པའོ། །
Enumeration Block 41:
གསུམ་པ་ལ་གཉིས། མདོར་བསྟན་པ་དང། རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 42:

Enumeration Block 43:
