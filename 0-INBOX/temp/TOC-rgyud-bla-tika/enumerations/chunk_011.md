Enumeration Block 1:
གཉིས་པ་ཤེས་བྱེད་ལུང་དང་སྦྱར་བ་ལ་གསུམ། བཤད་ཟིན་གྱི་མཚམས་སྦྱར་བ་དང༌། རྩ་བ་དང༌། འགྲེལ་པའོ། །
Enumeration Block 2:
གསུམ་པ་དཔེས་བསྟན་པའི་དོན་བསྡུ་བ་ལ་གཉིས། མཚམས་སྦྱར་བ་དང༌། རྩ་བའོ། །
Enumeration Block 3:
གཉིས་པ་ལ་གཉིས། མདོར་བསྟན་པ་དང༌། ཆོས་མཐུན་སོ་སོར་བཤད་པའོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གཉིས། བྲལ་བའི་ཡོན་ཏན་གྱི་ཆོས་མཐུན་བཤད་པ་དང༌། རྣམ་སྨིན་གྱི་ཡོན་ཏན་གྱི་ཆོས་མཐུན་བཤད་པའོ། །དང་པོ་ལ་གཉིས། རྒྱས་པར་བཤད་པ་དང༌། དོན་བསྡུ་བའོ། །དང་པོ་ལ་གསུམ། སྟོབས་ཀྱི་ཆོས་མཐུན་དང༌། མི་འཇིགས་པའི་ཆོས་མཐུན་དང་། མ་འདྲེས་པའི་ཆོས་མཐུན་ནོ། །དང་པོ་ལ་གཉིས། སྟོབས་ཀྱི་ནུས་པའི་ཁྱད་པར་དང༌། མི་ཕྱེད་པའི་དོན་བཤད་པའོ། །
Enumeration Block 5:
གཉིས་པ་ལ་གཉིས། བསྟན་པ་དང༌། བཤད་པའོ། །
Enumeration Block 6:
གཉིས་པ་ལ་གཉིས། བསྟན་པ་དང༌། བཤད་པའོ། །
Enumeration Block 7:
གཉིས་པ་ལ་གཉིས། ཡོན་ཏན་རྟེན་དང་བཅས་པ་དང༌། དཔེ་དོན་ཆོས་མཐུན་བཤད་པའོ། །
Enumeration Block 8:
གསུམ་པ་ཡོན་ཏན་ལ་བརྟེན་པའི་འཕྲིན་ལས་བཤད་པ་ལ་གསུམ། མཚམས་སྦྱར་བ་དང༌། དོན་བཤད་པ་དང༌། ལེའུའི་མཚན་བསྟན་པའོ། །དང་པོ་ལ་གཉིས། བཤད་ཟིན་གྱི་མཚམས་སྦྱར་དང༌། འཆད་འགྱུར་གྱི་མཚམས་སྦྱར་རོ། །
Enumeration Block 9:
གཉིས་པ་ལ་གསུམ། མདོར་བསྟན་པ་དང༌། རྒྱས་པར་བཤད་པ་དང༌། འཕྲིན་ལས་ཚུལ་དེ་ལྟར་འཇུག་པ་དཔེས་བསྒྲུབ་པའོ། །དང་པོ་ལ་གཉིས། ལྷུན་གྱིས་གྲུབ་པའི་དོན་བསྟན་པ་དང༌། རྒྱུན་མི་འཆད་པའི་དོན་བསྟན་པའོ། །
Enumeration Block 10:
གཉིས་པ་ནི། བསྡུས་དོན་དང༌། ཚིག་དོན་གཉིས་ཀྱིས་ཤེས་པར་བྱའོ། །དང་པོ་ལ་གཉིས། རྒྱས་པར་བཤད་པ་དང༌། སྐབས་དོན་བསྡུ་བའོ། །དང་པོ་ལ་གསུམ། དཔེ་དྲུག་དང༌། དོན་དྲུག་དང༌། དཔེ་དོན་ཆོས་མཐུན་དྲུག་གོ །
Enumeration Block 11:
གཉིས་པ་ལ་གཉིས། མཚམས་སྦྱར་བ་དང༌། དོན་བཤད་པའོ། །
Enumeration Block 12:
གཉིས་པ་ལ་གཉིས། འཕྲིན་ལས་ལྷུན་གྱིས་གྲུབ་པ་བཤད་པ་དང༌། རྒྱུན་མི་འཆད་པ་བཤད་པའོ། །དང་པོ་ལ་གཉིས། སྤྱིར་བཤད་པ་དང༌། སོ་སོར་བཤད་པའོ། །
Enumeration Block 13:
གཉིས་པ་ལ་གསུམ། བསྟན་པ་དང༌། བཤད་པ་དང༌། སྤྱིའི་དོན་བསྡུ་བའོ། །
Enumeration Block 14:
གཉིས་པ་ལ་གསུམ། དོན་དྲུག་ངོས་བཟུང་བ་དང༌། དཔེ་དོན་དྲུག་དགོད་པ་དང༌། དཔེ་དོན་ཆོས་མཐུན་བཤད་པའོ། །
Enumeration Block 15:
གསུམ་པ་འཕྲིན་ལས་ཚུལ་དེ་ལྟར་འཇུག་པ་དཔེས་བསྒྲུབ་པ་ལ་གཉིས། མཚམས་སྦྱར་བ་དང༌། དོན་བཤད་པའོ། །
Enumeration Block 16:
གཉིས་པ་ལ་གསུམ། མདོར་བསྟན་པ་དང༌། རྒྱས་པར་བཤད་པ་དང༌། དཔེའི་གོ་རིམས་བཤད་པའོ། །དང་པོ་ལ་གཉིས། རྩ་བ་དང༌། རྒྱས་པར་བཤད་པ་འོག་མ་ལ་ཁ་འཕངས་ཏེ་བསྟན་པའོ། །
Enumeration Block 17:
གཉིས་པ་ལ་གསུམ། དཔེ་དོན་རྒྱས་པར་དབྱེ་བ་དང༌། དཔེ་རྣམས་ཀྱིས་བསྡུས་པའི་དོན་གྱིས་དཔེའི་དགོས་པ་བཤད་པ་དང༌། དཔེས་མཚོན་པར་བྱ་བའི་དོན་བསྡུས་ཏེ་བཤད་པའོ། །
དང་པོ་ལ་བཞི། སྐུ་གསུང་ཐུགས་ཀྱིས་ངོ་བོ་གསུམ་དཔེས་མཚོན་ཏེ་བསྟན་པ་དང༌། འཕྲིན་ལས་གསུམ་དཔེས་མཚོན་ཏེ་བསྟན་པ་དང༌། གསང་བའི་གནས་གསུམ་དཔེས་མཚོན་ཏེ་བསྟན་པ་དང༌། དེ་ཐམས་ཅད་ཀྱི་རྟེན་དཔེས་མཚོན་ཏེ་བསྟན་པའོ། །དང་པོ་ལ་གསུམ། སྐུ་བརྒྱ་བྱིན་གྱིས་གཟུགས་ཀྱི་དཔེས་བསྟན་པ་དང༌། གསུང་ལྷའི་རྔའི་དཔེས་བསྟན་པ་དང༌། ཐུགས་སྤྲིན་གྱི་དཔེས་བསྟན་པའོ། །དང་པོ་ལ་གཉིས། རྣམ་རྟོག་མེད་པ་དཔེས་བསྟན་པ་དང༌། ཕྱིན་ཅི་ལོག་གི་སྐྱེ་འགག་མེད་པ་དཔེས་བསྟན་པའོ། །དང་པོ་ལ་གཉིས། དཔེ་དང༌། དོན་ནོ། །
Enumeration Block 18:
བརྒྱ་བྱིན་གྱི་དཔེ་ལ་བཞི། ས་གཞི་དག་པ་ལ་གཟུགས་སྣང་བའི་ཚུལ་དང༌། སྣང་བ་དེའི་རྐྱེན་གྱིས་མི་རྣམས་དགེ་བ་ལ་འཇུག་པ་དང༌། གནས་ཚོད་ཇི་ལྟ་བ་བཞིན་མི་ཤེས་ཀྱང་ལྷར་སྐྱེ་བ་དང༌། སྣང་བ་དེ་རྟོག་པ་མེད་ཀྱང་ཕན་པའི་རྒྱུ་བྱེད་པ་མི་འགལ་བའོ། །
Enumeration Block 19:
གཉིས་པ་ལ་བཞི། སེམས་དག་པའི་དབང་གིས་རྒྱལ་བའི་སྐུ་སྣང་བ་དང༌། སྣང་བ་དེས་གནས་སྐབས་དང་མཐར་ཐུག་གི་དོན་བྱེད་པ་དང༌། སྣང་བ་དེ་ལ་རྟོག་པ་མེད་ཀྱང་དོན་བྱེད་པ་མི་འགལ་བ་དང༌། གདུལ་བྱ་རྣམས་ཀྱིས་སྣང་བ་དེའི་གནས་ཚོད་ཇི་ལྟ་བ་བཞིན་མ་ཤེས་ཀྱང་འབྲས་བུ་ཆེན་པོར་འགྱུར་བའོ། །
Enumeration Block 20:
བཞི་པ་ལ་གཉིས། རྒྱུའི་ཁྱད་པར་དང༌། འབྲས་བུའི་ཁྱད་པར་རོ། །
Enumeration Block 21:
གཉིས་པ་ལ་གཉིས། བསྟན་པ་དང༌། བཤད་པའོ། །དང་པོ་ལ་གཉིས། དཔེ་དང༌། དོན་ནོ། །དང་པོ་ལ་གཉིས། སྣང་བ་ལྟར་མ་གྲུབ་ཀྱང་སྐྱེ་འགག་དང་ལྡན་པ་ལྟར་སྣང་བ་དང༌། སྣང་བ་དེ་ཉིད་འདོད་པའི་འབྲས་བུའི་རྒྱུར་བསྟན་པའོ། །
Enumeration Block 22:
གཉིས་པ་ལ་གཉིས། སྐྱེ་བར་སྣང་བའི་དཔེ་དོན་དང༌། འགག་པར་སྣང་བའི་དཔེ་དོན་ནོ། །
Enumeration Block 23:
གཉིས་པ་གསུང་ལྷའི་རྔའི་དཔེས་བསྟན་པ་ལ་གསུམ། གདུལ་བྱ་ལ་ཕན་འདོགས་པའི་ཁྱད་པར་དང༌། སངས་རྒྱས་ཀྱི་གསུང་གི་ཁྱད་པར་དུ་འཕགས་པའི་ཆོས་དང༌། སངས་རྒྱས་ཀྱི་གསུང་གདུལ་བྱས་རེས་འགའ་མ་ཐོས་པ་གདུལ་བྱའི་ཉེས་པ་ཡིན་གྱི་གསུང་གི་སྐྱོན་མ་ཡིན་པའོ། །དང་པོ་ལ་གཉིས། བག་ཡོད་པའི་གནས་ལ་སྦྱོར་བ་དང༌། ཉེ་བར་འཚེ་བ་ལས་སྐྱོབ་པའོ། །དང་པོ་ལ་གཉིས། མདོར་བསྟན་པ་དང༌། རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གཉིས། དཔེ་དང༌། དོན་ནོ། །
Enumeration Block 24:
