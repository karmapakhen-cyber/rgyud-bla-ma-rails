Enumeration Block 1:
གསུམ་པ་ལ་གཉིས། མཚམས་སྦྱར་བ་དང༌། ལུང་དགོད་པའོ། །
Enumeration Block 2:
གསུམ་པ་ལྡན་པའི་དོན་བཤད་པ་ལ་གསུམ། མཚམས་སྦྱར་བ་དང༌། མདོར་བསྟན་པ་དང༌། རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 3:
གཉིས་པ་ལ་གཉིས། རྒྱུའི་ཡོན་ཏན་དང་ལྡན་པ་དང༌། འབྲས་བུའི་ཡོན་ཏན་དང་ལྡན་པའོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གཉིས། རྒྱུའི་ཡོན་ཏན་དང་ལྡན་པ་དང་། འབྲས་བུའི་ཡོན་ཏན་དང་ལྡན་པ་བཤད་པའོ། །དང་པོ་ལ་གཉིས། དྲི་བ་དང༌། ལན་ནོ། །
Enumeration Block 5:
གཉིས་པ་ལ་གཉིས། རྩ་བ་དང༌། འགྲེལ་པའོ། །
Enumeration Block 6:
གཉིས་པ་ལ་གཉིས། བསྟན་པ་དང༌། བཤད་པའོ། །
Enumeration Block 7:
གཉིས་པ་ལ་གསུམ། ཡོན་ཏན་གྱི་དབྱེ་བ་དང༌། སོ་སོར་བཤད་པ་དང༌། དཔེ་དོན་ཆོས་མཐུན་སྦྱར་བའོ། །
Enumeration Block 8:
གཉིས་པ་ལ་གཉིས། དྲི་བ་དང༌། ལན་ནོ། །
Enumeration Block 9:
གཉིས་པ་ལ་གཉིས། རྩ་བ་དང༌། འགྲེལ་པའོ། །
Enumeration Block 10:
གཉིས་པ་ལ་གཉིས། དངོས་ཀྱི་དོན་དང༌། ལུང་དང་སྦྱར་བའོ། །དང་པོ་ལ་གསུམ། མདོར་བསྟན་པ་དང༌། རྒྱས་པར་བཤད་པ་དང༌། དོན་བསྡུ་བའོ། །
Enumeration Block 11:
གཉིས་པ་ལ་གཉིས། ཡོན་ཏན་གྱི་དབྱེ་བ་དང༌། དཔེ་དོན་ཆོས་མཐུན་སྦྱར་བའོ། །
Enumeration Block 12:
བཞི་པ་འཇུག་པའི་རབ་དབྱེ་བཤད་པ་ལ་གཉིས། དངོས་ཀྱི་དོན་དང༌། དེའི་ཡན་ལག་གོ ། དང་པོ་ལ་གསུམ། མཚམས་སྦྱར་བ་དང༌། བསྟན་པ་དང༌། བཤད་པའོ། །
Enumeration Block 13:
ལན་ལ་གཉིས། རྩ་བ་དང༌། འགྲེལ་པའོ། །
Enumeration Block 14:
གཉིས་པ་ལ་གཉིས། སྤྱིའི་མཚམས་སྦྱར་བ་དང༌། སོ་སོའི་དོན་བཤད་པའོ། །
Enumeration Block 15:
གཉིས་པ་ལ་བཞི། ངོ་བོའི་སྒོ་ནས་ཐ་དད་པ་མ་ཡིན་པར་གནས་སྐབས་ཙམ་ཐ་དད་པའི་རབ་ཏུ་དབྱེ་བ་དང༌། རང་བཞིན་གཅིག་ཉིད་གནས་སྐབས་ཀུན་ཏུ་འགྲོ་བས་དེ་ཉིད་བསྒྲུབ་པ་དང༌། ངོ་བོའི་སྒོ་ནས་གཞན་དུ་མི་འགྱུར་བས་བསྒྲུབ་པ་དང༌། ཤིན་ཏུ་རྣམ་པར་དག་པའི་དུས་ན་རྣམ་གྲོལ་གྱི་ཡོན་ཏན་རྣམས་དབྱེར་མེད་དུ་ལྡན་པར་བསྒྲུབ་པའོ། །དང་པོ་ལ་གསུམ། མཚམས་སྦྱར་བ་དང༌། བསྟན་པ་དང༌། རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 16:
ལན་ལ་གཉིས། རྩ་བ་དང༌། འགྲེལ་པའོ། །
Enumeration Block 17:
གཉིས་པ་ལ་གཉིས། ཚིག་དོན་དང༌། ལུང་དང་སྦྱར་བའོ། །
Enumeration Block 18:
གཉིས་པ་ལ་གསུམ། མཚམས་སྦྱར་བ་དང༌། བསྟན་པ་དང༌། རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 19:
ལན་ལ་གཉིས། རྩ་བ་དང༌། འགྲེལ་པའོ། །
Enumeration Block 20:
གཉིས་པ་ལ་གཉིས། ཚིག་དོན་དང༌། ལུང་དང་སྦྱར་བའོ། །
Enumeration Block 21:
གསུམ་པ་ལ་གཉིས། མཚམས་སྦྱར་བ་དང༌། དོན་བཤད་པའོ། །
Enumeration Block 22:
གཉིས་པ་ལ་གཉིས། སྤྱིར་བསྟན་པ་དང༌། སོ་སོར་བཤད་པའོ། །དང་པོ་ལ་གཉིས། རྩ་བ་དང༌། དོན་ཚན་སོ་སོར་བཤད་པའོ། །
Enumeration Block 23:
གཉིས་པ་ལ་གསུམ། མ་དག་པའི་གནས་སྐབས་ན་མི་འགྱུར་བ་བཤད་པ་དང༌། མ་དག་པ་དང་དག་པའི་གནས་སྐབས་ན་མི་འགྱུར་བ་བཤད་པ་དང༌། ཤིན་ཏུ་རྣམ་དག་གི་གནས་སྐབས་ན་མི་འགྱུར་བའི་དོན་བཤད་པའོ། །དང་པོ་ལ་གཉིས། དྲི་བ་དང༌། ལན་ནོ། །
Enumeration Block 24:
གཉིས་པ་ལ་གཉིས། ཕུང་སོགས་སྐྱེད་བྱེད་ལས་ཉོན་སོགས་ཀྱིས་མི་འགྱུར་བ་དང༌། མེ་དང་ཆོས་མཚུངས་པའི་ཕུང་སོགས་འཇིག་བྱེད་རྒ་བ་སོགས་ཀྱིས་མི་འགྱུར་བའོ། །དང་པོ་ལ་གཉིས། རྩ་བ་དང༌། འགྲེལ་པའོ། །དང་པོ་ལ་གསུམ། མདོར་བསྟན་པ་དང༌། རྒྱས་པར་བཤད་པ་དང༌། དོན་བསྡུ་བའོ། །དང་པོ་ལ་གཉིས། ཀུན་ནས་ཉོན་མོངས་ཀྱི་ཆོས་ཀྱིས་མ་གོས་པ་དང༌། དེའི་སྐྱེ་འཇིག་གིས་མ་གོས་པའོ། །
Enumeration Block 25:
གཉིས་པ་ལ་གཉིས། འཇིག་པའི་ཆོས་ཀྱིས་མ་གོས་པ་དང༌། སྐྱེ་བའི་ཆོས་ཀྱིས་མ་གོས་པའོ། །
Enumeration Block 26:
གཉིས་པ་ལ་གསུམ། དཔེ་དང་། དོན་དང༌། དཔེ་དོན་སོ་སོར་སྦྱར་བའོ། །
Enumeration Block 27:
གསུམ་པ་ལ་གཉིས། དངོས་དང༌། དཔེ་དོན་ཆོས་མཐུན་གྱི་ཁྱད་པར་བཤད་པའོ། །
Enumeration Block 28:
གཉིས་པ་ལ་གསུམ། ཚུལ་མིན་ཡིད་བྱེད་ཀྱི་ཁྱད་པར་དང༌། ལས་ཉོན་གྱི་ཁྱད་པར་དང༌། དེ་དག་གི་རྟེན་གྱི་ཁྱད་པར་རོ། །
Enumeration Block 29:
གསུམ་པ་ལ་གཉིས། ལས་ཉོན་གྱིས་གཞན་དུ་མི་འགྱུར་བ་དང༌། སྐྱེ་འཇིག་གིས་གཞན་དུ་མི་འགྱུར་བ་མཚམས་སྦྱར་བ་དང་བཅས་པའོ། །
Enumeration Block 30:
གཉིས་པ་ལ་གཉིས། མཚམས་སྦྱར་བ་དང༌། རྩ་བའོ། །
Enumeration Block 31:
གཉིས་པ་ལ་གསུམ། ཚིག་དོན་བསྡུས་ཏེ་བསྟན་པ་དང༌། ལུང་དང་སྦྱར་བ་དང༌། བཤད་ཟིན་དྲན་པར་བྱེད་པའོ། །དང་པོ་ལ་གསུམ། སྐྱེ་བས་མ་གོས་པ་དང༌། འཇིག་པས་མ་གོས་པ་དང༌། དོན་བསྡུ་བའོ། །
Enumeration Block 32:
དེ་ལ་གཉིས། ཉོན་མོངས་ཀྱི་ཆོས་ཀྱིས་མ་གོས་པ་དང༌། སྐྱེ་འཇིག་གིས་མ་གོས་པའོ། །
Enumeration Block 33:
གཉིས་པ་ལ་གཉིས། རྒྱས་པར་བཤད་པ་དང༌། དོན་བསྡུ་བའོ། །དང་པོ་ལ་གསུམ། དཔེ་དང༌། དོན་དང། དཔེ་དོན་སྦྱར་བའོ། །
Enumeration Block 34:
གཉིས་པ་ལ་གསུམ། མཚམས་སྦྱར་བ་དང༌། རྩ་བ་དང༌། འགྲེལ་པའོ། །
Enumeration Block 35:
གསུམ་པ་ལ་གཉིས། དཔེ་གསུམ་དང་འདྲ་བའི་རྒྱུ་མཚན་དང༌། ལུང་དང་སྦྱར་བའོ། །
Enumeration Block 36:
གཉིས་པ་ལ་གསུམ། མཚམས་སྦྱར་བ་དང༌། མདོར་བསྟན་པ་དང༌། རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 37:
གསུམ་པ་ལ་གཉིས། དྲི་བ་དང༌། ལན་ནོ། །
Enumeration Block 38:
གཉིས་པ་ལ་གཉིས། སྐྱེ་བའི་ཁྱད་པར་ལ་བལྟོས་ནས་བཤད་པའི་མ་དག་པ་དང་དག་པའི་གནས་སྐབས་ན་འགྱུར་བ་མེད་པ་དང༌། སངས་རྒྱས་དང་སོ་སྐྱེ་ལ་བལྟོས་ནས་བཤད་པའི་མ་དག་པ་དང་དག་པའི་གནས་སྐབས་ན་འགྱུར་བ་མེད་པའོ། །དང་པོ་ལ་གཉིས། དག་པའི་ཁྱད་པར་བཤད་པ་དང༌། མ་དག་པའི་རང་བཞིན་དག་མ་དག་གི་རྒྱུས་ཁྱད་པར་དུ་བྱས་ནས་བཤད་པའོ། །དང་པོ་ལ་གཉིས། རྩ་བ་དང༌། འགྲེལ་པའོ། །
Enumeration Block 39:
གཉིས་པ་ལ་གཉིས། རྩ་བ་དང༌། དེ་དག་གི་དོན་བཤད་པའོ། །
Enumeration Block 40:
གཉིས་པ་ལ་གཉིས། ཚིག་དོན་མདོར་བསྟན་པ་དང༌། དེ་དག་གི་དོན་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 41:
གཉིས་པ་ལ་གཉིས། སྙིང་རྗེ་དང་སྨོན་ལམ་གྱི་དབང་གིས་སྐྱེ་བ་ལེན་པའི་ཚུལ་རྒྱས་པར་བཤད་པ་དང༌། ལས་དང་ཉོན་མོངས་པའི་དབང་གིས་མི་སྐྱེ་བའི་རྒྱུ་མཚན་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གཉིས། ལུང་དང་སྦྱར་བ་དང༌། ལུང་གི་དོན་བསྡུས་ཏེ་བསྟན་པའོ། །དང་པོ་ལ་གཉིས། འཁོར་བར་སྐྱེ་བ་ལེན་པའི་རྒྱུ་ངོས་བཟུང་བ་དང༌། དེ་ཉོན་མོངས་མཚན་ཉིད་པ་ཡིན་པ་དགག་པའོ། །
Enumeration Block 42:
གཉིས་པ་ལ་གསུམ། ཉོན་མོངས་པར་འདོགས་པའི་རྒྱུ་མཚན་དང༌། ཉོན་མོངས་མཚན་ཉིད་པ་ཡིན་པ་དགག་པ་དང༌། ཁམས་གསུམ་དུ་སྐྱེ་བ་སོགས་བསྟན་པའི་དགོས་པའོ། །
Enumeration Block 43:
གསུམ་པ་ལ་གཉིས། དཔེ་དང༌། དོན་ནོ། །
Enumeration Block 44:
གཉིས་པ་ལ་གཉིས། མཚམས་སྦྱར་བ་དང༌། ལུང་དང་སྦྱར་བའོ། །
Enumeration Block 45:
གཉིས་པ་ལ་གསུམ། ལུང་དྲང་བ་དང། ལུང་གི་དོན་བཤད་པ་དང། ཟག་པ་ཟད་པའི་ཤེས་པ་བྱེ་བྲག་ཏུ་བཤད་པའོ། །དང་པོ་ལ་གསུམ། དེ་ཁོ་ན་ཉིད་མཐོང་བའི་ཚུལ་དང། དེ་ཁོ་ན་ཉིད་མཐོང་ཡང་སྐྱེ་བ་ལེན་པའི་རྒྱུ་བརྗོད་པ་དང། དེ་ཉིད་བསྒྲུབ་པའོ། །
Enumeration Block 46:
གསུམ་པ་ལ་གསུམ། དཔེ་དང༌། དོན་དང༌། དག་མ་དག་གཉི་གའི་རྒྱུའི་དོན་བསྡུ་བའོ། །
Enumeration Block 47:
གསུམ་པ་ལ་གཉིས། དག་པའི་དོན་བསྡུ་བ་དང་མ་དག་པའི་དོན་བསྡུ་བའོ། །
Enumeration Block 48:
གཉིས་པ་ལ་གཉིས། དངོས་དང༌། ལུང་དང་སྦྱར་བའོ། །
Enumeration Block 49:
གསུམ་པ་ལ་གཉིས། སྤྱིར་བསྟན་པ་དང༌། ལུང་དང་སྦྱར་བའོ། །
Enumeration Block 50:
གཉིས་པ་སངས་རྒྱས་དང་སོ་སྐྱེ་ལ་བལྟོས་ནས་བཤད་པའི་མ་དག་པ་དང༌དག་པའི་གནས་སྐབས་ན་འགྱུར་བ་མེད་པ་ལ་གསུམ། མཚམས་སྦྱར་བ་དང་། རྩ་བ་དང༌། འགྲེལ་པའོ། །
Enumeration Block 51:
གཉིས་པ་ལ་གཉིས། བྱང་ཆུབ་སེམས་དཔའ་བཞིའི་དག་པ་དང་མ་དག་པའི་ཡོན་ཏན་བཤད་པ་དང༌། སྲིད་པ་ཐ་མ་པའི་བྱང་ཆུབ་སེམས་དཔའི་དག་པ་དང་མ་དག་པའི་ཡོན་ཏན་བཤད་པའོ། །
Enumeration Block 52:
དང་པོ་ལ་བཞི། དོན་དམ་པའི་སེམས་དང་པོ་བསྐྱེད་པ་དང༌། སྤྱོད་པ་ལ་ཞུགས་པ་དང༌། ཕྱིར་མི་ལྡོག་པ་དང༌། སྐྱེ་བ་གཅིག་གིས་ཐོགས་པའི་བྱང་ཆུབ་སེམས་དཔའི་ཡོན་ཏན་བཤད་པའོ། །དང་པོ་ལ་གཉིས། རང་དོན་གྱི་ཡོན་ཏན་དང༌། གཞན་དོན་གྱི་ཡོན་ཏན་ནོ། །
Enumeration Block 53:
གཉིས་པ་ལ་གཉིས། འཇིག་རྟེན་ན་གནས་ཀྱང་དེའི་དྲི་མས་མ་གོས་པ་དང༌། དཔེ་དོན་སྦྱར་ཏེ་བཤད་པའོ། །
Enumeration Block 54:
བཞི་པ་ལ་གཉིས། འཕྲིན་ལས་ཕུན་ཚོགས་ཀྱི་རྒྱུ་དང༌། དེ་ལ་བརྟེན་ནས་འཕྲིན་ལས་འབད་མེད་དུ་འཇུག་པར་བསྟན་པའོ། །དང་པོ་ལ་གཉིས། འཕྲིན་ལས་རྩོལ་བ་མི་མངའ་བར་འཇུག་པའི་རྒྱུ་དང༌། གདུལ་བྱ་དང་རྗེས་སུ་མཐུན་པའི་འཕྲིན་ལས་སྣ་ཚོགས་མཁྱེན་པའོ། །
Enumeration Block 55:
གཉིས་པ་ལ་གཉིས། དག་པའི་ཁྱད་པར་དང་། མ་དག་པའི་ཁྱད་པར་རོ། །
Enumeration Block 56:
གསུམ་པ་ལ་གཉིས། སྤྱིར་བསྟན་པ་དང༌། སོ་སོར་བཤད་པའོ། །
