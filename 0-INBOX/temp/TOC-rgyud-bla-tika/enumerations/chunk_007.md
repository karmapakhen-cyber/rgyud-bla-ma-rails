Enumeration Block 1:
གཉིས་པ་སངས་རྒྱས་དང་སོ་སྐྱེ་ལ་བལྟོས་ནས་བཤད་པའི་མ་དག་པ་དང༌དག་པའི་གནས་སྐབས་ན་འགྱུར་བ་མེད་པ་ལ་གསུམ། མཚམས་སྦྱར་བ་དང་། རྩ་བ་དང༌། འགྲེལ་པའོ། །
Enumeration Block 2:
གཉིས་པ་ལ་གཉིས། བྱང་ཆུབ་སེམས་དཔའ་བཞིའི་དག་པ་དང་མ་དག་པའི་ཡོན་ཏན་བཤད་པ་དང༌། སྲིད་པ་ཐ་མ་པའི་བྱང་ཆུབ་སེམས་དཔའི་དག་པ་དང་མ་དག་པའི་ཡོན་ཏན་བཤད་པའོ། །
Enumeration Block 3:
དང་པོ་ལ་བཞི། དོན་དམ་པའི་སེམས་དང་པོ་བསྐྱེད་པ་དང༌། སྤྱོད་པ་ལ་ཞུགས་པ་དང༌། ཕྱིར་མི་ལྡོག་པ་དང༌། སྐྱེ་བ་གཅིག་གིས་ཐོགས་པའི་བྱང་ཆུབ་སེམས་དཔའི་ཡོན་ཏན་བཤད་པའོ། །དང་པོ་ལ་གཉིས། རང་དོན་གྱི་ཡོན་ཏན་དང༌། གཞན་དོན་གྱི་ཡོན་ཏན་ནོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གཉིས། འཇིག་རྟེན་ན་གནས་ཀྱང་དེའི་དྲི་མས་མ་གོས་པ་དང༌། དཔེ་དོན་སྦྱར་ཏེ་བཤད་པའོ། །
Enumeration Block 5:
བཞི་པ་ལ་གཉིས། འཕྲིན་ལས་ཕུན་ཚོགས་ཀྱི་རྒྱུ་དང༌། དེ་ལ་བརྟེན་ནས་འཕྲིན་ལས་འབད་མེད་དུ་འཇུག་པར་བསྟན་པའོ། །དང་པོ་ལ་གཉིས། འཕྲིན་ལས་རྩོལ་བ་མི་མངའ་བར་འཇུག་པའི་རྒྱུ་དང༌། གདུལ་བྱ་དང་རྗེས་སུ་མཐུན་པའི་འཕྲིན་ལས་སྣ་ཚོགས་མཁྱེན་པའོ། །
Enumeration Block 6:
གཉིས་པ་ལ་གཉིས། དག་པའི་ཁྱད་པར་དང་། མ་དག་པའི་ཁྱད་པར་རོ། །
Enumeration Block 7:
གསུམ་པ་ལ་གཉིས། སྤྱིར་བསྟན་པ་དང༌། སོ་སོར་བཤད་པའོ། །
Enumeration Block 8:
གཉིས་པ་ལ་ལྔ་ཡོད་པའི་དང་པོ་དོན་དམ་པའི་སེམས་དང་པོ་བསྐྱེད་པའི་ཡོན་ཏན་ནི།
Enumeration Block 9:
གསུམ་པ་ཤིན་ཏུ་རྣམ་དག་གི་གནས་སྐབས་ན་འགྱུར་བ་མེད་པའི་དོན་བཤད་པ་ལ་གཉིས། མཚམས་སྦྱར་བ་དང༌། དོན་བཤད་པའོ། །
Enumeration Block 10:
གཉིས་པ་ལ་གསུམ། བསྟན་པ་དང༌། བཤད་པ་དང༌། བསྟན་བཤད་སྦྱར་བའོ། །
Enumeration Block 11:
གཉིས་པ་ལ་གཉིས། དྲི་བ་དང༌། ལན་ནོ། །
Enumeration Block 12:
གཉིས་པ་ལ་གཉིས། རྩ་བ་དང༌། འགྲེལ་པའོ། །དང་པོ་ལ་གསུམ། ཤུགས་ལ་བསྟན་པའི་རྣམ་བཅད་ཀྱི་དོན་དང་། ཡོངས་གཅོད་ཀྱི་དོན་དང༌། རྣམ་བཅད་ཀྱི་དོན་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 13:
གསུམ་པ་ལ་གཉིས། རྟག་སོགས་བཞིའི་དོན་མདོ་ལས་ཤེས་པར་བྱ་བ་དང༌། བསྟན་བཤད་སྦྱར་བའོ། །དང་པོ་ལ་གཉིས། རྩ་བ་དང༌། འགྲེལ་པའོ། །
Enumeration Block 14:
གཉིས་པ་ལ་གཉིས། རྩ་བ་དང༌། མདོ་དང་སྦྱར་བའོ། །
Enumeration Block 15:
བཞི་པ་ཤིན་ཏུ་རྣམ་པར་དག་པའི་དུས་ན་རྣམ་གྲོལ་གྱི་ཡོན་ཏན་རྣམས་དབྱེར་མེད་དུ་ལྡན་པར་བསྒྲུབ་པ་ལ་གཉིས། མཚམས་སྦྱར་བ་དང༌། དོན་བཤད་པའོ། །
Enumeration Block 16:
གཉིས་པ་ལ་གཉིས། མདོར་བསྟན་པ་དང་། རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 17:
གཉིས་པ་ལ་གསུམ། མཐར་ཐུག་པའི་ཡོན་ཏན་གྱི་དབྱེར་མེད་པའི་གཏན་ཚིགས་ཀྱི་དོན་བཤད་པ་དང༌། དེས་གྲུབ་པའི་དོན་དང༌། ཡོན་ཏན་དབྱེར་མེད་ཀྱི་རང་བཞིན་དང་དཔེ་བཤད་པའོ། །དང་པོ་ལ་གཉིས། དྲི་བ་དང༌། ལན་ནོ། །
Enumeration Block 18:
གཉིས་པ་ལ་གཉིས། མདོར་བསྟན་པ་དང༌། རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གཉིས། རྩ་བ་དང༌། འགྲེལ་པའོ། །
Enumeration Block 19:
གཉིས་པ་ལ་གཉིས། དྲི་བ་དང༌། ལན་ནོ། །
Enumeration Block 20:
གཉིས་པ་ལ་གཉིས། རྩ་བ་དང་། འགྲེལ་པའོ། །
Enumeration Block 21:
གཉིས་པ་ལ་གཉིས། ལུང་དང་སོ་སོར་སྦྱར་བ་དང༌། བསྟན་བཤད་ཀྱི་ཚིག་སྦྱར་བའོ། །
Enumeration Block 22:
གཉིས་པ་ལ་གཉིས། དྲི་བ་དང༌། ལན་ནོ། །
Enumeration Block 23:
གཉིས་པ་ལ་གཉིས། རྩ་བ་དང༌། འགྲེལ་པའོ། །
Enumeration Block 24:
གསུམ་པ་ལ་གཉིས། ཡོན་ཏན་དབྱེ་བ་མེད་པའི་རང་བཞིན་བཤད་པ་དང༌། དབྱེ་བ་མེད་པའི་དཔེ་བཤད་པའོ། །དང་པོ་ལ་གཉིས། དངོས་ཀྱི་དོན་དང༌། ཡོན་ཏན་མ་ཚང་བ་མེད་པ་རི་མོ་མཁན་གྱི་དཔེས་བཤད་པའོ། །དང་པོ་ལ་གཉིས། རྩ་བ་དང༌། འགྲེལ་པའོ། །
Enumeration Block 25:
གཉིས་པ་ལ་གཉིས། མཐར་ཐུག་པའི་རྣམ་གྲོལ་མི་འདྲ་བ་གསུམ་བཤད་པ་དགོངས་པ་ཅན་དུ་བསྟན་པ་དང༌། ཡོན་ཏན་བཞི་དབྱེར་མེད་པའི་ཐར་པ་སངས་རྒྱས་ཉག་གཅིག་ཏུ་བསྟན་པའོ། །
Enumeration Block 26:
གཉིས་པ་ལ་གསུམ། མཚམས་སྦྱར་བ་དང༌། རྩ་བ་དང་། འགྲེལ་པའོ། །
Enumeration Block 27:
གཉིས་པ་ལ་གཉིས། དཔེ་དང༌། དོན་ནོ། །
Enumeration Block 28:
གསུམ་པ་ལ་གསུམ། ཟབ་པ་དང་རྒྱ་ཆེ་བའི་ཡོན་ཏན་བཤད་པ་དང༌། དེ་དག་འགྲུབ་བྱེད་ཀྱི་རྒྱུ་དང༌། ཉན་རང་ལ་ཡོན་ཏན་དེ་དག་མེད་པར་བསྟན་པའོ། །དང་པོ་ལ་གཉིས། རྟོགས་པའི་ཡོན་ཏན་དང༌། སྤངས་པའི་ཡོན་ཏན་ནོ། །
Enumeration Block 29:
གཉིས་པ་ལ་གཉིས། དག་པ་ས་གསུམ་དུ་ཡོན་ཏན་ཇི་ལྟར་གྲུབ་པའི་ཚུལ་དང༌། དེ་ལ་བརྟེན་ནས་མཐར་ཐུག་གི་ཡོན་ཏན་གྲུབ་པའི་ཚུལ་ལོ། །དང་པོ་ལ་གསུམ། ས་བརྒྱད་པར་ལམ་ཤེས་རང་གི་ངང་གིས་འབྱུང་བའི་ཡོན་ཏན་ཐོབ་པ་དང༌། ས་དགུ་པར་སངས་རྒྱས་ཀྱི་དམ་པའི་ཆོས་མ་ལུས་པ་འཛིན་པའི་ཡོན་ཏན་ཐོབ་པ་དང༌། ས་བཅུ་པར་གསང་བའི་གནས་ཕྲ་མོ་མ་ལུས་པར་རྟོགས་པའི་ཡོན་ཏན་ཐོབ་པའོ། །
Enumeration Block 30:
གཉིས་པ་ཡོན་ཏན་དབྱེ་བ་མེད་པའི་དཔེ་བཤད་པ་ལ་གཉིས། དཔེ་དོན་ཆོས་མཐུན་བཤད་པ་དང༌། ཉན་རང་ལ་ཐེག་པ་དང་མྱང་འདས་མཐར་ཐུག་མེད་པར་གྲུབ་པའི་དོན་ནོ། །དང་པོ་ལ་གཉིས། རྩ་བ་དང༌། འགྲེལ་པའོ། །
Enumeration Block 31:
གཉིས་པ་ལ་གསུམ། ཆོས་མཐུན་སྤྱིར་བསྟན་པ་དང༌། སོ་སོར་བཤད་པ་དང༌། བསྡུས་ཏེ་བཤད་པའོ། །
Enumeration Block 32:
གཉིས་པ་ལ་གཉིས། རྩ་བ་དང༌། འགྲེལ་པའོ། །
Enumeration Block 33:
གཉིས་པ་ལ་གཉིས། ཚིག་དོན་དང༌། ལུང་དང་སྦྱར་བའོ། །
Enumeration Block 34:
གསུམ་པ་དོན་བསྡུ་བ་ལ་གཉིས། རྩ་བ་དང༌། འགྲེལ་པའོ། །
Enumeration Block 35:
