Enumeration Block 1:
གཉིས་པ་ལ་གཉིས། མཚམས་སྦྱར་བ་དང༌། རྩ་བའོ། །
Enumeration Block 2:
གཉིས་པ་ལ་གཉིས། མཚམས་སྦྱར་བ་དང༌། རྩ་བའོ། །
Enumeration Block 3:
གསུམ་པ་ལ་གཉིས། མཚམས་སྦྱར་བ་དང༌། རྩ་བའོ། །
Enumeration Block 4:
བཞི་པ་དེ་ཐམས་ཅད་ཀྱི་རྟེན་དཔེས་མཚོན་ཏེ་བསྟན་པ་ལ་གཉིས། མཚམས་སྦྱར་བ་དང༌། རྩ་བའོ། །
Enumeration Block 5:
གཉིས་པ་དཔེ་རྣམས་ཀྱི་བསྡུས་པའི་དོན་གྱི་དཔེའི་དགོས་པ་བཤད་པ་ལ་གཉིས། མཚམས་སྦྱར་བ་དང༌། དོན་བཤད་པའོ། །
Enumeration Block 6:
གཉིས་པ་ལ་གཉིས། དངོས་ཀྱི་དོན་དང༌། དེའི་སྒྲུབ་བྱེད་དོ། །
Enumeration Block 7:
གཉིས་པ་ལ་གཉིས། བསྟན་པ་དང༌། བཤད་པའོ། །
Enumeration Block 8:
གསུམ་པ་དཔེས་མཚོན་པར་བྱ་བའི་དོན་བསྡུས་ཏེ་བཤད་པ་ལ་གཉིས། དངོས་ཀྱི་དོན་དང༌། དཔེ་དོན་ཆོས་མཐུན་བཤད་པའོ། །དང་པོ་ལ་གསུམ། དངོས་བསྟན་གྱི་དོན་མདོར་བསྟན་པ་དང༌། ཤུགས་བསྟན་གྱི་དོན་བཤད་པ་དང༌། དངོས་བསྟན་གྱི་དོན་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གཉིས། བསྟན་པ་དང༌། བཤད་པའོ། །
Enumeration Block 9:
གཉིས་པ་ལ་གསུམ། བསྟན་པ་དང༌། བཤད་པ་དང༌། སྟོན་པ་སྐྱེ་འཆི་དང་བྲལ་ཞིང་འཕྲིན་ལས་འབད་མེད་དུ་འཇུག་པར་གྲུབ་པའོ། །
Enumeration Block 10:
གསུམ་པ་ལ་གཉིས། མཚམས་སྦྱར་བ་དང༌། རྩ་བའོ། །
Enumeration Block 11:
གཉིས་པ་ལ་གཉིས། སྤྱིར་བསྟན་པ་དང༌། དེ་ཉིད་བཤད་པའོ། །
Enumeration Block 12:
གཉིས་པ་ལ་གཉིས། དྲི་བ་དང༌། ལན་ནོ། །
Enumeration Block 13:
གཉིས་པ་ལ་གཉིས། སྐྱེ་འགག་མེད་པའི་ཆོས་མཐུན་བཤད་པ་དང༌། རྣམ་རྟོག་མེད་པའི་ཆོས་མཐུན་བཤད་པའོ། །
Enumeration Block 14:
གསུམ་པ་དཔེའི་གོ་རིམས་བཤད་པ་ལ་གསུམ། མདོར་བསྟན་པ་དང༌། རྒྱས་པར་བཤད་པ་དང༌། གནས་གྱུར་མཐར་ཕྱིན་པའི་ཡེ་ཤེས་ཡོན་ཏན་ཀུན་གྱི་རྟེན་དུ་བསྒྲུབ་པའོ། །
Enumeration Block 15:
གཉིས་པ་རྟོགས་པར་བྱ་བའི་དོན་རྣམ་པ་བདུན་ལ་མོས་པའི་ཕན་ཡོན་བཤད་པ་ལ་གཉིས། ལེའུའི་དོན་བཤད་པ་དང༌། ལེའུའི་མཚན་བསྟན་པའོ། །དང་པོ་ལ་གཉིས། དངོས་ཀྱི་དོན་དང༌། བཤད་པ་མཐར་ཕྱིན་པར་བསྟན་པའོ། །དང་པོ་ལ་གསུམ། མཚམས་སྦྱར་བ་དང༌། མདོར་བསྟན་པ་དང༌། རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 16:
གཉིས་པ་ལ་གསུམ། གནས་བཞི་ལ་མོས་པའི་ཕན་ཡོན་སྤྱིར་བསྟན་པ་དང༌། སོ་སོར་བཤད་པ་དང༌། གཞི་གསུམ་གྱིས་བསྡུས་པའི་དགེ་བ་ལས་གནས་བཞི་ལ་མོས་པ་ཁྱད་པར་དུ་འཕགས་པའི་སྒྲུབ་བྱེད་དོ། །དང་པོ་ལ་གཉིས། གནས་བཞི་མ་ལུས་པ་སངས་རྒྱས་ཉག་ཅིག་གི་སྤྱོད་ཡུལ་དུ་བསྟན་པ་དང༌། དེ་ལ་མོས་པའི་ཕན་ཡོན་ནོ། །
Enumeration Block 17:
གཉིས་པ་ལ་གསུམ། སྦྱིན་པ་ལས་བྱུང་བའི་བསོད་ནམས་ལས་ཁྱད་པར་དུ་འཕགས་པ་དང༌། ཚུལ་ཁྲིམས་ལས་བྱུང་བའི་བསོད་ནམས་དང༌། བསྒོམས་པ་ལས་བྱུང་བའི་བསོད་ནམས་གཞན་ལས་ཁྱད་པར་དུ་འཕགས་པའོ། །
Enumeration Block 18:
གསུམ་པ་ལ་གཉིས། མཚམས་སྦྱར་བ་དང༌། རྩ་བའོ། །
Enumeration Block 19:
གཉིས་པ་ལ་གསུམ། གནས་བཞི་ཐོས་ཤིང་མོས་པའི་བསྔགས་པ་སྤྱིར་བསྟན་པ་དང༌། བྱེ་བྲག་ཏུ་བཤད་པ་དང༌། ཐོས་ནས་མོས་པ་མཆོག་ཏུ་གྲུབ་པའོ། །དང་པོ་ལ་གཉིས། མོས་པའི་ཡུལ་ངོས་བཟུང་བ་དང༌། དེ་ལས་མོས་པས་མཐར་ཐུག་པའི་དཀོན་མཆོག་གསུམ་ཐོབ་པར་འགྱུར་བའོ། །
Enumeration Block 20:
གཉིས་པ་ལ་གསུམ། བསམ་པ་ཕུན་ཚོགས་སེམས་བསྐྱེད་ཀྱི་རྒྱུར་བསྔགས་པ་དང༌། སྦྱོར་བ་ཕུན་ཚོགས་ཕར་ཕྱིན་གྱི་རྒྱུར་བསྔགས་པ་དང༌། ཚོགས་གཉིས་ཀྱི་ངོ་བོ་ངོས་བཟུང་བའོ། །
Enumeration Block 21:
གསུམ་པ་ལ་གཉིས། དངོས་ཀྱི་དོན་དང༌། ཕར་ཕྱིན་དང་པོ་ལྔ་གཞི་གསུམ་གྱིས་བསྡུས་པའི་དགེ་བར་མ་འདུས་པའི་སྐྱོན་མེད་པའོ། །
Enumeration Block 22:
གསུམ་པ་ལ་གཉིས། སྒྲིབ་གཉིས་ངོས་བཟུང་བ་དང༌། དེའི་གཉེན་པོ་འདྲེན་པའི་རྩ་བ་ཡིན་པས་རྒྱུའི་མཆོག་ཏུ་གྲུབ་པའོ། །
Enumeration Block 23:
གཉིས་པ་བཤད་པ་མཐར་ཕྱིན་པར་བསྟན་པ་ལ་གཉིས། རྒྱས་པར་བཤད་པ་དང༌། དོན་བསྡུ་བའོ། །
དང་པོ་ལ་གསུམ། དམ་པའི་ཆོས་བརྗོད་པའི་ཚུལ་དང༌། དམ་པའི་ཆོས་སྤོང་བའི་སྒྲིབ་པ་ལ་བག་བྱ་བར་གདམས་པ་དང༌། བརྩམས་པའི་དགེ་བ་བྱང་ཆུབ་ཏུ་བསྔོ་བའོ། །དང་པོ་ལ་གསུམ། གང་ལ་བརྟེན་ནས་དགོས་པ་གང་གི་ཕྱིར་མཛད་པ་དང༌། རང་བཞིན་ཅི་འདྲ་བ་ཞིག་བཤད་པ་དང༌། རྒྱུ་མཐུན་གྱི་འབྲས་བུ་ལ་གུས་པར་གདམས་པའོ། །དང་པོ་ལ་གཉིས། གང་ལ་བརྟེན་ནས་མཛད་པ་དང༌། དགོས་པ་གང་གིས་ཕྱིར་མཛད་པའོ། །
Enumeration Block 24:
གཉིས་པ་ལ་གཉིས། འཆད་བྱེད་བསྟན་བཅོས་ཀྱི་རང་བཞིན་ཅི་འདྲ་བ་ཞིག་བཤད་པ་དང༌། བཤད་བྱ་གསུང་རབ་ཀྱི་ངོ་བོ་ངོས་བཟུང་བའོ། །
Enumeration Block 25:
གཉིས་པ་ལ་གསུམ། དམ་པའི་ཆོས་མི་སྤོང་བའི་ཐབས་ལ་འབད་པར་གདམས་པ་དང༌། དམ་པའི་ཆོས་སྤོང་བའི་རྒྱུ་སྤང་བར་བྱ་བར་གདམས་པ་དང༌། ཆོས་སྤངས་པའི་ཉེས་དམིགས་བཤད་པའོ། །དང་པོ་ལ་གཉིས། ཆོས་ལ་དབང་མི་ཟ་བར་གུས་པར་བྱ་བ་དང༌། ཆགས་སྡང་གི་ཕྱོགས་སུ་མ་ལྷུང་བར་གདམས་པའོ། །དང་པོ་ལ་གཉིས། དབང་ཟ་བར་མི་རིགས་པ་དང༌། དབང་ཟོས་པའི་ཉེས་དམིགས་སོ། །
Enumeration Block 26:
གཉིས་པ་ལ་གཉིས། ཕྱོགས་སུ་ལྷུང་བའི་ཉེས་དམིགས་དང༌། དེ་འགོག་པའི་ཐབས་སོ། །
Enumeration Block 27:
གསུམ་པ་ལ་གཉིས། དམ་པའི་ཆོས་སྤོང་བས་ངན་སོང་དུ་འགྲོ་བ་དང༌། འཁོར་བ་ལས་མི་ཐར་པའོ། །
Enumeration Block 28:
གཉིས་པ་ལ་གཉིས། མཚམས་སྦྱར་བ་དང༌། རྩ་བའོ། །
Enumeration Block 29:
