Enumeration Block 1:
གཉིས་པ་ལ་གཉིས། མཚམས་སྦྱར་བ་དང༌། དོན་བཤད་པའོ། །
Enumeration Block 2:
གཉིས་པ་ལ་གཉིས། བསྟན་པ་དང༌། བཤད་པའོ། །དང་པོ་ལ་གསུམ། དཔེ་དང༌། དོན་དང༌། སྒྲིབ་པ་སེལ་བྱེད་དོ། །
Enumeration Block 3:
བཞི་པ་ལ་གཉིས། མ་དག་པའི་ས་ལ་བརྟེན་པའི་དྲི་མ་གློ་བུར་བར་དཔེས་བསྒྲུབ་པ་དང༌། དག་པའི་ས་ལ་བརྟེན་པའི་དྲི་མ་གློ་བུར་བར་དཔེས་བསྒྲུབ་པའོ། །དང་པོ་ལ་གཉིས། མཚམས་སྦྱར་བ་དང༌། དོན་བཤད་པའོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གཉིས། བསྟན་པ་དང༌། བཤད་པའོ། །དང་པོ་ལ་གཉིས། དཔེ་དང༌། དོན་ནོ། །
Enumeration Block 5:
གཉིས་པ་ལ་གཉིས། མཚམས་སྦྱར་བ་དང༌། དོན་བཤད་པའོ། །
Enumeration Block 6:
གཉིས་པ་ལ་གཉིས། བསྟན་པ་དང༌། བཤད་པའོ། །དང་པོ་ལ་གསུམ། དཔེ་དང༌། དོན་དང༌། སྒྲིབ་པ་སེལ་བྱེད་དོ། །
Enumeration Block 7:
གསུམ་པ་དོན་བསྡུ་བ་ལ་གསུམ། མཚམས་སྦྱར་བ་དང༌། རྩ་བ་དང༌། འགྲེལ་པའོ། །
Enumeration Block 8:
གཉིས་པ་ལ་གསུམ། སྒྲིབ་བྱེད་ཀྱི་དཔེ་དང༌། བསྒྲིབ་བྱའི་དཔེ་དང༌། སེམས་རང་བཞིན་རྣམ་དག་ལ་དྲི་མ་གློ་བུར་བར་གྲུབ་པའི་དོན་ནོ། །
Enumeration Block 9:
གཉིས་པ་དཔེས་མཚོན་པར་བྱ་བའི་དོན་སོ་སོར་བཤད་པ་ལ་བཞི། ཁམས་སྒྲིབ་བྱེད་ཀྱི་དབྱེ་བ་དང༌། གང་ཟག་གང་ལ་སྒྲིབ་པ་དང༌། ཁམས་སྒྲིབ་བྱེད་ཀྱི་དཔེ་དོན་ཆོས་མཐུན་བཤད་པ་དང༌། བསྒྲིབ་བྱ་ཁམས་ཀྱི་དཔེ་དོན་ཆོས་མཐུན་བཤད་པའོ། །དང་པོ་ལ་གསུམ། མཚམས་སྦྱར་བ་དང༌། རྒྱས་པར་བཤད་པ་དང༌། དོན་བསྡུ་བའོ། །
Enumeration Block 10:
གཉིས་པ་ལ་གཉིས། རྩ་བ་དང༌། འགྲེལ་པའོ། །དང་པོ་ལ་གསུམ། སྒྲིབ་བྱེད་མཚན་ཉིད་དགུར་དབྱེ་བ་དང༌། དེ་དཔེས་བསྟན་པ་དང༌། གསལ་བའི་དབྱེ་བ་མཐའ་ཡས་པའོ། །
Enumeration Block 11:
གཉིས་པ་ལ་གཉིས། དྲི་མ་གློ་བུར་བར་ཡོད་པ་མདོར་བསྟན་པ་དང༌། སོ་སོའི་རང་བཞིན་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 12:
གཉིས་པ་ལ་གཉིས། མིང་གི་དབྱེ་བ་དང༌། སོ་སོའི་མཚན་ཉིད་དོ། །
Enumeration Block 13:
གཉིས་པ་ལ་བཞི། དུག་གསུམ་གྱི་བག་ལ་ཉལ་དང་མངོན་གྱུར་བཤད་པ་དང༌། མ་རིག་བག་ཆགས་ཀྱི་ས་བཤད་པ་དང༌། མཐོང་སྤང་དང་སྒོམ་སྤང་བཤད་པ་དང༌། མ་དག་པ་དང་དག་པའི་ས་ལ་བརྟེན་པའི་དྲི་མ་བཤད་པའོ། །
Enumeration Block 14:
གསུམ་པ་ལ་གཉིས། སྤྱིའི་དོན་དང༌། ཡན་ལག་གི་དོན་ནོ། །དང་པོ་ལ་ལྔ། སྒྲིབ་པ་གཉིས་ཀྱི་མཚན་ཉིད་དང༌། མཚན་གཞི་ངོས་བཟུང་བ་དང༌། མཐོང་སྤངས་དང་སྒོམ་སྤངས་ཀྱི་ཁྱད་པར་དང༌། ས་བོན་སྤོང་ཚུལ་གྱི་ཕྱོགས་ཙམ་བཤད་པ་དང༌། མཐོང་ལམ་ཤེས་བཟོད་བྱེ་བྲག་ཏུ་བཤད་པའོ། །
Enumeration Block 15:
གསུམ་པ་དོན་བསྡུ་བ་ལ་གཉིས། རྩ་བ་དང༌། གསལ་བའི་དབྱེ་བ་མཐའ་ཡས་པར་བསྟན་པའོ། །
Enumeration Block 16:
གཉིས་པ་གང་ཟག་གང་ལ་སྒྲིབ་པ་ལ་གཉིས། རྩ་བ་དང༌། འགྲེལ་པའོ། །
Enumeration Block 17:
གསུམ་པ་ཁམས་སྒྲིབ་བྱེད་ཀྱི་དཔེ་དོན་ཆོས་མཐུན་བཤད་པ་ལ་གཉིས། སྤྱིའི་མཚམས་སྦྱར་བ་དང༌། རྩ་བའོ། །
Enumeration Block 18:
གཉིས་པ་ལ་གཉིས། རྒྱས་པར་བཤད་པ་དང༌། དོན་བསྡུ་བའོ། །དང་པོ་ལ་བཞི་ཡོད་པའི་དང་པོ་དུག་གསུམ་གྱི་བག་ལ་ཉལ་དང་ཀུན་ལྡང་དྲག་པོའི་ཆོས་མཐུན་ནི།
Enumeration Block 19:
བཞི་པ་བསྒྲིབ་བྱ་ཁམས་ཀྱི་དཔེ་དོན་ཆོས་མཐུན་བཤད་པ་ལ་གཉིས། སྤྱིར་བསྟན་པ་དང་སོ་སོར་བཤད་པའོ། །དང་པོ་ལ་གཉིས། རྩ་བ་དང༌། འགྲེལ་པའོ། །
Enumeration Block 20:
གཉིས་པ་ལ་གཉིས། དཔེ་དོན་སྤྱིར་སྦྱར་བ་དང༌། ཆོས་མཐུན་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གཉིས། དྲི་བ་དང༌། ལན་ནོ། །
Enumeration Block 21:
གཉིས་པ་ལ་གཉིས། རྩ་བ་དང༌། འགྲེལ་པའོ། །
Enumeration Block 22:
གཉིས་པ་ལ་གསུམ། ཆོས་ཀྱི་སྐུའི་ཆོས་མཐུན་བཤད་པ་དང༌། དེ་བཞིན་ཉིད་ཀྱི་ཆོས་མཐུན་བཤད་པ་དང༌། རིགས་ཀྱི་ཆོས་མཐུན་བཤད་པའོ། །དང་པོ་ལ་གཉིས། དབྱེ་བ་དང༌། ཆོས་མཐུན་བཤད་པ་དངོས་སོ། །དང་པོ་ལ་གཉིས། དྲི་བ་དང༌། ལན་ནོ། །
Enumeration Block 23:
གཉིས་པ་ལ་གཉིས། རྩ་བ་དང་། འགྲེལ་པའོ། །
Enumeration Block 24:
གཉིས་པ་ལ་གཉིས། རྩ་བ་དང༌། འགྲེལ་པའོ། །
Enumeration Block 25:
གཉིས་པ་ལ་གཉིས། དཔེ་གསུམ་གྱིས་བསྟན་པའི་ཚིག་དོན་བཤད་པ་དང༌། ཆོས་སྐུས་ཁྱབ་པ་ལུང་དང་སྦྱར་བའོ། །
Enumeration Block 26:
གཉིས་པ་ལ་གཉིས། རྩ་བ་དང༌། འགྲེལ་པའོ། །
Enumeration Block 27:
གཉིས་པ་ལ་གཉིས། ཚིག་དོན་དང༌། ལུང་དང་སྦྱར་བའོ། །
Enumeration Block 28:
གཉིས་པ་ལ་གཉིས། མདོའི་ལུང་དང༌། བསྟན་བཅོས་ཀྱི་ལུང་ངོ༌། །
Enumeration Block 29:
གསུམ་པ་ལ་གཉིས། རྩ་བ་དང༌། འགྲེལ་པའོ། །དང་པོ་ལ་གཉིས། རིགས་ཀྱི་ངོ་བོའི་དཔེ་དོན་ཆོས་མཐུན་དང༌། རིགས་ཀྱི་ནུས་པའི་དཔེ་དོན་ཆོས་མཐུན་ནོ། །
Enumeration Block 30:
གཉིས་པ་ལ་གཉིས། ནུས་པའི་དབྱེ་བ་དང༌། དཔེ་དོན་ཆོས་མཐུན་བཤད་པའོ། །
Enumeration Block 31:
གཉིས་པ་ལ་གཉིས། སངས་རྒྱས་ཀྱི་རིགས་ཡོད་པས་སངས་རྒྱས་ཀྱི་སྙིང་པོ་ཅན་དུ་བཤད་པ་དང༌། ཤེས་བྱེད་ལུང་དང་སྦྱར་བའོ། །
Enumeration Block 32:
གཉིས་པ་ལ་གསུམ། མཚམས་སྦྱར་བ་དང༌། ལུང་དྲང་བ་དང༌། དེའི་དོན་མདོ་གཞན་ལ་བརྟེན་ནས་བཤད་པའོ། །
Enumeration Block 33:
གསུམ་པ་ཁམས་རྟོགས་བྱེད་ཀྱི་ཡུལ་ཅན་བཤད་པ་ལ་གཉིས། ཉན་ཐོས་དང་རང་སངས་རྒྱས་རྣམས་ཀྱིས་ཀྱང་ཁམས་དད་པས་རྟོགས་པར་བྱ་བར་བསྟན་པ་དང༌། གང་ཟག་བཞི་པོས་རྟོགས་ཚུལ་དེ་ལས་གཞན་དུ་མི་རྟོགས་པར་བསྟན་པའོ། །དང་པོ་ལ་གཉིས། སྔ་འགྲེལ་དང༌། རྩ་བའོ། །དང་པོ་ལ་གསུམ། སེམས་ཅན་ཐམས་ཅད་དེ་བཞིན་གཤེགས་པའི་སྙིང་པོ་ཅན་དུ་བསྟན་པ་དང༌། ལུང་དང་སྦྱར་བ་དང་། དོན་བཤད་པའོ། །
Enumeration Block 34:
གཉིས་པ་ལ་གཉིས། རྩ་བ་དང༌། འགྲེལ་པའོ། །
Enumeration Block 35:
གཉིས་པ་ལ་གཉིས། མདོར་བསྟན་པ་དང༌། རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གཉིས། ཚིག་དོན་དང༌། ལུང་དང་སྦྱར་བའོ། །
Enumeration Block 36:
གཉིས་པ་ལ་གསུམ། འཇིག་ཚོགས་ལ་ལྟ་བར་ལྷུང་བས་མ་རྟོགས་པར་བསྟན་པ་དང༌། ཕྱིན་ཅི་ལོག་ལ་མངོན་པར་དགའ་བས་མ་རྟོགས་པར་བསྟན་པ་དང༌། སྟོང་པ་ཉིད་ལ་སེམས་གཡེངས་པས་མ་རྟོགས་པར་བསྟན་པའོ། །
Enumeration Block 37:
གཉིས་པ་ལ་གསུམ། ཕྱིན་ཅི་ལོག་ཏུ་ཞུགས་པའི་དོན་བཤད་པ་དང༌། དེས་ན་དེ་བཞིན་ཉིད་རྟོགས་པ་ལས་ཕྱི་རོལ་ཏུ་གྱུར་པ་དང༌། དོན་དེ་ཉིད་བསྒྲུབ་པའོ། །
Enumeration Block 38:
གསུམ་པ་ལ་གཉིས། མཚམས་སྦྱར་བ་དང༌། ལུང་དྲང་བའོ། །
Enumeration Block 39:
གཉིས་པ་ལ་གཉིས། དཔེ་དང༌། དོན་ནོ། །
Enumeration Block 40:
གསུམ་པ་ལ་གཉིས། སྤྱིར་བསྟན་པ་དང༌། སོ་སོར་བཤད་པའོ། །
Enumeration Block 41:
བཞི་པ་ཁམས་ཀྱི་རང་བཞིན་ངོས་བཟུང་བ་ལ་གཉིས། དྲི་བ་དང༌། ལན་ནོ། །
Enumeration Block 42:
གཉིས་པ་ལ་གཉིས། རྩ་བ་དང༌། སྟོང་པ་ཉིད་ངོས་བཟུང་ནས་སེམས་རྣམ་པར་གཡེངས་པའི་ཡུལ་མ་ཡིན་པར་བཤད་པའོ། །དང་པོ་ལ་གཉིས། དོན་དངོས་དང༌། སྒྲུབ་བྱེད་དགོད་པའོ། །དང་པོ་ལ་གསུམ། གཞི་དངོས་པོའི་གནས་ལུགས་དང༌། དེ་རྟོགས་པའི་ལྟ་བ་དང༌། ལྟ་བ་གོམས་པའི་འབྲས་བུའོ། །
Enumeration Block 43:
གཉིས་པ་ལ་གསུམ། གནས་ལུགས་ཀྱི་དོན་བཤད་པ་དང༌། དེ་སྟོང་པ་ཉིད་ལ་སེམས་གཡེངས་པ་དང་ཕྱིན་ཅི་ལོག་ལ་མངོན་པར་དགའ་བའི་ཡུལ་མ་ཡིན་པར་བསྟན་པ་དང༌། ས་བཅུ་ལ་ཞུགས་པའི་བྱང་ཆུབ་སེམས་དཔའ་རྣམས་ཀྱི་སྤྱོད་ཡུལ་དུ་བསྟན་པའོ། །དང་པོ་ལ་གསུམ། དངོས་ཀྱི་དོན་དང༌། ལུང་དང་སྦྱར་བ་དང༌། དོན་བསྡུ་བའོ། །
Enumeration Block 44:
གཉིས་པ་ལ་གཉིས། ཤེས་བྱེད་ཀྱི་དོན་ལུང་དང་སྦྱར་བ་དང༌། ལམ་བདེན་གྱི་རྟོགས་ཚུལ་ལུང་དང་སྦྱར་བའོ། །
Enumeration Block 45:
གཉིས་པ་ལ་གཉིས། སྟོང་པ་ཉིད་ལ་སེམས་གཡེངས་པ་སོགས་ཀྱི་ཡུལ་མ་ཡིན་པ་དང༌། དེ་དག་གི་འཐད་པའོ། །དང་པོ་ལ་གཉིས། དངོས་ཀྱི་དོན་དང༌། ལུང་དང་སྦྱར་བའོ། །
Enumeration Block 46:
གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ། དེ་བཞིན་གཤེགས་པའི་སྙིང་པོ་ཆོས་ཀྱི་སྐུའི་སྙིང་པོར་བསྟན་པས་འཇིག་ཚོགས་ལ་ལྟ་བར་ལྷུང་བའི་ཡུལ་མ་ཡིན་པར་བསྟན་པ་ནི།
Enumeration Block 47:
གསུམ་པ་ལ་གཉིས། དངོས་ཀྱི་དོན་དང༌། ལུང་དང་སྦྱར་བའོ། །
