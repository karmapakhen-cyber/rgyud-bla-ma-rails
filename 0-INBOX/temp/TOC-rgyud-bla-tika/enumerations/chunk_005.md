Enumeration Block 1:
གཉིས་པ་ལ་གསུམ། བསྟན་པ་དང། བཤད་པ་དང། དོན་བསྡུ་བའོ། །
Enumeration Block 2:
གཉིས་པ་སྒྲིབ་པའི་གཉེན་པོ་རྒྱུའི་རང་བཞིན་བྱེ་བྲག་ཏུ་བཤད་པ་ལ་གཉིས། མཚམས་སྦྱར་བ་དང། རྩ་བའོ། །
Enumeration Block 3:
གཉིས་པ་འབྲས་བུ་དང་ལས་ཀྱི་དོན་བཤད་པ་ལ་གསུམ། མཚམས་སྦྱར་བ་དང། མདོར་བསྟན་པ་དང། རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གཉིས། འབྲས་བུ་བསྟན་པ་དང། བྱེད་ལས་བསྟན་པའོ། །
Enumeration Block 5:
གསུམ་པ་ལ་གཉིས། འབྲས་བུའི་དོན་རྒྱས་པར་བཤད་པ་དང། ལས་ཀྱི་དོན་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གཉིས། དྲི་བ་དང། ལན་ནོ། །
Enumeration Block 6:
གཉིས་པ་ལ་གསུམ། གཉེན་པོ་བཞིས་ཐོབ་པའི་འབྲས་བུའི་མཚན་ཉིད་སྤྱིར་བཤད་པ་དང། འབྲས་བུ་བཞིའི་མཚན་ཉིད་སོ་སོར་བཤད་པ་དང། བྱང་ཆུབ་སེམས་དཔའི་རྒྱུད་ཀྱི་སྟོང་ཉིད་རྟོགས་པའི་ཤེས་རབ་དང་སྙིང་རྗེ་ཆོས་སྐུའི་རྩ་བར་བསྟན་པའོ། །དང་པོ་ལ་གཉིས། རྩ་བ་དང། འགྲེལ་པའོ། །
Enumeration Block 7:
གཉིས་པ་ལ་གཉིས། མདོར་བསྟན་པ་དང། རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 8:
གཉིས་པ་ལ་གསུམ། ཕྱིན་ཅི་ལོག་དང་དེ་གཉེན་པོས་སྤངས་པའི་འབྲས་བུ་བཤད་པ་དང། རྒྱུ་འབྲས་སྦྱར་ཏེ་བཤད་པ་དང། གང་ཟག་གསུམ་གྱིས་ཆོས་སྐུ་ཐོབ་པའི་གེགས་བྱེ་བྲག་ཏུ་བཤད་པའོ། །དང་པོ་ལ་གཉིས། དངོས་ཀྱི་དོན་དང། ལུང་དང་སྦྱར་བའོ། །དང་པོ་ལ་གསུམ། ཀུན་རྫོབ་པའི་སྡོད་ལུགས་ལ་ལྟོས་པའི་ཕྱིན་ཅི་ལོག་དང། དོན་དམ་པའི་སྡོད་ལུགས་ལ་ལྟོས་པའི་ཕྱིན་ཅི་ལོག་དང། དེ་སྤངས་པའི་འབྲས་བུའི་དབྱེ་བའོ། །
Enumeration Block 9:
གཉིས་པ་ལ་གསུམ། རྟག་སོགས་ཕྱིན་ཅི་ལོག་བཞི་ལུང་དང་སྦྱར་བ་དང། མི་རྟག་སོགས་བཞི་བདེན་པར་ཞེན་པ་ལུང་དང་སྦྱར་བ་དང། གཉེན་པོ་ལུང་དང་སྦྱར་བའོ། །
Enumeration Block 10:
གཉིས་པ་རྒྱུ་འབྲས་སྦྱར་ཏེ་བཤད་པ་ལ་གཉིས། སོ་སོར་བཤད་པ་དང། བསྡུས་ཏེ་བསྟན་པའོ། །དང་པོ་ལ་གསུམ། མདོར་བསྟན་པ་དང། རྒྱས་པར་བཤད་པ་དང༌། དོན་བསྡུ་བའོ། །
Enumeration Block 11:
གཉིས་པ་ལ་བཞི། གཙང་བའི་ཕ་རོལ་ཏུ་ཕྱིན་པ་ཐེག་པ་ཆེན་པོའི་ཆོས་ལ་མོས་པའི་རྒྱུ་དང་སྦྱར་ཏེ་བཤད་པ་དང། བདག་དམ་པའི་ཕ་རོལ་ཏུ་ཕྱིན་པ་ཤེར་ཕྱིན་སྒོམ་པའི་འབྲས་བུར་བསྟན་པ་དང། བདེ་བ་དམ་པའི་ཕ་རོལ་ཏུ་ཕྱིན་པ་བསམ་གཏན་གྱི་ཕར་ཕྱིན་སྒོམ་པའི་འབྲས་བུར་བསྟན་པ་དང། རྟག་པའི་ཕ་རོལ་ཏུ་ཕྱིན་པ་སྙིང་རྗེ་ཆེན་པོ་སྒོམ་པའི་འབྲས་བུར་བསྟན་པའོ། །
Enumeration Block 12:
གཉིས་པ་ལ་གཉིས། དངོས་ཀྱི་དོན་དང། བདག་དམ་པའི་དོན་བྱེ་བྲག་ཏུ་བཤད་པའོ། །
Enumeration Block 13:
གསུམ་པ་གང་ཟག་གསུམ་གྱིས་ཆོས་སྐུ་ཐོབ་པའི་གེགས་བྱེ་བྲག་ཏུ་བཤད་པ་ལ་གསུམ། དངོས་ཀྱི་དོན་དང། ལུང་དང་སྦྱར་བ་དང། དེ་བཞིན་གཤེགས་པའི་ཆོས་སྐུ་འབའ་ཞིག་ཕར་ཕྱིན་བཞི་ལྡན་དུ་བསྟན་པའོ། །དང་པོ་ལ་གསུམ། ཆོས་སྐུ་ཐོབ་པའི་གེགས་ཀྱི་དབྱེ་བ་དང། གེགས་ཀྱི་རང་བཞིན་བཤད་པ་དང། གང་ཟག་གསུམ་གྱིས་འབྲས་བུ་ཐོབ་པ་ལ་གེགས་བྱེད་པའི་ཚུལ་ལོ། །
Enumeration Block 14:
གཉིས་པ་ལ་བཞི་ཡོད་པའི་དང་པོ་ནི།
Enumeration Block 15:
གཉིས་པ་འབྲས་བུ་བཞིའི་མཚན་ཉིད་སོ་སོར་བཤད་པ་ལ་གཉིས། རྩ་བ་དང། འགྲེལ་པའོ། །
Enumeration Block 16:
གསུམ་པ་བྱང་ཆུབ་སེམས་དཔའི་རྒྱུད་ཀྱི་སྟོང་ཉིད་རྟོགས་པའི་ཤེས་རབ་དང་སྙིང་རྗེ་ཆེན་པོ་ཆོས་སྐུའི་རྩ་བར་བསྟན་པ་ལ་གསུམ། སྔ་འགྲེལ་དང། མཚམས་སྦྱར་བ་དང། རྩ་བས་བསྟན་པའོ། །
Enumeration Block 17:
གཉིས་པ་ལས་ཀྱི་དོན་རྒྱས་པར་བཤད་པ་ལ་གཉིས། དྲི་བ་དང་། ལན་ནོ། །
Enumeration Block 18:
གཉིས་པ་ལ་གཉིས། སྒྲུབ་བྱེད་འཕེན་པའི་ཐལ་འགྱུར་དང༌། རྗེས་སུ་འགྲོ་ལྡོག་གི་སྒོ་ནས་དེ་བསྒྲུབ་པའོ། །དང་པོ་ལ་གཉིས། རྩ་བ་དང། འགྲེལ་པའོ། །
Enumeration Block 19:
གཉིས་པ་ལ་གཉིས། ཤེས་བྱེད་དགོད་པ་དང། ཚིག་དོན་བཤད་པའོ། །
Enumeration Block 20:
གཉིས་པ་ལ་གཉིས། རྩ་བ་དང༌། འགྲེལ་པའོ། །
Enumeration Block 21:
གཉིས་པ་ལ་གསུམ། རིགས་ཡོད་པར་རྗེས་སུ་འགྲོ་ལྡོག་གི་སྒོ་ནས་བསྒྲུབ་པ་དང། དེའི་ཡང་སྒྲུབ་བྱེད་ཀྱི་ཐལ་འགྱུར་དང། ཐར་པ་ཐོབ་མི་སྲིད་པའི་གང་ཟག་མདོ་ལས་བཤད་པ་དགོངས་པ་ཅན་དུ་བསྒྲུབ་པའོ། །
Enumeration Block 22:
གསུམ་པ་ལ་གཉིས། ལུང་དང་སྦྱར་བ་དང། དགོངས་པ་ཅན་དུ་སྒྲུབ་པའི་ཚུལ་ལོ། །
Enumeration Block 23:
གཉིས་པ་ལ་གསུམ། དགོངས་ཏེ་གསུངས་པའི་དགོས་པ་དགོངས་གཞི་དང་བཅས་པ་དང། སྒྲས་ཟིན་གྱི་དོན་ལ་གནོད་བྱེད་བསྟན་པ་དང། གནོད་བྱེད་ལུང་དང་སྦྱར་བའོ། །
Enumeration Block 24:
འདི་ལ་གཉིས། གཞན་གྱི་ལུགས་དགག་པ་དང༌། རང་གི་ལུགས་རྣམ་པར་བཞག་པའོ། །
Enumeration Block 25:
གསུམ་པ་ལ་གཉིས། མཚམས་སྦྱར་བ་དང༌། ལུང་དགོད་པའོ། །
Enumeration Block 26:
གསུམ་པ་ལྡན་པའི་དོན་བཤད་པ་ལ་གསུམ། མཚམས་སྦྱར་བ་དང༌། མདོར་བསྟན་པ་དང༌། རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 27:
གཉིས་པ་ལ་གཉིས། རྒྱུའི་ཡོན་ཏན་དང་ལྡན་པ་དང༌། འབྲས་བུའི་ཡོན་ཏན་དང་ལྡན་པའོ། །
Enumeration Block 28:
གཉིས་པ་ལ་གཉིས། རྒྱུའི་ཡོན་ཏན་དང་ལྡན་པ་དང་། འབྲས་བུའི་ཡོན་ཏན་དང་ལྡན་པ་བཤད་པའོ། །དང་པོ་ལ་གཉིས། དྲི་བ་དང༌། ལན་ནོ། །
Enumeration Block 29:
གཉིས་པ་ལ་གཉིས། རྩ་བ་དང༌། འགྲེལ་པའོ། །
Enumeration Block 30:
གཉིས་པ་ལ་གཉིས། བསྟན་པ་དང༌། བཤད་པའོ། །
Enumeration Block 31:
གཉིས་པ་ལ་གསུམ། ཡོན་ཏན་གྱི་དབྱེ་བ་དང༌། སོ་སོར་བཤད་པ་དང༌། དཔེ་དོན་ཆོས་མཐུན་སྦྱར་བའོ། །
Enumeration Block 32:
གཉིས་པ་ལ་གཉིས། དྲི་བ་དང༌། ལན་ནོ། །
Enumeration Block 33:
གཉིས་པ་ལ་གཉིས། རྩ་བ་དང༌། འགྲེལ་པའོ། །
Enumeration Block 34:
གཉིས་པ་ལ་གཉིས། དངོས་ཀྱི་དོན་དང༌། ལུང་དང་སྦྱར་བའོ། །དང་པོ་ལ་གསུམ། མདོར་བསྟན་པ་དང༌། རྒྱས་པར་བཤད་པ་དང༌། དོན་བསྡུ་བའོ། །
Enumeration Block 35:
གཉིས་པ་ལ་གཉིས། ཡོན་ཏན་གྱི་དབྱེ་བ་དང༌། དཔེ་དོན་ཆོས་མཐུན་སྦྱར་བའོ། །
Enumeration Block 36:
བཞི་པ་འཇུག་པའི་རབ་དབྱེ་བཤད་པ་ལ་གཉིས། དངོས་ཀྱི་དོན་དང༌། དེའི་ཡན་ལག་གོ ། དང་པོ་ལ་གསུམ། མཚམས་སྦྱར་བ་དང༌། བསྟན་པ་དང༌། བཤད་པའོ། །
