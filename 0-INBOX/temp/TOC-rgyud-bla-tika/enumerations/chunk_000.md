Enumeration Block 1:
ཐེག་པ་ཆེན་པོ་རྒྱུད་བླ་མའི་བསྟན་བཅོས་འགྲེལ་པ་དང་བཅས་པ་འཆད་པ་ལ་དོན་བཞི་སྟེ། མཚན་གྱི་དོན་དང༌། འགྱུར་གྱི་ཕྱག་དང༌། གཞུང་གི་དོན་དང༌། མཇུག་གི་དོན་ཏོ། །དང་པོ་ལ་གཉིས། མཚན་བསྒྱུར་བ་དང༌། མཚན་བཤད་པའོ། །
Enumeration Block 2:
གསུམ་པ་ལ་གཉིས། བཤད་པ་ཉེ་བར་དགོད་པ་དང༌། བཤད་པ་མཐར་ཕྱིན་པའི་ཡན་ལག་གོ ། དང་པོ་ལ་གཉིས། ལུས་རྣམ་པར་བཞག་པ་དང༌། ཡན་ལག་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གསུམ། ལུས་ཀྱི་རང་བཞིན་དང༌། མདོ་ལས་ཇི་ལྟར་བསྟན་པ་དང༌། གོ་རིམས་ངེས་པའོ། །དང་པོ་ལ་གཉིས། སྤྱིའི་དོན་དང༌། ཡན་ལག་གི་དོན་ཏོ། །དང་པོ་ལ་གསུམ། རྡོ་རྗེ་ལྟ་བུའི་གནས་བདུན་གྱི་ངོ་བོ་ངོས་བཟུང་བ་དང༌། གྲངས་ངེས་པ་དང༌། དོགས་པ་བཅད་པའོ། །
Enumeration Block 3:
གཉིས་པ་ལ་གཉིས། རྩ་བ་དང༌། འགྲེལ་པའོ། །དང་པོ་ལ། ངོ་བོ་ངོས་བཟུང་བ་དང༌། གྲངས་བདུན་དུ་བསྟན་པའོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གཉིས། རྒྱས་པར་བཤད་པ་དང་། དོན་བསྡུ་བའོ། །དང་པོ་ལ་གསུམ། རྡོ་རྗེ་ལྟ་བུ་དང་དེའི་གནས་ཀྱི་སྒྲ་བཤད་པའི་རྒྱུ་མཚན་དང༌། སྒྲ་འཇུག་པའི་གཞི་ངོས་བཟུང་བ་དང༌། རྟོགས་པར་དཀའ་བ་ལུང་དང་སྦྱར་བའོ། །དང་པོ་ལ་གསུམ། བསྟན་པ་དང༌། བཤད་པ་དང༌། དོན་བསྡུ་བའོ། །
Enumeration Block 5:
གཉིས་པ་ལ་གཉིས། དྲི་བ་དང༌། ལན་ནོ། །
Enumeration Block 6:
གསུམ་པ་ལ་གཉིས། མཚམས་སྦྱར་བ་དང༌། ལུང་དང་སྦྱར་བ་དངོས་སོ། །
Enumeration Block 7:
གཉིས་པ་ལ་གཉིས། དཀོན་མཆོག་གསུམ་ལུང་དང་སྦྱར་བ་དང༌། ལྷག་མ་བཞི་ལུང་དང་སྦྱར་བའོ། །
Enumeration Block 8:
གཉིས་པ་ལ་གཉིས། ཁམས་ལུང་དང་སྦྱར་བ་དང༌། བྱང་ཆུབ་སོགས་གསུམ་ལུང་དང་སྦྱར་བའོ། །དང་པོ་ལ་གསུམ། རྟག་ཏུ་དེ་བཞིན་གཤེགས་པ་ཉག་གཅིག་གི་ཡུལ་དུ་བསྟན་པ་དང༌། དེ་ལས་གཞན་གྱི་གཏན་དུ་བའི་ཡུལ་མ་ཡིན་པ་དང༌། དོན་དམ་པའི་རང་བཞིན་ངོས་བཟུང་བའོ། །
Enumeration Block 9:
གཉིས་པ་ལ་གསུམ། རྩ་བ་དང༌། འགྲེལ་པ་དང༌། དོན་བསྡུ་᪠འོ། །
Enumeration Block 10:
གཉིས་པ་ལ་གཉིས། འབྲས་བུ་དཀོན་མཆོག་གསུམ་ཇི་ལྟར་བསྟན་པ་དང༌། ལྷག་མ་བཞི་ཇི་ལྟར་བསྟན་པའོ། །དང་པོ་ལ་གཉིས། ཚིག་དོན་ཙམ་བཤད་པ་དང༌། ལུང་དང་སྦྱར་བའོ། །
Enumeration Block 11:
གཉིས་པ་ལ་གཉིས། རང་གི་ངོ་བོ་འགྲུབ་པའི་ཚུལ་ལུང་དང་སྦྱར་བ་དང༌། ཡོན་ཏན་ལུང་དང་སྦྱར་བའོ། །དང་པོ་ལ་གསུམ། མདོར་བསྟན་པ་དང༌། ཞར་ལ་རྒྱུ་རྐྱེན་ངོས་བཟུང་བ་དང༌། རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 12:
གསུམ་པ་ལ་གཉིས། ཉེ་རྒྱུ་དག་པ་ས་གསུམ་ལ་དཀོན་མཆོག་གསུམ་རིམ་གྱིས་འགྲུབ་པའི་ཚུལ་དང༌། དགེ་འདུན་དཀོན་མཆོག་ཁྱད་པར་དུ་བཤད་པའོ། །
Enumeration Block 13:
གཉིས་པ་ལ་གཉིས། རྒྱ་ཆེ་བའི་ཡོན་ཏན་ལུང་དང་སྦྱར་བ་དང༌། ཟབ་པའི་ཡོན་ཏན་ལུང་དང་སྦྱར་བའོ། །
