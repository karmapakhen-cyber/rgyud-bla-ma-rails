Enumeration Block 1:
བཞི་པ་ཁམས་ཀྱི་རང་བཞིན་ངོས་བཟུང་བ་ལ་གཉིས། དྲི་བ་དང༌། ལན་ནོ། །
Enumeration Block 2:
གཉིས་པ་ལ་གཉིས། རྩ་བ་དང༌། སྟོང་པ་ཉིད་ངོས་བཟུང་ནས་སེམས་རྣམ་པར་གཡེངས་པའི་ཡུལ་མ་ཡིན་པར་བཤད་པའོ། །དང་པོ་ལ་གཉིས། དོན་དངོས་དང༌། སྒྲུབ་བྱེད་དགོད་པའོ། །དང་པོ་ལ་གསུམ། གཞི་དངོས་པོའི་གནས་ལུགས་དང༌། དེ་རྟོགས་པའི་ལྟ་བ་དང༌། ལྟ་བ་གོམས་པའི་འབྲས་བུའོ། །
Enumeration Block 3:
གཉིས་པ་ལ་གསུམ། གནས་ལུགས་ཀྱི་དོན་བཤད་པ་དང༌། དེ་སྟོང་པ་ཉིད་ལ་སེམས་གཡེངས་པ་དང་ཕྱིན་ཅི་ལོག་ལ་མངོན་པར་དགའ་བའི་ཡུལ་མ་ཡིན་པར་བསྟན་པ་དང༌། ས་བཅུ་ལ་ཞུགས་པའི་བྱང་ཆུབ་སེམས་དཔའ་རྣམས་ཀྱི་སྤྱོད་ཡུལ་དུ་བསྟན་པའོ། །དང་པོ་ལ་གསུམ། དངོས་ཀྱི་དོན་དང༌། ལུང་དང་སྦྱར་བ་དང༌། དོན་བསྡུ་བའོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གཉིས། ཤེས་བྱེད་ཀྱི་དོན་ལུང་དང་སྦྱར་བ་དང༌། ལམ་བདེན་གྱི་རྟོགས་ཚུལ་ལུང་དང་སྦྱར་བའོ། །
Enumeration Block 5:
གཉིས་པ་ལ་གཉིས། སྟོང་པ་ཉིད་ལ་སེམས་གཡེངས་པ་སོགས་ཀྱི་ཡུལ་མ་ཡིན་པ་དང༌། དེ་དག་གི་འཐད་པའོ། །དང་པོ་ལ་གཉིས། དངོས་ཀྱི་དོན་དང༌། ལུང་དང་སྦྱར་བའོ། །
Enumeration Block 6:
གསུམ་པ་ལ་གཉིས། དངོས་ཀྱི་དོན་དང༌། ལུང་དང་སྦྱར་བའོ། །
Enumeration Block 7:
འདི་ལ་གསུམ། རྩོད་པ་དང་བསྡུས་དོན་གྱིས་མཚམས་སྦྱར་བ་དང༌། རྩོད་ལན་མདོར་བསྟན་པ་དང༌། རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གཉིས། རྩོད་པ་དང་། བསྡུས་དོན་ནོ། །
Enumeration Block 8:
གཉིས་པ་ལ་གཉིས། སྤྱིའི་དོན་དང༌། ཡན་ལག་གི་དོན་ནོ། །དང་པོ་ལ་གསུམ། མི་འཐད་པའི་ཕྱོགས་སུན་དབྱུང་བ་དང༌། འཐད་པའི་ཕྱོགས་ལེགས་པར་བཞག་པ་དང༌། དེ་ལ་རྩོད་པ་སྤང་བའོ། །དང་པོ་ལ་གསུམ། ཁམས་རྟག་དངོས་གསུངས་པའི་དགོས་པ་སྟོན་པའི་གཞུང་དུ་འཆད་པ་རྣར་མི་འོང་བའི་ཚིག་ཡིན་པ་དང༌། དེ་བཞིན་གཤེགས་པའི་སྙིང་པོའི་མདོ་དྲང་དོན་དུ་གསུངས་པའི་རྒྱུ་མཚན་སྟོན་པར་འཆད་པ་འབྲེལ་བ་དང༌། འཁོར་ལོ་བར་པ་དྲང་དོན་དུ་སྒྲུབ་པའི་རྣམ་རིག་པའི་ལུགས་སུ་འཆད་པ་དགོངས་པ་མ་ཡིན་པའོ། །
Enumeration Block 9:
གཉིས་པ་ཡན་ལག་གི་དོན་ལ་གཉིས། རྩོད་པ་དང༌། ལན་ནོ། །
Enumeration Block 10:
གཉིས་པ་ལ་གཉིས། མཚམས་སྦྱར་བ་དང༌། རྩ་བའོ། །
Enumeration Block 11:
གཉིས་པ་ལ་གཉིས། སྔ་ཕྱི་མི་འགལ་བའི་དོན་བཤད་པ་དང༌། ཁམས་ཡོད་པར་གསུངས་པའི་དགོས་པ་བཤད་པའོ། །
Enumeration Block 12:
གཉིས་པ་ལ་གཉིས། མདོར་བསྟན་པ་དང༌། རྒྱས་བཤད་དོ། །
Enumeration Block 13:
གཉིས་པ་ལ་གཉིས། སོ་སོར་བཤད་པ་དང༌། ཉེས་པ་ལྔ་དང་བྲལ་བའི་ཕན་ཡོན་བསྡུས་ཏེ་བསྟན་པའོ། །
དང་པོ་ལ་བཞི། བྱང་ཆུབ་ཀྱི་མཆོག་ཏུ་སེམས་བསྐྱེད་པའི་གེགས་དང༌། སྤྱོད་པ་ཉམས་སུ་ལེན་པའི་གེགས་དང༌། སྤྱོད་པའི་ཁྱད་པར་གནས་ལུགས་ཀྱི་དོན་རྟོགས་པའི་གེགས་དང༌། སེམས་བསྐྱེད་ཀྱི་རྒྱུ་བྱམས་སྙིང་རྗེ་སྐྱེ་བའི་གེགས་སོ། །
Enumeration Block 14:
གསུམ་པ་ལ་གཉིས། དེ་ལྟར་མ་རྟོགས་ན་ཉེས་པས་ཟིན་པར་འགྱུར་བ་དང༌། རྟོགས་པའི་ཐབས་སོ། །
Enumeration Block 15:
གཉིས་པ་ལ་གཉིས། ལྡོག་པ་དང༌། རྗེས་འགྲོའོ། །
Enumeration Block 16:
གཉིས་པ་བྱང་ཆུབ་སོགས་བཤད་པ་ལ་གསུམ། དག་པ་གཉིས་ལྡན་གྱི་བྱང་ཆུབ་བཤད་པ་དང༌། དེ་ལ་བརྟེན་པའི་ཡོན་ཏན་བཤད་པ་དང༌། ཡོན་ཏན་ལ་བརྟེན་པའི་འཕྲིན་ལས་བཤད་པའོ། །དང་པོ་ལ་གསུམ། མཚམས་སྦྱར་བ་དང༌། དོན་བཤད་པ་དང༌། ལེའུའི་མཚན་བསྟན་པའོ། །
Enumeration Block 17:
གཉིས་པ་ལ་གཉིས། མདོར་བསྟན་པ་དང༌། རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གཉིས། དོན་བརྒྱད་ཀྱི་སྒོ་ནས་དབྱེ་བ་དང༌། དེ་ཉིད་སྡོམ་དུ་བསྡུ་བའོ། །དང་པོ་ལ་གཉིས། དྲི་བ་དང༌། ལན་ནོ། །
Enumeration Block 18:
གཉིས་པ་ལ་གཉིས། རྩ་བ་དང༌། འགྲེལ་པའོ། །
Enumeration Block 19:
གཉིས་པ་ལ་གཉིས། མིང་གི་དབྱེ་བ་དང༌། དོན་སོ་སོར་བཤད་པའོ། །
Enumeration Block 20:
གཉིས་པ་ལ་ལྔ། ངོ་བོ་དང་རྒྱུའི་དོན་བཤད་པ་དང༌། འབྲས་བུའི་དོན་བཤད་པ་དང༌། ལས་ཀྱི་དོན་བཤད་པ་དང༌། ལྡན་པའི་དོན་བཤད་པ་དང༌། འཇུག་པའི་རབ་དབྱེ་བཤད་པའོ། །དང་པོ་ལ་གསུམ། མཚམས་སྦྱར་བ་དང༌། བསྟན་པ་དང༌། བཤད་པའོ། །
Enumeration Block 21:
གཉིས་པ་ལ་གཉིས། བྱང་ཆུབ་ཀྱི་ངོ་བོ་དང༌། དེ་ཐོབ་པར་བྱེད་པའི་རྒྱུའོ། །དང་པོ་ལ་གཉིས། རང་བཞིན་རྣམ་དག་བཤད་པ་དང༌། གློ་བུར་རྣམ་དག་བཤད་པའོ། །
Enumeration Block 22:
གཉིས་པ་ལ་གསུམ། མཚམས་སྦྱར་བ་དང༌། རྩ་བ་དང༌། འགྲེལ་པའོ། །
Enumeration Block 23:
གཉིས་པ་ལ་གཉིས། ངོ་བོའི་དོན་དང་། དེ་ཐོབ་བྱེད་ཀྱི་རྒྱུའོ། །དང་པོ་ལ་གཉིས། སྤྱིར་བསྟན་པ་དང༌། སོ་སོར་བཤད་པའོ། །
Enumeration Block 24:
གཉིས་པ་ལ་གཉིས། སྤངས་རྟོགས་ཀྱི་ཡོན་ཏན་དང༌། སྤང་བྱ་ངོས་བཟུང་བའོ། །
Enumeration Block 25:
གཉིས་པ་འབྲས་བུའི་དོན་བཤད་པ་ལ་གསུམ། མཚམས་སྦྱར་བ་དང༌། བསྟན་པ་དང༌། བཤད་པའོ། །
Enumeration Block 26:
གཉིས་པ་ལ་གཉིས། གནས་ལུགས་མངོན་སུམ་དུ་རྟོགས་པའི་མཉམ་གཞག་ཡེ་ཤེས་གོམས་པའི་འབྲས་བུ་ཉོན་སྒྲིབ་དང་བྲལ་བ་བཤད་པ་དང༌། རྗེས་ཐོབ་བསོད་ནམས་ཀྱི་ཚོགས་གོམས་པའི་འབྲས་བུ་ཁྱད་པར་གསུམ་དང་ལྡན་ཞིང་ཤེས་སྒྲིབ་སྤངས་པའི་གཟུགས་ཀྱི་སྐུའི་ཡོན་ཏན་བཤད་པའོ། །
Enumeration Block 27:
གསུམ་པ་ལ་གཉིས། མཚམས་སྦྱར་བ་དང༌། རྩ་བའོ། །
Enumeration Block 28:
གཉིས་པ་ལ་གསུམ། ཡེ་ཤེས་གཉིས་ཀྱི་ནུས་པ་འཇུག་པའི་ཡུལ་སྤྱིར་བསྟན་པ་དང༌། མཉམ་གཞག་གི་འབྲས་བུའི་དཔེ་དོན་ཆོས་མཐུན་བཤད་པ་དང༌། རྗེས་ཐོབ་ཀྱི་འབྲས་བུའི་དཔེ་དོན་ཆོས་མཐུན་བཤད་པའོ། །
Enumeration Block 29:
གསུམ་པ་ལས་ཀྱི་དོན་བཤད་པ་ལ་གཉིས། ལས་སྒྲུབ་བྱེད་ཀྱི་དོན་གཉིས་ཕུན་ཚོགས་བཤད་པ་དང༌། ལས་ཀྱི་ངོ་བོ་བཤད་པའོ། །
Enumeration Block 30:
གཉིས་པ་ལ་གསུམ། མཚམས་སྦྱར་བ་དང༌། བསྟན་པ་དང༌། བཤད་པའོ། །
Enumeration Block 31:
གཉིས་པ་ལ་གཉིས། རང་དོན་ཆོས་ཀྱི་སྐུ་བཤད་པ་དང༌། གཞན་དོན་གཟུགས་ཀྱི་སྐུ་བཤད་པའོ། །
Enumeration Block 32:
གསུམ་པ་ལ་གཉིས། མཚམས་སྦྱར་བ་དང༌། རྩ་བའོ། །
Enumeration Block 33:
གཉིས་པ་ལ་གསུམ། ཡེ་ཤེས་གཉིས་ཀྱི་ནུས་པ་འཇུག་པའི་ཡུལ་ངོས་བཟུང་བ་དང༌། ཆོས་ཀྱི་སྐུ་བཤད་པ་དང༌། གཟུགས་ཀྱི་སྐུ་བཤད་པའོ། །
Enumeration Block 34:
གཉིས་པ་ལ་གཉིས། སྤྱིར་བསྟན་པ་དང༌། སོ་སོར་བཤད་པའོ། །
Enumeration Block 35:
གཉིས་པ་ལ་གཉིས། སྤངས་པ་དང་རྟོགས་པ་བཤད་པ་དང༌། དེ་ལ་བརྟེན་པའི་ཡོན་ཏན་བཤད་པའོ། །
Enumeration Block 36:
གཉིས་པ་ལ་གཉིས། བསྟན་པ་དང༌། དེ་བསྒྲུབ་པའོ། །
Enumeration Block 37:
གཉིས་པ་ལ་གཉིས། དཔེ་དང༌། དོན་ནོ། །
Enumeration Block 38:
བཞི་པ་ལྡན་པའི་ཡོན་ཏན་བཤད་པ་ལ་གཉིས། ཀུན་རྫོབ་པའི་ཡོན་ཏན་ཁོ་ན་དང་ལྡན་པ་དགག་པ་དང༌། དོན་དམ་པའི་ཡོན་ཏན་དང་ལྡན་པར་བསྒྲུབ་པའོ། །
Enumeration Block 39:
གཉིས་པ་ལ་གསུམ། མཚམས་སྦྱར་བ་དང༌། བསྟན་པ་དང༌། བཤད་པའོ། །
Enumeration Block 40:
གསུམ་པ་ལ་གཉིས། མཚམས་སྦྱར་བ་དང་། རྩ་བའོ། །
Enumeration Block 41:
གཉིས་པ་ལ་གཉིས། ཡོན་ཏན་གྱི་རྟེན་ངོས་བཟུང་བ་དང༌། ཡོན་ཏན་ཉིད་བཤད་པའོ། །
Enumeration Block 42:
གཉིས་པ་ལ་གཉིས། སྤངས་པས་རབ་ཏུ་ཕྱེ་བའི་ཡོན་ཏན་དང་རང་བཞིན་དུ་གནས་པའི་ཡོན་ཏན་ནོ། །དང་པོ་ལ་ལྔ། ཟབ་པའི་ཁྱད་པར་དང༌། རྟག་པའི་ཁྱད་པར་དང༌། བདེ་བའི་ཁྱད་པར་དང༌། ཡེ་ཤེས་ཀྱི་ཁྱད་པར་དང༌། སྤངས་པའི་ཁྱད་པར་རོ། །དང་པོ་ལ་གཉིས། དུས་ཐམས་ཅད་དུ་མངོན་སུམ་དུ་རྟོགས་པ་སངས་རྒྱས་འབའ་ཞིག་གི་ཁྱད་པར་དུ་བསྟན་པ་དང༌། གཞན་གྱིས་དེ་ལྟར་རྟོགས་མི་ནུས་པའོ། །
Enumeration Block 43:
ལྔ་པ་འཇུག་པའི་རབ་དབྱེ་ལ་གཉིས། སྤྱིའི་མཚམས་སྦྱར་བ་དང༌། དོན་སོ་སོར་བཤད་པའོ། །
Enumeration Block 44:
གཉིས་པ་ལ་གསུམ། སྐུ་གསུམ་གྱི་འཇུག་པའི་རབ་དབྱེ་དང༌། རྟག་པའི་ཁྱད་པར་དང༌། བསམ་གྱིས་མི་ཁྱབ་པའི་ཁྱད་པར་རོ། །དང་པོ་ལ་གཉིས། མཚམས་སྦྱར་བ་དང༌། དོན་བཤད་པའོ། །
Enumeration Block 45:
