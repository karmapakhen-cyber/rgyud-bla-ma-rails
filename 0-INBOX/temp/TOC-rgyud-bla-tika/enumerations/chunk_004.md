Enumeration Block 1:
བཞི་པ་རྒྱལ་བའི་མཛད་པ་རྟོགས་པར་དཀའ་བ་ལ་གཉིས། དངོས་ཀྱི་དོན་དང། ལུང་དང་སྦྱར་བའོ། །
Enumeration Block 2:
གསུམ་པ་རྒྱུ་རྐྱེན་སོ་སོར་རྣམ་པར་བཞག་པ་ལ་གཉིས། རྩ་བ་དང། འགྲེལ་པའོ། །
Enumeration Block 3:
གཉིས་པ་ལ་གཉིས། རྒྱུ་རྐྱེན་ངོས་བཟུང་བ་དང། རྒྱུ་རྐྱེན་དུ་འགྱུར་བའི་ཚུལ་ལོ། །
Enumeration Block 4:
གཉིས་པ་སོ་སོའི་རྣམ་པར་དབྱེ་བ་ལ་གཉིས། རྒྱུའི་གནས་སྐབས་ཁམས་དེ་བཞིན་གཤེགས་པའི་སྙིང་པོ་བཤད་པ་དང། བྱང་ཆུབ་ལ་སོགས་པ་གསུམ་བཤད་པའོ། །དང་པོ་ལ་གསུམ། མཚམས་སྦྱར་བ་དང། དོན་དངོས་དང། ལེའུའི་མཚན་བསྟན་པའོ། །དང་པོ་ལ་གཉིས། སྤྱིའི་མཚམས་སྦྱར་བ་དང། བྱེ་བྲག་གི་མཚམས་སྦྱར་བའོ། །
Enumeration Block 5:
གཉིས་པ་ལ་གསུམ། ཁམས་དེ་བཞིན་གཤེགས་པའི་སྙིང་པོ་དོན་གསུམ་གྱིས་མདོར་བསྟན་པ་དང། སྒྲུབ་བྱེད་རྒྱས་པར་བཤད་པ་དང། སེམས་ཅན་ལ་ཁམས་ཡོད་པར་བཤད་པའི་དགོས་པ་བསྟན་པའོ། །དང་པོ་ལ་གཉིས། སྤྱིའི་དོན་དང། ཡན་ལག་གི་དོན་ནོ། །དང་པོ་ལ་གསུམ། དེ་བཞིན་གཤེགས་པའི་སྙིང་པོ་ངོས་བཟུང་བ་དང། དེ་བཞིན་གཤེགས་པའི་སྙིང་པོའི་མདོས་ཇི་ལྟར་བསྟན་པའི་ཚུལ་དང། མདོ་སྡེ་གཞན་གྱི་དགོས་པ་བཤད་པའོ། །
Enumeration Block 6:
གཉིས་པ་ཡན་ལག་གི་དོན་ལ་གཉིས། རྩ་བ་དང། འགྲེལ་པའོ། །
Enumeration Block 7:
གཉིས་པ་སྒྲུབ་བྱེད་རྒྱས་པར་བཤད་པ་ལ་བཞི། ཁམས་རང་བཞིན་གྱིས་རྣམ་པར་དག་པ་རྣམ་གཞག་བཅུས་བསྒྲུབ་པ་དང། གློ་བུར་གྱི་དྲི་མས་བསྒྲིབས་པ་དཔེ་དགུས་བསྒྲུབ་པ་དང། ཁམས་རྟོགས་བྱེད་ཀྱི་ཡུལ་ཅན་དང། ཁམས་ཀྱི་རང་བཞིན་ངོས་བཟུང་བའོ། །དང་པོ་ལ་གསུམ། སྡོམ་གྱིས་མདོར་བསྟན་པ་དང། སོ་སོའི་དོན་རྒྱས་པར་བཤད་པ་དང། དོན་བསྡུ་བའོ། །དང་པོ་ལ་གསུམ། མཚམས་སྦྱར་བ་དང། རྩ་བ་དང༌། དོན་ཚན་སོ་སོར་བཅད་པའོ། །
Enumeration Block 8:
གཉིས་པ་ལ་བཞི། ངོ་བོ་དང་རྒྱུའི་དོན་བཤད་པ་དང། འབྲས་བུ་དང་ལས་ཀྱི་དོན་བཤད་པ་དང། ལྡན་པའི་དོན་བཤད་པ་དང། འཇུག་པའི་རབ་དབྱེ་བཤད་པའོ། །དང་པོ་ལ་གསུམ། མཚམས་སྦྱར་བ་དང། མདོར་བསྟན་པ་དང། རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 9:
གཉིས་པ་ལ་གཉིས། ངོ་བོའི་དོན་དང། རྒྱུའི་དོན་ནོ། །དང་པོ་ལ་གཉིས། དཔེ་དང༌། དོན་ནོ། །
Enumeration Block 10:
གསུམ་པ་ལ་གཉིས། ངོ་བོའི་དོན་བཤད་པ་དང། རྒྱུའི་དོན་བཤད་པའོ། །དང་པོ་ལ་གཉིས། དྲི་བ་དང། ལན་ནོ། །
Enumeration Block 11:
གཉིས་པ་ལ་གཉིས། རྩ་བ་དང། འགྲེལ་པའོ། །
Enumeration Block 12:
གཉིས་པ་ལ་གཉིས། དྲི་བ་དང། ལན་ནོ། །
Enumeration Block 13:
གཉིས་པ་ལ་གཉིས། སྤྱིར་བཤད་པ་དང། སྒྲིབ་པའི་གཉེན་པོ་རྒྱུའི་རང་བཞིན་བྱེ་བྲག་ཏུ་བཤད་པའོ། །དང་པོ་ལ་གཉིས། རྩ་བ་དང། འགྲེལ་པའོ། །དང་པོ་ལ་གཉིས། སྒྲིབ་བཅས་ཀྱི་གང་ཟག་སྒྲིབ་པ་དང་བཅས་པ་བཤད་པ་དང། གཉེན་པོའི་རྒྱུའི་རང་བཞིན་བཤད་པའོ། །
Enumeration Block 14:
གཉིས་པ་ལ་གཉིས། མདོར་བསྟན་པ་དང༌། རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 15:
གཉིས་པ་ལ་གཉིས། སྒྲིབ་པ་དང་ལྡན་པའི་གང་ཟག་བཤད་པ་དང། དེ་ལ་ཡོད་པའི་སྒྲིབ་པ་བཤད་པའོ། །
དང་པོ་ལ་གཉིས། སོ་སོར་བཤད་པ་དང། དེ་ཐམས་ཅད་ཕུང་པོ་གསུམ་དུ་བསྡུ་བའོ། །དང་པོ་ལ་གསུམ། སྲིད་པའི་མཐར་ལྷུང་བ་དང། ཞི་བའི་མཐར་ལྷུང་བ་དང། སྲིད་ཞི་གཉི་གའི་མཐར་མ་ལྷུང་བའོ། །
Enumeration Block 16:
གཉིས་པ་ལ་གཉིས། སྤྱིར་བསྟན་པ་དང། སོ་སོར་བཤད་པའོ། །
Enumeration Block 17:
གཉིས་པ་ལ་གཉིས། ཐབས་མ་ཡིན་པ་ལ་ཞུགས་པ་དང། ཐབས་ལ་ཞུགས་པའོ། །
Enumeration Block 18:
གཉིས་པ་ལ་གསུམ། བསྟན་པ་དང། བཤད་པ་དང། དོན་བསྡུ་བའོ། །
Enumeration Block 19:
གཉིས་པ་སྒྲིབ་པའི་གཉེན་པོ་རྒྱུའི་རང་བཞིན་བྱེ་བྲག་ཏུ་བཤད་པ་ལ་གཉིས། མཚམས་སྦྱར་བ་དང། རྩ་བའོ། །
Enumeration Block 20:
གཉིས་པ་འབྲས་བུ་དང་ལས་ཀྱི་དོན་བཤད་པ་ལ་གསུམ། མཚམས་སྦྱར་བ་དང། མདོར་བསྟན་པ་དང། རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 21:
གཉིས་པ་ལ་གཉིས། འབྲས་བུ་བསྟན་པ་དང། བྱེད་ལས་བསྟན་པའོ། །
Enumeration Block 22:
གསུམ་པ་ལ་གཉིས། འབྲས་བུའི་དོན་རྒྱས་པར་བཤད་པ་དང། ལས་ཀྱི་དོན་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གཉིས། དྲི་བ་དང། ལན་ནོ། །
Enumeration Block 23:
གཉིས་པ་ལ་གསུམ། གཉེན་པོ་བཞིས་ཐོབ་པའི་འབྲས་བུའི་མཚན་ཉིད་སྤྱིར་བཤད་པ་དང། འབྲས་བུ་བཞིའི་མཚན་ཉིད་སོ་སོར་བཤད་པ་དང། བྱང་ཆུབ་སེམས་དཔའི་རྒྱུད་ཀྱི་སྟོང་ཉིད་རྟོགས་པའི་ཤེས་རབ་དང་སྙིང་རྗེ་ཆོས་སྐུའི་རྩ་བར་བསྟན་པའོ། །དང་པོ་ལ་གཉིས། རྩ་བ་དང། འགྲེལ་པའོ། །
Enumeration Block 24:
གཉིས་པ་ལ་གཉིས། མདོར་བསྟན་པ་དང། རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 25:
གཉིས་པ་ལ་གསུམ། ཕྱིན་ཅི་ལོག་དང་དེ་གཉེན་པོས་སྤངས་པའི་འབྲས་བུ་བཤད་པ་དང། རྒྱུ་འབྲས་སྦྱར་ཏེ་བཤད་པ་དང། གང་ཟག་གསུམ་གྱིས་ཆོས་སྐུ་ཐོབ་པའི་གེགས་བྱེ་བྲག་ཏུ་བཤད་པའོ། །དང་པོ་ལ་གཉིས། དངོས་ཀྱི་དོན་དང། ལུང་དང་སྦྱར་བའོ། །དང་པོ་ལ་གསུམ། ཀུན་རྫོབ་པའི་སྡོད་ལུགས་ལ་ལྟོས་པའི་ཕྱིན་ཅི་ལོག་དང། དོན་དམ་པའི་སྡོད་ལུགས་ལ་ལྟོས་པའི་ཕྱིན་ཅི་ལོག་དང། དེ་སྤངས་པའི་འབྲས་བུའི་དབྱེ་བའོ། །
Enumeration Block 26:
གཉིས་པ་ལ་གསུམ། རྟག་སོགས་ཕྱིན་ཅི་ལོག་བཞི་ལུང་དང་སྦྱར་བ་དང། མི་རྟག་སོགས་བཞི་བདེན་པར་ཞེན་པ་ལུང་དང་སྦྱར་བ་དང། གཉེན་པོ་ལུང་དང་སྦྱར་བའོ། །
