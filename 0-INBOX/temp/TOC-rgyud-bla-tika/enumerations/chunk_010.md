Enumeration Block 1:
གཉིས་པ་ལ་གསུམ། མཚམས་སྦྱར་བ་དང༌། བསྟན་པ་དང༌། བཤད་པའོ། །
Enumeration Block 2:
གསུམ་པ་ལ་གཉིས། མཚམས་སྦྱར་བ་དང་། རྩ་བའོ། །
Enumeration Block 3:
གཉིས་པ་ལ་གཉིས། ཡོན་ཏན་གྱི་རྟེན་ངོས་བཟུང་བ་དང༌། ཡོན་ཏན་ཉིད་བཤད་པའོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གཉིས། སྤངས་པས་རབ་ཏུ་ཕྱེ་བའི་ཡོན་ཏན་དང་རང་བཞིན་དུ་གནས་པའི་ཡོན་ཏན་ནོ། །དང་པོ་ལ་ལྔ། ཟབ་པའི་ཁྱད་པར་དང༌། རྟག་པའི་ཁྱད་པར་དང༌། བདེ་བའི་ཁྱད་པར་དང༌། ཡེ་ཤེས་ཀྱི་ཁྱད་པར་དང༌། སྤངས་པའི་ཁྱད་པར་རོ། །དང་པོ་ལ་གཉིས། དུས་ཐམས་ཅད་དུ་མངོན་སུམ་དུ་རྟོགས་པ་སངས་རྒྱས་འབའ་ཞིག་གི་ཁྱད་པར་དུ་བསྟན་པ་དང༌། གཞན་གྱིས་དེ་ལྟར་རྟོགས་མི་ནུས་པའོ། །
Enumeration Block 5:
ལྔ་པ་འཇུག་པའི་རབ་དབྱེ་ལ་གཉིས། སྤྱིའི་མཚམས་སྦྱར་བ་དང༌། དོན་སོ་སོར་བཤད་པའོ། །
Enumeration Block 6:
གཉིས་པ་ལ་གསུམ། སྐུ་གསུམ་གྱི་འཇུག་པའི་རབ་དབྱེ་དང༌། རྟག་པའི་ཁྱད་པར་དང༌། བསམ་གྱིས་མི་ཁྱབ་པའི་ཁྱད་པར་རོ། །དང་པོ་ལ་གཉིས། མཚམས་སྦྱར་བ་དང༌། དོན་བཤད་པའོ། །
Enumeration Block 7:
གཉིས་པ་ལ་གསུམ། མདོར་བསྟན་པ་དང་། རྒྱས་པར་བཤད་པ་དང༌། དོན་བསྡུ་བའོ། །དང་པོ་ལ་གཉིས། སྤྱིའི་དོན་དང༌། ཡན་ལག་གི་དོན་ནོ། །དང་པོ་ལ་གསུམ། འབྲས་བུ་འགྲུབ་པའི་དུས་མཚམས་དང༌། སྐུ་གསུམ་གྱི་ངོ་བོ་ངོས་བཟུང་བ་དང༌། དེ་ལ་ལོག་པར་རྟོག་པ་བསལ་བའོ། །
Enumeration Block 8:
གཉིས་པ་ཡན་ལག་གི་དོན་ལ་གསུམ། ཆོས་ཀྱི་སྐུ་དང༌། ལོངས་སྤྱོད་རྫོགས་པའི་སྐུ་དང༌། སྤྲུལ་པའི་སྐུའོ། །
དང་པོ་ལ་གཉིས། མཚན་ཉིད་ལྔ་ལྡན་དུ་བསྟན་པ་དང༌། ཡོན་ཏན་ལྔ་ལྡན་དུ་བསྟན་པའོ། །
Enumeration Block 9:
གཉིས་པ་ལ་གཉིས། མཚམས་སྦྱར་བ་དང༌། རྩ་བའོ། །
Enumeration Block 10:
གཉིས་པ་ལ་གཉིས། སྤྱིའི་དབྱེ་བ་དང༌། སོ་སོའི་རང་བཞིན་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གསུམ། དབྱེ་གཞི་བཤད་པ་དང༌། འབྱེད་པའི་རྒྱུ་མཚན་དང༌། དབྱེ་བའི་དོན་ནོ། །
Enumeration Block 11:
གཉིས་པ་ལ་གསུམ། ངོ་བོ་ཉིད་ཀྱི་སྐུ་དང༌། ལོངས་སྤྱོད་རྫོགས་པའི་སྐུ་དང༌། སྤྲུལ་པའི་སྐུའོ། །
དང་པོ་ལ་གསུམ། མཚན་ཉིད་དང༌། ཡོན་ཏན་གྱི་གྲངས་དང༌། དེ་དག་སོ་སོར་བཤད་པ་དང༌། ཡོན་ཏན་ལྔར་འབྱེད་པའི་རྒྱུ་མཚན་ནོ། །
Enumeration Block 12:
གཉིས་པ་ལ་གཉིས། མཚན་ཉིད་ལྔ་བཤད་པ་དང༌། ཡོན་ཏན་ལྔ་བཤད་པའོ། །
Enumeration Block 13:
གཉིས་པ་ལ་གཉིས། སོ་སོར་བཤད་པ་དང༌། བསྡུས་ཏེ་བསྟན་པའོ། །དང་པོ་ལ་གསུམ། སྐུ་མཚན་དཔེས་སྤྲས་པ་དང་གསུང་ཆོས་སྟོན་པའི་རིགས་འདྲ་རྒྱུན་མི་འཆད་པ་དང༌། མཛད་པ་རྒྱུན་མི་འཆད་ཅིང་དེ་གསུམ་ལྷུན་གྱིས་གྲུབ་པར་འཇུག་པ་དང༌། སྣ་ཚོགས་སུ་སྣང་ཡང་སྣང་བ་ལྟར་རང་བཞིན་གྱིས་མ་གྲུབ་པའོ། །
Enumeration Block 14:
གཉིས་པ་ལ་གཉིས། དངོས་དང༌། སྣ་ཚོགས་སུ་སྣང་བ་དཔེས་བསྒྲུབ་པའོ། །
Enumeration Block 15:
གསུམ་པ་ལ་གསུམ། མཆོག་གི་སྤྲུལ་པའི་སྐུའི་རང་བཞིན་དང༌། མཛད་པ་བཅུ་གཉིས་ཀྱིས་དོན་སྒྲུབ་པའི་ཚུལ་དང༌། གདུལ་བྱ་བཀྲི་བའི་རིམ་པ་བསྟན་པའོ། །
Enumeration Block 16:
གཉིས་པ་རྟག་པའི་ཁྱད་པར་བཤད་པ་ལ་གཉིས། མཚམས་སྦྱར་བ་དང༌། དོན་བཤད་པའོ། །
Enumeration Block 17:
གཉིས་པ་ལ་གཉིས། བསྟན་པ་དང༌། བཤད་པའོ། །དང་པོ་ལ་གཉིས། གཟུགས་སྐུ་རྟག་པའི་རྒྱུ་མཚན་བདུན་དང༌། ཆོས་སྐུ་རྟག་པའི་རྒྱུ་མཚན་གསུམ་མོ། །
Enumeration Block 18:
གཉིས་པ་ལ་གཉིས། མཚམས་སྦྱར་བ་དང༌། རྩ་བའོ། །
Enumeration Block 19:
གཉིས་པ་ལ་གཉིས། སོ་སོར་བཤད་པ་དང༌། དོན་བསྡུ་བའོ། །
དང་པོ་ལ་གཉིས། གཟུགས་སྐུ་རྟག་པའི་རྒྱུ་མཚན་བདུན་དང༌། ཆོས་སྐུ་རྟག་པའི་རྒྱུ་མཚན་གསུམ་མོ། །དང་པོ་ལ་གཉིས། འཇིག་རྟེན་ཡོངས་སུ་འཛིན་པའི་རྒྱུ་དང༌། མི་འདོར་བའི་རྒྱུའོ། །
Enumeration Block 20:
གསུམ་པ་བསམ་གྱིས་མི་ཁྱབ་པའི་ཁྱད་པར་བཤད་པ་ལ་གསུམ། མཚམས་སྦྱར་བ་དང༌། བསྟན་པ་དང། བཤད་པའོ། །
Enumeration Block 21:
གསུམ་པ་ལ་གཉིས། མཚམས་སྦྱར་བ་དང༌། རྩ་བའོ། །
Enumeration Block 22:
གཉིས་པ་ལ་གསུམ། བསམ་གྱིས་མི་ཁྱབ་པའི་དོན་སོ་སོར་བཤད་པ་དང༌། དེ་སྐུ་གཉིས་ལ་བསྡུས་ཏེ་སྦྱར་བ་དང༌། དོན་བསྡུ་བའོ། །
Enumeration Block 23:
གཉིས་པ་བྱང་ཆུབ་ལ་བརྟེན་པའི་ཡོན་ཏན་ལ་གསུམ། མཚམས་སྦྱར་བ་དང༌། དོན་བཤད་པ་དང་། ལེའུའི་མཚན་བསྟན་པའོ། །དང་པོ་ལ་གཉིས། བཤད་ཟིན་གྱི་མཚམས་སྦྱར་བ་དང༌། འཆད་འགྱུར་གྱི་མཚམས་སྦྱར་རོ། །
Enumeration Block 24:
གཉིས་པ་ལ་གསུམ། མདོར་བསྟན་པ་དང༌། དཔེའི་སྒོ་ནས་རྒྱས་པར་བཤད་པ་དང༌། དཔེས་བསྟན་པའི་དོན་བསྡུ་བའོ། །དང་པོ་ལ་གཉིས། རྟེན་གྱི་སྒོ་ནས་མདོར་བསྟན་པ་དང༌། བརྟེན་པའི་སྒོ་ནས་མདོར་བསྟན་པའོ། །
Enumeration Block 25:
གཉིས་པ་ལ་གཉིས། མཚམས་སྦྱར་བ་དང༌། དོན་བཤད་པའོ། །
Enumeration Block 26:
གཉིས་པ་ལ་གཉིས། དངོས་དང༌། ཤེས་བྱེད་ལུང་དང་སྦྱར་བའོ། །དང་པོ་ལ་གཉིས། སྡོམ་གྱི་སྒོ་ནས་སྤྱིར་བཤད་པ་དང༌། སོ་སོའི་དོན་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 27:
གཉིས་པ་ལ་གསུམ། བྲལ་བའི་ཡོན་ཏན་བཤད་པ་དང༌། རྣམ་སྨིན་གྱི་ཡོན་ཏན་བཤད་པ་དང༌། གྲངས་ཀྱི་སྒོ་ནས་དོན་བསྡུ་བའོ། །དང་པོ་ལ་གསུམ། སྟོབས་བཅུ་བཤད་པ་དང༌། མི་འཇིགས་པ་བཞི་བཤད་པ་དང༌། སངས་རྒྱས་ཀྱི་ཆོས་མ་འདྲེས་པ་བཅོ་བརྒྱད་བཤད་པའོ། །དང་པོ་ལ་གཉིས། མཚམས་སྦྱར་བ་དང༌། རྩ་བའོ། །
Enumeration Block 28:

Enumeration Block 29:

Enumeration Block 30:

Enumeration Block 31:
གཉིས་པ་ལ་གསུམ། བསྟན་པ་དང༌། བཤད་པ་དང༌། དཔེ་དང་སྦྱར་བའོ། །དང་པོ་ལ་གཉིས། ངོ་བོ་ངོས་བཟུང་བ་དང༌། སངས་རྒྱས་ཁོ་ནའི་ཁྱད་ཆོས་སུ་བསྟན་པའོ། །
Enumeration Block 32:
གཉིས་པ་ལ་གཉིས། མཚམས་སྦྱར་བ་དང༌། དོན་བཤད་པའོ། །
Enumeration Block 33:
གཉིས་པ་ལ་གསུམ། རྒྱས་པར་བཤད་པ་དང༌། དོན་བསྡུ་བ་དང༌། དཔེ་དོན་སྦྱར་བའོ། །
Enumeration Block 34:
གཉིས་པ་ཤེས་བྱེད་ལུང་དང་སྦྱར་བ་ལ་གསུམ། བཤད་ཟིན་གྱི་མཚམས་སྦྱར་བ་དང༌། རྩ་བ་དང༌། འགྲེལ་པའོ། །
Enumeration Block 35:

Enumeration Block 36:
གཉིས་པ་ལ་གཉིས། མདོར་བསྟན་པ་དང༌། ཆོས་མཐུན་སོ་སོར་བཤད་པའོ། །
Enumeration Block 37:
