Enumeration Block 1:
གཉིས་པ་རྒྱས་བཤད་ལ་གསུམ། སོ་སོའི་ངོ་བོ་དཔེ་དོན་སྦྱར། དགོས་པ་བརྗོད་དེ་སྐབས་དོན་བསྡུ། སླར་ཡང་བསྡུས་ཏེ་ཁྱད་པར་བཤད་པའོ། །དང་པོ་ལ་དགུསྐུ་རྣམ་འཕྲུལ་སྟོན་པ། གསུང་གདམས་ངག་བརྗོད་པ། ཐུགས་མཁྱེན་བརྩེས་ཁྱབ་ཚུལ། སྤྲུལ་པ་སྤྲོ་བ། ཡེ་ཤེས་འཇུག་ཚུལ། ཐུགས་ཀྱི་གསང་བ། གསུང་གི་གསང་བ། སྐུའི་གསང་བ། ཐུགས་རྗེ་འཇུག་ཚུལ་བཅས་ཀྱི་དཔེ་དོན་སྦྱར་བའོ། །དེའི་དང་པོ་ལ་ལྔ། དཔེ་བསྟན་པ། དོན་བཤད་པ། དཔེ་རྒྱས་བཤད། དོན་ངོས་གཟུང་བ། བསྡུས་ཏེ་སྐྱེ་འགག་མེད་ཚུལ་བསྟན་པའོ། །དང་པོ་ལའང་གསུམ། སྣང་ཚུལ། བྱེད་ལས། དོན་དུ་གྱུར་པའོ། །
Enumeration Block 2:
གཉིས་པ་དོན་བཤད་པ་ལ་གསུམ། སྣང་ཚུལ། དོན་གཉེར། མི་རྟོག་ཀྱང་དོན་བྱེད་པའོ། །
Enumeration Block 3:
གཉིས་པ་གསུང་གདམས་ངག་བརྗོད་པའི་དཔེ་སྦྱར་བ་ལ་དྲུགདཔེ་འགོད་པ། དོན་བསྟན་པ། དཔེ་དོན་གྱི་བྱེད་ལས། ཁྱད་པར་བརྗོད་པ། ཆོ་འཕྲུལ་གསུམ་དང་སྦྱར་བཤད། གསུང་གི་ནུས་པ་མི་འཇུག་པ་མི་འགལ་བའོ། །
Enumeration Block 4:
གསུམ་པ་ལ་གཉིས། རྒྱས་བཤད། དོན་བསྡུའོ། །
Enumeration Block 5:
འདིར་ཤློ་ཀ་བཞིས་ཉི་ཚེ་བ་ཡིན་མིན། ཕན་མི་ཕན། བདེ་མི་བདེ། ངེས་པར་འབྱིན་མི་འབྱིན་རྒྱས་པར་བཤད་པའོ།
Enumeration Block 6:
གསུམ་པ་ཐུགས་མཁྱེན་བརྩེས་ཁྱབ་ཚུལ་དཔེ་སྦྱར་ལ་ལྔ། སྤྲིན་གྱི་དཔེ་དོན་མདོར་བསྟན། དེ་ཉིད་རྒྱས་པར་བཤད་པ། སྣོད་ཀྱི་འགྱུར་ཚུལ། འབད་མེད་དུ་འཇུག་པ། སྡུག་བསྔལ་སེལ་བའི་ཆོས་མཐུན་སྦྱར་བའོ། །
Enumeration Block 7:
གཉིས་པ་ལ་གཉིས། དཔེ་དོན་བསྟན་པ་དང། ཆོས་མཚུངས་ཀྱི་སྒོ་ནས་དོན་བཤད་པའོ། །
Enumeration Block 8:
བཞི་པ་འབད་མེད་དུ་འཇུག་པ་ལ་གཉིས། མདོར་བསྟན། རྒྱས་བཤད་དོ།
Enumeration Block 9:
གཉིས་པ་ལ་གཉིས། དཔེ་དོན་ཆོས་མཚུངས་སུ་སྦྱར་བ་དང། ལྟོས་པ་མེད་པའི་ཚུལ་ལོ། །
Enumeration Block 10:
ལྔ་པ་ལ་གསུམ། སྡུག་བསྔལ་སེལ་བ་དངོས། འགྱུར་བར་རྟོགས་པ། བདེན་བཞིའི་ཚུལ་མཐོང་བའོ།
Enumeration Block 11:
བཞི་པ་སྤྲུལ་པ་སྤྲོ་པའི་དཔེ་སྦྱར་ལ་བཞི། དཔེ་དོན་མདོར་བསྟན་པ། དེ་བཤད་པ། མཐོང་བའི་རྒྱུ་བསྟན་པ། སྤྲུལ་སྐུའི་མཛད་པ་བཅུ་གཉིས་བཤད་པའོ། །
Enumeration Block 12:
ལྔ་པ་ཡེ་ཤེས་འཇུག་ཚུལ་གྱི་དཔེ་སྦྱར་ལ་དྲུག ། ཡེ་ཤེས་འཇུག་མི་འཇུག་བསྟན་པ། དེ་འཇུག་པའི་བྱ་བ་བཤད་པ། ཡེ་ཤེས་སྤྲོ་བའི་ཚུལ། དུ་མར་འཇུག་ཚུལ། ཡེ་ཤེས་འཇུག་པའི་རིམ་པ། བྱེད་ལས་ཁྱད་པར་དུ་འཕགས་པའོ། །
Enumeration Block 13:
ལྔ་པ་ལ་གཉིས། མདོར་བསྟན། རྒྱས་བཤད། །
Enumeration Block 14:
དྲུག་པ་ལ་གཉིས། །དཔེ་ལས་འདས་པར་བསྟན་པ་དང། བྱེད་ལས་ཀྱི་ཁྱད་པར་དངོས། །
Enumeration Block 15:
དྲུག་པ་ཐུགས་ཀྱི་གསང་བའི་དཔེ་སྦྱར་བ་ལ་གསུམ། རྟོག་མེད་འདོད་རྒུ་སྒྲུབ་ཚུལ། འབད་མེད་རྟག་ཏུ་བཞུགས་ཚུལ། རྙེད་པར་དཀའ་བས་མཚུངས་པར་བསྟན་པའོ།
Enumeration Block 16:
གཉིས་པ་དགོས་པ་བརྗོད་དེ་སྐབས་དོན་བསྡུ་བ་ལ་གཉིས། དགོས་པ་དང་དཔེ་དོན་གྱི་དབྱེ་བ་དང། དཔེས་མཚོན་ཚུལ་ཁྱད་པར་དུ་བཤད་པའོ། །དང་པོ་ལ་བཞི། དགོས་པ་དང་ཉིང་དགོས་འགྲུབ་ཚུལ། དཔེ་དོན་བསྡུས་ཏེ་བསྟན་པ། དཔེ་གསུམ་དུ་སྦྱར་བ། སྐབས་ཀྱི་དོན་ལ་འབད་རྩོལ་མེད་ཚུལ་ལོ། །
Enumeration Block 17:
གཉིས་པ་དཔེས་མཚོན་ཚུལ་ཁྱད་པར་དུ་བཤད་པ་ལ་གཉིས་དཔེའི་དབྱེ་བ། དེ་དོན་དང་སྦྱར་ཏེ་བཤད་པའོ། །
Enumeration Block 18:
གསུམ་པ་སླར་ཡང་བསྡུས་ཏེ་ཁྱད་པར་དུ་བསྟན་པ་ལ་གཉིས། སྣང་ཡང་སྐྱེ་འཇིགས་མེད་ཚུལ། ཆོས་མཚུངས་ལས་ཁྱད་པར་འཕགས་པའི་ཚུལ་ལོ། །དང་པོ་ལ་གཉིས། དབང་པོའི་དཔེ་དང། རྒྱུན་མི་འཆད་པས་སྐྱེ་འཇིག་མེད་ཚུལ་ལོ། །
Enumeration Block 19:
གཉིས་པ་ཆོས་མཚུངས་ལས་ཁྱད་པར་འཕགས་ཚུལ་ལ་གཉིས། མདོར་བསྟན། རྒྱས་བཤད་དོ། །
Enumeration Block 20:
གསུམ་པ་བསྟན་བཅོས་ཡོངས་སུ་རྫོགས་པའི་བྱ་བ་ལ་གསུམ། ཕན་ཡོན་དང། ཇི་ལྟར་མཛད་པ་དང། བསྔོ་བ་དོན་བསྡུ་དང་བཅས་པའོ། །དང་པོ་ལ་ལྔ། བསམ་མི་ཁྱབ་ཀྱི་དོན་བརྗོད་པ། ཡོན་ཏན་མདོར་བསྟན་པ། སྦྱིན་སོགས་གསུམ་ལས་ཁྱད་པར་བཤད་པ། དེའི་རྒྱུ་མཚན་བརྗོད་པ། ཕན་ཡོན་ཤིན་ཏུ་རྒྱས་བཤད་དོ། །
Enumeration Block 21:
གསུམ་པ་ཁྱད་པར་བཤད་པ་ལ་གསུམ། སྦྱིན་པ། ཚུལ་ཁྲིམས། བསམ་གཏན་ལས་ཁྱད་པར་བཤད་པའོ།
Enumeration Block 22:
ལྔ་པ་ཕན་ཡོན་ཤིན་ཏུ་རྒྱས་བཤད་ལ་ལྔ། བྱང་ཆུབ་ཐོབ་པ་དང། བྱང་ཆུབ་ཀྱི་སེམས་བརྟན་པ། ཡོངས་སུ་རྫོགས་པའི་ཐོབ་པ། ཞར་ལ་ཚོགས་ཀྱི་ངེས་པ་བསྟན་པ། སྒྲིབ་པ་སྤོང་བའོ། །
