Enumeration Block 1:
དྲུག་པ་ཀུན་ཏུ་འགྲོ་བའི་དོན་ལ་གཉིས། ངོ་བོ་བསྟན་པ་དང། རྣམ་དབྱེ་བཤད་པའོ། །
Enumeration Block 2:
བདུན་པ་མི་འགྱུར་བའི་དོན་ལ་གཉིས། ངོ་བོ་མདོར་བསྟན་པ། གནས་སྐབས་གསུམ་དུ་མི་འགྱུར་བའི་རྒྱས་བཤད་དོ། །
Enumeration Block 3:
གཉིས་པ་ལ་གསུམ། མ་དག་པའི། མ་དག་ལ་དག་པའི། ཤིན་ཏུ་དག་པའི་གནས་སྐབས་སུ་མི་འགྱུར་པའོ། །དང་པོ་ལ་བཞི། ངོ་བོ་ལ་དྲི་མས་མ་གོས་པ། ཆོས་ཅན་ལ་སྐྱེ་འཇིག་སྣང་བ་དང། ཆོས་ཉིད་ལ་འཇིགས་པས་མི་གནོད་པ་དང། རྟེན་ཅིང་འབྲེལ་བར་འབྱུང་བ་རྒྱས་བཤད་དོ། །
Enumeration Block 4:
བཞི་པ་རྟེན་ཅིང་འབྲེལ་བར་འབྱུང་བ་རྒྱས་པར་བཤད་པ་ལ་གསུམ། དཔེ་དོན་སྦྱར་ཏེ་བསྐྱེད་པའི་ཚུལ་བསྟན། ངོ་བོ་མཐའ་བྲལ་དྲི་མེད་བཤད། སྐྱེ་འཇིག་དཔེ་དོན་བསྡུ་བའོ། །དང་པོ་ལ་བཞི། དཔེ། དོན། དེ་གཉིས་སྦྱར་བ། བསྐྱེད་པའི་ཚུལ་ལོ། །
Enumeration Block 5:
གཉིས་པ་ལ་གཉིས། ངོ་བོ་སྐྱེ་འགག་མེད་པ་དང། དེ་ལ་དྲི་མས་དག་པའི་ཚུལ་ལོ། །
Enumeration Block 6:
གསུམ་པ་ལ་གཉིས། སྐྱེ་འཇིག་བྲལ་བའི་ཚུལ་བསྡུ་བ་དང། འཇིག་ཚུལ་བསྡུ་བའོ། །
Enumeration Block 7:
གཉིས་པ་མ་དག་ལ་དག་པའི་གནས་སྐབས་སུ་མི་འགྱུར་བའི་དོན་ལ་གཉིས། སྐྱེ་སོགས་ཀྱིས་མི་འགྱུར་བའི་དོན་དངོས་བསྟན་པ། ས་བཅུར་རྒྱལ་སྲས་ཀྱི་ཡོན་ཏན་ངོས་བཟུང་བའོ། །དང་པོ་ལ་གཉིས། མ་འགྱུར་ཡང་འགྱུར་བར་སྣང་ཚུལ། དེའི་དོན་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 8:
གཉིས་པ་ལ་གཉིས། སྡུག་བསྔལ་གྱིས་འགྱུར་བ་མེད་ཚུལ། སྙིང་རྗེ་ལས་འགྱུར་བར་སྣང་ཚུལ་ལོ། །
Enumeration Block 9:
གཉིས་པ་ས་བཅུར་རྒྱལ་སྲས་ཀྱི་ཡོན་ཏན་ངོས་བཟུང་བ་ལ་ལྔ། དང་པོ་སེམས་བསྐྱེད་སྐྱེས་པའི། སྤྱོད་པ་མཆོག་ལ་ཞུགས་པའི། ཕྱིར་མི་ལྡོག་པ་ཐོབ་པའི། སྐྱེ་བ་ཐ་མར་གྱུར་པའི་ཡོན་ཏན། དོན་གཉིས་འགྲུབ་པའི་ཁྱད་པར་བསྟན་པའོ། །
Enumeration Block 10:
གསུམ་པ་ཤིན་ཏུ་རྣམ་དག་གི་གནས་སྐབས་ནའང་འགྱུར་བ་མེད་པའི་ཚུལ་ལ་གཉིས། འགྱུར་མེད་ཀྱི་རྒྱུ་མཚན་མདོར་བསྟན་པ་དང། དེའི་དོན་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 11:
གཉིས་པ་ལ་གསུམ། སྐྱེ་སོགས་བྲལ་བའི་དམ་བཅའ་དང་རྟགས་བརྗོད། དེའི་དོན་བསྡུས་ཏེ་བཤད། རྟགས་སོགས་སུ་འཇོག་པའི་རྒྱུ་མཚན་བསྟན་པའོ། །དང་པོ་ལ་གཉིས། སོ་སོར་མདོར་བསྟན། སྦྱར་ཏེ་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 12:
སྤྱི་དོན་བརྒྱད་པ་ཡོན་ཏན་དབྱེར་མེད་པའི་དོན་བསྟན་པ་ལ་གཉིས། མིང་དོན་གྱི་སྒོ་ནས་མདོར་བསྟན། དེ་དག་གི་ངོ་བོ་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 13:
གཉིས་པ་ལ་གསུམ། མིང་གི་རྣམ་གྲངས་རྒྱས་བཤད། དོན་གྱི་ངོ་བོ་རྒྱས་བཤད། དེ་དག་དཔེ་ཡིས་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གཉིས། དོན་གྱི་དབང་གིས་མིང་བརྟགས་པ། དེ་རྣམས་དོན་དང་སྦྱར་བའོ། །
Enumeration Block 14:
གཉིས་པ་དོན་གྱི་ངོ་བོའི་རྒྱས་བཤད་ལ་གཉིས། གཉིས་མེད་ཀྱི་དོན་དང། ཐར་པའི་དོན་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 15:
གསུམ་པ་དེ་དག་དཔེ་ཡིས་ངེས་པར་བྱེད་པ་ལ་གཉིས། མ་ངེས་པ་རི་མོའི་དཔེ་དང། ངེས་པ་ཅན་ཉི་མའི་དཔེས་བསྟན་པའོ། །དང་པོ་ལ་གཉིས། དཔེ་དང། དོན་ནོ། །
Enumeration Block 16:
གཉིས་པ་ངེས་པ་ཅན་ཉི་མའི་དཔེ་ལ་གཉིས། ཆོས་མཐུན་བརྗོད་པ་དང་སངས་རྒྱས་ཉིད་མྱ་ངན་ལས་འདས་པར་བསྟན་པའོ། །
Enumeration Block 17:
གསུམ་པ་ངོ་བོ་མི་འགྱུར་ཡང་དྲི་མ་སྦྱོང་བའི་དཔེ་བསྟན་པ་ལ་ལྔ། མཚམས་སྦྱར་བ། དཔེ་དགུ་དྲི་མ་དང་རྒྱལ་བའི་སྙིང་པོ་བསྟན་པ། དྲི་མ་སྦྱོང་བའི་ཚུལ། ཇི་ལྟར་རྟོགས་པའི་རིམ་པ། སྙིང་པོ་ཉིད་བསྟན་པའོ། །
Enumeration Block 18:
གཉིས་པ་ལ་གསུམ། མདོར་བསྟན། རྒྱས་བཤད། དོན་བསྡུ་བའོ། །
Enumeration Block 19:
དང་པོ་ལ་གཉིས། བསྒྲིབ་བྱ་སྒྲིབ་བྱེད་དཔེ་དོན་སེལ་ནས་བརྗོད་པ་དང། སོ་སོར་བརྗོད་པའོ། །
Enumeration Block 20:
གཉིས་པ་རྒྱས་པར་བཤད་པ་ལ་དགུ། པདྨ་དང་སངས་རྒྱས་ཀྱི་དཔེ་དོན། སྦྲང་མ་དང་སྦྲང་རྩི། སྦུན་པ་དང་འབྲས། མི་གཙང་བ་དང་གསེར། ས་དང་གཏེར། ཤུན་པ་དང་མྱུ་གུ། གོས་ཧྲུལ་དང་སྐུ། མི་མོ་དང་འཁོར་བསྒྱུར། ས་འདམ་དང་གསེར་གྱི་སྐུ་སྟེ་ཐམས་ཅད་ལ་དཔེ་དོན་བྱེད་ལས་གསུམ་གསུམ་གྱིས་བསྟན་ཅིང། དགུ་པོ་རེ་རེ་བཞིན་དཔེ་བཤད་པ། དོན་བསྟན་པ། དཔེ་དོན་སྦྱར་ནས་དོན་བསྡུ་བ་སྟེ་གསུམ་གསུམ་དུ་ཡོད་དོ། །དེ་ལྟར་ན་དཔེ་དོན་དང་པོ་ལ་གསུམ། དཔེ། དོན། དེ་གཉིས་སྦྱར་བའོ། །
Enumeration Block 21:
དཔེ་དོན་གཉིས་པ་ལ་གསུམ། དཔེ། དོན། སྦྱར་བཤད་དོ། །
Enumeration Block 22:
དཔེ་དོན་གསུམ་པ་ལ་གསུམ། དཔེ། དོན། སྦྱར་བཤད་དོ། །
Enumeration Block 23:
དཔེ་དོན་བཞི་པ་ལ་གསུམ། དཔེ། དོན། སྦྱར་བཤད་དོ། །
Enumeration Block 24:
དཔེ་དོན་ལྔ་པ་ལ་གསུམ། དཔེ། དོན། སྦྱར་བཤད་དོ། །
Enumeration Block 25:
དཔེ་དོན་དྲུག་པ་ལ་གསུམ། དཔེ། དོན། སྦྱར་བཤད་དོ། །
Enumeration Block 26:
དཔེ་དོན་བདུན་པ་ལ་གསུམ། དཔེ། དོན། སྦྱར་བཤད་དོ། །
Enumeration Block 27:
དཔེ་དོན་བརྒྱད་པ་ལ་གསུམ། དཔེ། དོན། སྦྱར་བཤད་དོ། །
Enumeration Block 28:
དཔེ་དོན་དགུ་པ་ལ་གསུམ། དཔེ། དོན། སྦྱར་བཤད་དོ། །
Enumeration Block 29:
གསུམ་པ་དྲི་མ་སྦྱོང་ཚུལ་ལ་གསུམ། དྲི་མ་དགུ་བསྟན་པ། གང་ཟག་གང་གི་རྒྱུད་ལ་ཡོད་པ། དྲི་མའི་ཚུལ་རྒྱས་བཤད་དོ། །
Enumeration Block 30:
གསུམ་པ་དྲི་མ་སྦྱོང་བའི་ཚུལ་བསྟན་པ་ལ་བདུན། བག་ལ་ཉལ་གསུམ་གྱི་ཚུལ། ཀུན་ལྡང་དྲག་པོའི་ཉེས་པ། མ་རིག་བག་ཆགས་ཀྱི་སའི་སྐྱོན། ཐེག་པ་ཐུན་མོང་གི་མཐོང་སྤང་དང་སྒོམ་སྤང༌། ཁྱད་པར་ས་བདུན་གྱི་དྲི་མ། རྡོ་རྗེ་ལྟ་བུས་གཞོམ་བྱ། དོན་བསྡུ་བའོ། །
Enumeration Block 31:
བཞི་པ་ཇི་ལྟར་རྟོགས་པའི་རིམ་པ་ལ་གསུམ། དཔེ་དགུས་མཚོན་ཚུལ་མདོར་བསྟན་པ། དེའི་དོན་སོ་སོར་དབྱེ་བ། ཕྱེས་པའི་ངོ་བོ་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 32:
གསུམ་པ་རྒྱས་པར་བཤད་པ་ལ་བཞི། ཆོས་སྐུའི་དཔེ་དོན། དེ་བཞིན་ཉིད་ཀྱི་དཔེ་དོན། རིགས་ཀྱི་དཔེ་དོན། དེ་དག་དད་པས་རྟོགས་ཚུལ་ལོ། །དང་པོ་ལ་གཉིས། ཆོས་སྐུའི་རྣམ་དབྱེ་བསྟན་པ། དེ་དག་དཔེ་དང་སྦྱར་བའོ། །
Enumeration Block 33:
གསུམ་པ་རིགས་ཀྱི་དཔེ་དོན་ལ་གསུམ། རིགས་གཉིས་དཔེར་བསྟན། དེ་ལས་སྐུ་གསུམ་ཐོབ་ཚུལ་བཤད། དེ་རྣམས་དཔེ་དང་སྦྱར་བའོ། །
