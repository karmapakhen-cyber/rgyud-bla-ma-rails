Enumeration Block 1:
གསུམ་པ་བསྟན་བཅོས་ཡོངས་སུ་རྫོགས་པའི་བྱ་བ་ལ་གསུམ། ཕན་ཡོན་དང། ཇི་ལྟར་མཛད་པ་དང། བསྔོ་བ་དོན་བསྡུ་དང་བཅས་པའོ། དང་པོ་ལ་ལྔ། བསམ་མི་ཁྱབ་ཀྱི་དོན་བརྗོད་པ། ཡོན་ཏན་མདོར་བསྟན་པ། སྦྱིན་སོགས་གསུམ་ལས་ཁྱད་པར་བཤད་པ། དེའི་རྒྱུ་མཚན་བརྗོད་པ། ཕན་ཡོན་ཤིན་ཏུ་རྒྱས་བཤད་དོ། །
Enumeration Block 2:
གསུམ་པ་ཁྱད་པར་བཤད་པ་ལ་གསུམ། སྦྱིན་པ། ཚུལ་ཁྲིམས། བསམ་གཏན་ལས་ཁྱད་པར་བཤད་པའོ།
Enumeration Block 3:
ལྔ་པ་ཕན་ཡོན་ཤིན་ཏུ་རྒྱས་བཤད་ལ་ལྔ། བྱང་ཆུབ་ཐོབ་པ་དང། བྱང་ཆུབ་ཀྱི་སེམས་བརྟན་པ། ཡོངས་སུ་རྫོགས་པའི་ཐོབ་པ། ཞར་ལ་ཚོགས་ཀྱི་ངེས་པ་བསྟན་པ། སྒྲིབ་པ་སྤོང་བའོ། །
Enumeration Block 4:
ལྔ་པ་སྒྲིབ་པ་སྤོང་བ་ལ་གཉིས། སྤང་བྱ་སྒྲིབ་པ་ངོས་བཟུང་བ་དང། གཉེན་པོ་ཡེ་ཤེས་མཆོག་ཏུ་བསྟན་པའོ།
Enumeration Block 5:
གཉིས་པ་བསྟན་བཅོས་ཇི་ལྟར་མཛད་པ་ལ་དྲུག ། ཇི་ལྟར་མཛད་པའི་ཚུལ། གང་ལ་བརྟེན་ནས་མཛད་པ། རྒྱལ་བའི་བཀའ་ངོས་བཟུང་བ། དེ་དང་མཐུན་པ་ཐམས་ཅད་བླང་བྱར་བསྟན་པ། རྒྱལ་བའི་བཀའ་དང་མ་འགལ་བར་བསྟན་པ། འགལ་བའི་ཉེས་པ་བསྟན་པའོ། །
Enumeration Block 6:
དྲུག་པ་ལ་གསུམ། ཆོས་སྤོང་ངོས་བཟུང་བ། ཟབ་མོའི་ཆོས་མི་སྤོང་བའི་ངེས་པ། ཆོས་སྤོང་མཚམས་མེད་ལས་ལྕི་བར་བསྟན་པའོ། །
Enumeration Block 7:
དང་པོ་ལ་གཉིས། བརྒྱུད་པའི་རྒྱུ་སྤང་བར་གདམས་པ་དང། རྒྱུ་བཅུ་དང་བཅས་པའི་ཆོས་སྤོང་བ་དངོས་སོ། །
Enumeration Block 8:
གསུམ་པ་བསྔོ་བ་དོན་བསྡུ་དང་བཅས་པ་ལ་གསུམ། བསྔོ་བ་སྨོན་ལམ་དང་བཅས་པ་ཕན་ཡོན་གྱི་དོན་བསྡུ་བསྟན་པ། རྫོགས་པའི་ཚུལ་ལོ། །
Enumeration Block 9:
ཐེག་པ་ཆེན་པོ་རྒྱུད་བླ་མའི་བསྟན་བཅོས་འདི་ལ་དོན་གཉིས། མཚན་དང༌། གཞུང་གི་དོན་ནོ། །
Enumeration Block 10:
གཉིས་པ་གཞུང་གི་དོན་ལ་གསུམ། ལུས་རྣམ་པར་བཞག་པ། ཡན་ལག་རྒྱས་པར་བཤད་པ། བརྩམས་པ་མཐར་ཕྱིན་པའི་དོན་ནོ། །དང་པོ་ལ་གསུམ། དགོས་དོན། བསྡུས་དོན། ཚིག་དོན་ནོ། །
Enumeration Block 11:
གསུམ་པ་ལ་གསུམ་སྟེ། བསྟན་བཅོས་ཀྱི་ལུས་རྡོ་རྗེའི་གནས་བདུན་དུ་བསྡུ་བ། དེ་མདོ་དང་སྦྱར་བ། དེ་དག་གི་འབྲེལ་བསྟན་པའོ། །དང་པོ་ལ་གཉིས་ཏེ། དོན་བདུན་སོ་སོར་བཤད་པ་དང༌། རྡོ་རྗེ་དང་དེའི་གནས་ཀྱི་རྒྱུ་མཚན་ནོ། །དང་པོ་ལ་གཉིས་ཏེ། དཀོན་མཆོག་གསུམ་དང༌། ཁམས་སོགས་བཞི་བཤད་པའོ། །དང་པོ་ལ་གཉིས་ཏེ། དངོས༌དང༌། ལུང༌དང་སྦྱར་བའོ། །
Enumeration Block 12:
གཉིས་པ་ལ་བཞི་སྟེ། ཁམས། བྱང་ཆུབ། ཡོན་ཏན། ཕྲིན་ལས་སོ། །
Enumeration Block 13:
ཇི་ལྟར་ཞེ༌ན༌གཉིས་ཏེ། དཀོན་མཆོག་གསུམ་དང༌། ཁམས་སོགས་བཞི་གསུངས་ཚུལ་ལོ། །
