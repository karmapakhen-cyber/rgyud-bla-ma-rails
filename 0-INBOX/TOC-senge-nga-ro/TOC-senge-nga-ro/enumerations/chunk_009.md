Enumeration Block 1:
གཉིས་པ་ལ་བསྟན་བཤད་གཉིས་ལས།
Enumeration Block 2:
གསུམ་པ་ལ་བཞི། བཤད་བྱ་དགོད་པ་དང༌། དེའི་རང་བཞིན་གཏན་ལ་དབབ་པ། རིག་པ་དང་གྲོལ་བའི་རྒྱུ་མཚན། དེས་ན་སྐྱབས་གནས་སུ་སྒྲུབ་པའོ། །
Enumeration Block 3:
གཉིས་པ་ལ་བསྟན་བཤད་གཉིས་ལས།
Enumeration Block 4:
གཉིས་པ་རྒྱུ་ཁམས་སོགས་བཞི་བཤད་པ་ལ་གསུམ་སྟེ། བསྟན། བཤད། དེ་ལ་མོས་པའི་ཕན་ཡོན་ནོ། །དང་པོ་ལ་གསུམ་སྟེ། ཁམས་སོགས་བཞི་ཉན་ཐོས་ལ་སོགས་པས་བསམ་གྱིས་མི་ཁྱབ་པ། དེའི་རྒྱུ་མཚན། ཁམས་སོགས་བཞིའི་གྲངས་ངེས་སོ། །
Enumeration Block 5:
རྒྱས་པར་བཤད་པ་ལ་བཞི་སྟེ། ཁམས། བྱང་ཆུབ། ཡོན་ཏན། ཕྲིན་ལས་སོ། །
Enumeration Block 6:
དང་པོ་ལ་བཞི་སྟེ། ཁམས་དེ་བཞིན་གཤེགས་པའི་སྙིང་པོས་སེམས་ཅན་ལ་ཁྱབ་པའི་རྒྱུ་མཚན། ཁམས་ཀྱི་རང་བཞིན་རྣམ་པར་བཞག་པ། དེས་སེམས་ཅན་ལ་ཁྱབ་པ་དཔེས་བསྟན་པ། ཁམས་དེ་རྟོགས་པར་དཀའ་བའི་ཚུལ་ལོ། །
Enumeration Block 7:
གཉིས་པ་ལ་གསུམ་སྟེ། མདོར་བསྟན། རྒྱས་བཤད། དོན་བསྡུ་བའོ། །
Enumeration Block 8:
གཉིས་པ་ལ་བརྒྱད་དེ། ངོ་བོ་དང་རྒྱུའི་དོན། འབྲས་བུ་དང་ལས་ཀྱི་དོན། ལྡན་པའི་དོན། འཇུག་པའི་དོན། གང་ཟག་གསུམ་གྱི་གནས་སྐབས་ཀྱི་དབྱེ་བ། ཀུན་ཏུ་འགྲོ་བའི་དོན། མི་འགྱུར་བའི་དོན། དབྱེ་བ་མེད་པའི་དོན་ནོ། །དང་པོ་ལ་གཉིས་ཏེ། མདོར་བསྟན་པ་དང༌། རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 9:
གཉིས་པ་ལ་ངོ་བོ་དང༌རྒྱུ་བཤད་པ་གཉིས་ལས།
Enumeration Block 10:
གཉིས་པ་ལ་གཉིས་ལས།
Enumeration Block 11:
གཉིས་པ་འབྲས་བུ་དང་ལས་ཀྱི་དོན་ལ་གཉིས་ལས།
Enumeration Block 12:
གཉིས་པ་རྒྱས་པར་བཤད་པ་ལ་གཉིས། འབྲས་བུ་དང་། ལས་ཀྱི་དོན་བཤད་པའོ། །དང་པོ་ལ་གཉིས། ཕྱིན་ཅི་ལོག་བཞིའི་གཉེན་པོ་ཆོས་སྐུ་ཡོན་ཏན་གྱི་ཕ་རོལ་ཏུ་ཕྱིན་པ་བཞི་ལྡན༌བསྟན༌པ་དང༌། ཡོན༌ཏན༌བཞི་སོ་སོར་བཤད་པའོ། །
Enumeration Block 13:
ལྡན་པའི་དོན་ལ་གཉིས་ལས།
Enumeration Block 14:
རྒྱས་པར་བཤད་པ་ལ་གཉིས་ལས།
Enumeration Block 15:
འཇུག་པའི་དོན་ལ་གཉིས་ལས།
Enumeration Block 16:
གང་ཟག་གསུམ་གྱི་གནས་སྐབས་ཀྱི་དབྱེ་བ་ལ་གཉིས་ལས།
Enumeration Block 17:
ཀུན་ཏུ་འགྲོ་བའི་དོན་ལ་གཉིས་ཏེ།
Enumeration Block 18:
མི་འགྱུར་བའི་དོན་ལ་གཉིས་ལས།
Enumeration Block 19:
རྒྱས་པར་བཤད་པ་ལ་གསུམ་སྟེ། སོ་སོའི་སྐྱེ་བོ་དང༌། འཕགས་པའི་སློབ་པ་དང༌། སངས་རྒྱས་ཀྱི་གནས་སྐབས་ན་མི་འགྱུར་བའོ། །དང་པོ་ལ་བཞི་སྟེ། ཉེས་པས་མ་གོས་པ་སྐྱེ་འཇིག་དང་བྲལ་བ། དེ་དག་གི་དོན་བསྡུ་བ། ཕུང་པོ་འཇིག་པའི་རྒྱུ་བཤད་པའོ། །
Enumeration Block 20:
གཉིས་པ་ལ་གཉིས་ཏེ། བསྟན་པ་དང༌། བཤད་པའོ། །
