Enumeration Block 1:
རྟག་པའི་དོན་ལ་གསུམ་སྟེ། བསྟན། བཤད། བསྡུ་བའོ། །
Enumeration Block 2:
གཉིས་པ་ལ་གཉིས་ཏེ། གཟུགས་སྐུ་དང༌། ཆོས་སྐུ་རྟག་པའི་རྒྱུའོ། །
Enumeration Block 3:
བསམ་གྱིས་མི་ཁྱབ་པའི་དོན་ལ་གསུམ་སྟེ། བསྟན། བཤད། བསྡུ་བའོ། །
Enumeration Block 4:
སངས་རྒྱས་ཀྱི་ཡོན་ཏན་ལ་བཞི་སྟེ། བཤད་བྱ་དགོད་པ། དེ་བཤད་པ། དེ་དག་མདོ་གང་ལ་བརྟེན་ནས་ཤེས་པའི་ཚུལ། མདོར་བསྡུས་ཏེ་ཆོས་མཐུན་ཁྱད་པར་དུ་བཤད་པའོ། །དང་པོ་ལ་བསྟན། བཤད་གཉིས་ལས།
Enumeration Block 5:
སངས་རྒྱས་ཀྱི་སྐུ་ལ་གཉིས་ཏེ། རང་དོན་དོན་དམ་པ་ཆོས་ཀྱི་སྐུ་དང་དེ་ལ་བརྟེན་པའི་གཞན་དོན་ཀུན་རྫོབ་པ་ཆོས་ཀྱི་སྐུ་ཉིད་དོ། །
Enumeration Block 6:
གཉིས་པ་ལ་གཉིས་ལས།
Enumeration Block 7:
རྒྱས་པར་བཤད་པ་ལ་གཉིས་ཏེ། བྲལ་བ་དང༌། རྣམ་སྨིན་གྱི་ཡོན་ཏན་བཤད་པའོ། །དང་པོ་ལ་གསུམ་སྟེ། སྟོབས་དང་མི་འཇིགས་པ་དང༌། སངས་རྒྱས་ཀྱི་ཆོས་མ་འདྲེས་པའོ། །དང་པོ་ལ་གཉིས་ཏེ། ངོ་བོ་དང༌། རྡོ་རྗེ་དང་ཆོས་མཐུན་པར་བསྟན་པའོ། །
Enumeration Block 8:
མི་འཇིགས་པ་ལ་གསུམ་སྟེ། སོ་སོའི་ངོ་བོ་དང༌། རྒྱུ་བྱེད་པ་དང༌། དཔེ་དང་སྦྱར་བའོ། །
Enumeration Block 9:
མ་འདྲེས་པ་ལ་གསུམ་སྟེ། ངོ་བོ་དང༌། དེ་སངས་རྒྱས་ཁོ་ན་ལ་ཡོད་པ། དཔེ་དང་སྦྱར་བའོ། །
Enumeration Block 10:

Enumeration Block 11:
གཉིས་པ་རྣམ་སྨིན་གྱི་ཡོན་ཏན་ལ་གཉིས་ཏེ། ངོ་བོ་དང༌། དཔེ་དང་སྦྱར་བའོ། །
Enumeration Block 12:
བཞི་པ་ལ་གཉིས་ཏེ། བསྟན་པ་དང༌། བཤད་པའོ། །
Enumeration Block 13:
གཉིས་པ་ལ་གཉིས་ཏེ། བྲལ་བ་དང༌། རྣམ་སྨིན་གྱི་ཡོན་ཏན་གྱི་ཆོས་མཐུན་བཤད་པའོ། །དང་པོ་ལ་གཉིས་ཏེ། སོ་སོར་བཤད། དོན་བསྡུ་བའོ། །དང་པོ་ལ་གསུམ་སྟེ། སྟོབས་དང༌། མི་འཇིགས་པ་དང༌། མ་འདྲེས་པའི་ཆོས་མཐུན་ནོ། །
Enumeration Block 14:
གཉིས་པ་ལ། བསྟན། བཤད་གཉིས་ལས།
Enumeration Block 15:
ཕྲིན་ལས་ལ་གཉིས་ཏེ། ཕྲིན་ལས་ལྷུན་གྱིས་གྲུབ་ཅིང་རྒྱུན་མི་ཆད་པར་བསྟན་པ་དང༌། དཔེའི་སྒོ་ནས་དེ་ལ་མོས་པ་བསྐྱེད་པའོ། །དང་པོ་ལ་གཉིས་ཏེ། བཤད་བྱ་དགོད་པ་དང༌། དེ་བཤད་པའོ། །དང་པོ་ལ་གཉིས་ཏེ། ལྷུན་གྱིས་གྲུབ་པ་དང༌། རྒྱུན་མི་ཆད་པའོ། །
Enumeration Block 16:
གཉིས་པ་ལ་གཉིས་ཏེ། ལྷུན་གྱིས་གྲུབ་པ་དང༌། རྒྱུན་མི་ཆད་པའོ། །དང་པོ་ལ་གཉིས་ལས།
Enumeration Block 17:
གཉིས་པ་ལ་གསུམ་སྟེ། བསྟན། བཤད། བསྡུ་བའོ། །
Enumeration Block 18:
གཉིས་པ་ལ་གསུམ་སྟེ། དོན་དང༌། དཔེ་དང༌། ཆོས་མཐུན༌སྦྱར་བའོ། །
Enumeration Block 19:
དེ་ལ་མོས་པ་བསྐྱེད་པ་ལ་གསུམ་སྟེ། བསྟན། བཤད། བསྡུ་བའོ། །
Enumeration Block 20:
རྒྱས་པར་བཤད་པ་ལ་མདོར་བསྟན་གྱི་གོ་རིམ་བཞིན་དུ་དགུ་ལས། དང་པོ་སྐུ་བརྒྱ་བྱིན་དང་འདྲ་བ་ལ་གཉིས་ཏེ། རྣམ་རྟོག་མེད་པ་དང་། སྐྱེ་འགག་མེད་པའོ། །དང་པོ་ལ་གཉིས། དཔེ་དང༌། དོན་ནོ། །
Enumeration Block 21:
དང་པོ་ལ་གསུམ་སྟེ། ས་གཞི་དག་པ་ལ་ལྷའི་གཟུགས་བརྙན་མཐོང་བ། དེས་རྐྱེན་བྱས་ནས་ལྷར་སྐྱེ་བ། གཟུགས་བརྙན་ལ་རྟོག་པ་མེད་ཀྱང་གཞན་དོན་དུ་འགྱུར་ཚུལ་ལོ། །
Enumeration Block 22:
དོན་ལ་བཞི་སྟེ། སེམས་དག་པ་ལ་སངས་རྒྱས་ཀྱི་གཟུགས་བརྙན་སྣང་བ་དང༌། དེ་སངས་རྒྱས་ཀྱི་རྒྱུར་འགྱུར་བ་དང༌། སངས་རྒྱས་ཀྱི་གཟུགས་བརྙན་ལ་རྟོག་པ་མེད་ཀྱང་གཞན་དོན་བྱེད་པ་དང༌། གཟུགས་སྐུ་མཐོང་བ་ལ་བརྟེན་ནས་ཆོས་སྐུ་མཐོང་བའི་ཚུལ་ལོ། །
Enumeration Block 23:
གཉིས་པ་སྐྱེ་འགག་མེད་པ་ལ་གཉིས་ཏེ། དཔེ་དང༌། དོན་ནོ། །དང་པོ་ལ་གཉིས་ཏེ། སྐྱེ་འགག་ཏུ་སྣང་བའི་ཚུལ། སྣང་བའི་བྱེད་པ་པོའོ། །
Enumeration Block 24:
དོན་ལ་གསུམ་སྟེ། སྐུ་གཟུགས་སྣང་བའི་བྱེད་པ། རྐྱེན་སྐུ་གཟུགས་སྣང་བའི་ཚུལ། སེམས་ཀྱི་དབང་གིས་སྐྱེ་འགག་དུ་སྣང་བའོ། །
Enumeration Block 25:
གཉིས་པ་གསུང་ལྷའི་རྔ་དང་འདྲ་བ་ལ་གསུམ་སྟེ། ཆོས་ཀྱི་རྔ་དང་མཚུངས་པ། ལྷ་རྫས་ཀྱི་སིལ་སྙན་གཞན་དང་མི་མཚུངས་པ། རྒྱུད་དག་པ་ལ་ལྟོས་པའོ། །དང་པོ་ལ་གཉིས་ཏེ། བག་མེད་པ་ལས་སྐྱོབ་པ་དང༌། འཇིགས་པ་ལས་སྐྱོབ་པའོ། །དང་པོ་ལ་གསུམ་སྟེ། དཔེ་དོན་སོ་སོར་བཤད་པ། སྒྲ་ཐོས་པའི་རྒྱུ། ཐོས་པའི་བྱེད་པའོ། །
