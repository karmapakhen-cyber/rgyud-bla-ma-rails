Enumeration Block 2:

Enumeration Block 7:

Enumeration Block 8:

Enumeration Block 9:

Enumeration Block 10:

Enumeration Block 13:

Enumeration Block 14:
གཉིས་པ་ལ་གཉིས། ཐོབ་བྱ་འབྲས་བུའི་དོན་དང། ཐོབ་བྱེད་ལས་ཀྱི་དོན་ནོ། །དང་པོ་ལ་གསུམ། སྤང་བྱ་ཕྱིན་ཅི་ལོག་སྤོང་ཚུལ། སྤང་པས་འབྲས་བུ་བཞི་འཐོབ་ཚུལ། ཐོབ་པས་མཐའ་གཉིས་ལས་གྲོལ་ཚུལ་ལོ།
Enumeration Block 15:
གཉིས་པ་ཐོབ་བྱེད་ལས་ཀྱི་དོན་ལ་གཉིས། རིགས་ཀྱི་ལས་ལྡོག་པའི་སྒོ་ནས་བསྟན་པ་དང། ནུས་པའི་ཁྱད་པར་རྗེས་འགྲོའི་ཚུལ་གྱིས་བསྟན་པའོ། །
Enumeration Block 16:
གསུམ་པ་ལྡན་པའི་དོན་ལ་གཉིས། རྒྱུ་འབྲས་གྱི་ཡོན་ཏན་ཐུན་མོང་དུ་བསྟན། སོ་སོའི་ངོ་བོ་ཁྱད་པར་བཤད་པའོ།
Enumeration Block 17:
གཉིས་པ་ལ་གཉིས། རྒྱུའི་ལྡན་པ་དང། འབྲས་བུའི་ལྡན་པའོ། །
Enumeration Block 18:
བཞི་པ་འཇུག་པའི་དོན་ལ་གཉིས། རྒྱུ་མཚན་མདོར་བསྟན་པ། དེ་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 19:
ལྔ་པ་གནས་སྐབས་ཀྱི་དོན་ལ་གཉིས། སྐབས་གསུམ་དུ་མིང་འདོགས་ཚུལ་དང། མིང་གསུམ་གྱིས་དོན་དྲུག་བསྡུས་ཚུལ་ལོ། །
Enumeration Block 20:
དྲུག་པ་ཀུན་ཏུ་འགྲོ་བའི་དོན་ལ་གཉིས། ངོ་བོ་བསྟན་པ་དང། རྣམ་དབྱེ་བཤད་པའོ། །
Enumeration Block 21:
བདུན་པ་མི་འགྱུར་བའི་དོན་ལ་གཉིས། ངོ་བོ་མདོར་བསྟན་པ། གནས་སྐབས་གསུམ་དུ་མི་འགྱུར་བའི་རྒྱས་བཤད་དོ། །
Enumeration Block 22:
གཉིས་པ་ལ་གསུམ། མ་དག་པའི། མ་དག་ལ་དག་པའི། ཤིན་ཏུ་དག་པའི་གནས་སྐབས་སུ་མི་འགྱུར་པའོ། །དང་པོ་ལ་བཞི། ངོ་བོ་ལ་དྲི་མས་མ་གོས་པ། ཆོས་ཅན་ལ་སྐྱེ་འཇིག་སྣང་བ་དང། ཆོས་ཉིད་ལ་འཇིགས་པས་མི་གནོད་པ་དང། རྟེན་ཅིང་འབྲེལ་བར་འབྱུང་བ་རྒྱས་བཤད་དོ། །
Enumeration Block 23:
བཞི་པ་རྟེན་ཅིང་འབྲེལ་བར་འབྱུང་བ་རྒྱས་པར་བཤད་པ་ལ་གསུམ། དཔེ་དོན་སྦྱར་ཏེ་བསྐྱེད་པའི་ཚུལ་བསྟན། ངོ་བོ་མཐའ་བྲལ་དྲི་མེད་བཤད། སྐྱེ་འཇིག་དཔེ་དོན་བསྡུ་བའོ། །དང་པོ་ལ་བཞི། དཔེ། དོན། དེ་གཉིས་སྦྱར་བ། བསྐྱེད་པའི་ཚུལ་ལོ། །
Enumeration Block 24:
གཉིས་པ་ལ་གཉིས། ངོ་བོ་སྐྱེ་འགག་མེད་པ་དང། དེ་ལ་དྲི་མས་དག་པའི་ཚུལ་ལོ། །
Enumeration Block 25:
གསུམ་པ་ལ་གཉིས། སྐྱེ་འཇིག་བྲལ་བའི་ཚུལ་བསྡུ་བ་དང། འཇིག་ཚུལ་བསྡུ་བའོ། །

Enumeration Block 1:
དྲུག་པ་ཀུན་ཏུ་འགྲོ་བའི་དོན་ལ་གཉིས། ངོ་བོ་བསྟན་པ་དང། རྣམ་དབྱེ་བཤད་པའོ། །
Enumeration Block 2:
བདུན་པ་མི་འགྱུར་བའི་དོན་ལ་གཉིས། ངོ་བོ་མདོར་བསྟན་པ། གནས་སྐབས་གསུམ་དུ་མི་འགྱུར་བའི་རྒྱས་བཤད་དོ། །
Enumeration Block 3:
གཉིས་པ་ལ་གསུམ། མ་དག་པའི། མ་དག་ལ་དག་པའི། ཤིན་ཏུ་དག་པའི་གནས་སྐབས་སུ་མི་འགྱུར་པའོ། །དང་པོ་ལ་བཞི། ངོ་བོ་ལ་དྲི་མས་མ་གོས་པ། ཆོས་ཅན་ལ་སྐྱེ་འཇིག་སྣང་བ་དང། ཆོས་ཉིད་ལ་འཇིགས་པས་མི་གནོད་པ་དང། རྟེན་ཅིང་འབྲེལ་བར་འབྱུང་བ་རྒྱས་བཤད་དོ། །
Enumeration Block 4:
བཞི་པ་རྟེན་ཅིང་འབྲེལ་བར་འབྱུང་བ་རྒྱས་པར་བཤད་པ་ལ་གསུམ། དཔེ་དོན་སྦྱར་ཏེ་བསྐྱེད་པའི་ཚུལ་བསྟན། ངོ་བོ་མཐའ་བྲལ་དྲི་མེད་བཤད། སྐྱེ་འཇིག་དཔེ་དོན་བསྡུ་བའོ། །དང་པོ་ལ་བཞི། དཔེ། དོན། དེ་གཉིས་སྦྱར་བ། བསྐྱེད་པའི་ཚུལ་ལོ། །
Enumeration Block 5:
གཉིས་པ་ལ་གཉིས། ངོ་བོ་སྐྱེ་འགག་མེད་པ་དང། དེ་ལ་དྲི་མས་དག་པའི་ཚུལ་ལོ། །
Enumeration Block 6:
གསུམ་པ་ལ་གཉིས། སྐྱེ་འཇིག་བྲལ་བའི་ཚུལ་བསྡུ་བ་དང། འཇིག་ཚུལ་བསྡུ་བའོ། །
Enumeration Block 7:
གཉིས་པ་མ་དག་ལ་དག་པའི་གནས་སྐབས་སུ་མི་འགྱུར་བའི་དོན་ལ་གཉིས། སྐྱེ་སོགས་ཀྱིས་མི་འགྱུར་བའི་དོན་དངོས་བསྟན་པ། ས་བཅུར་རྒྱལ་སྲས་ཀྱི་ཡོན་ཏན་ངོས་བཟུང་བའོ། །དང་པོ་ལ་གཉིས། མ་འགྱུར་ཡང་འགྱུར་བར་སྣང་ཚུལ། དེའི་དོན་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 8:
གཉིས་པ་ལ་གཉིས། སྡུག་བསྔལ་གྱིས་འགྱུར་བ་མེད་ཚུལ། སྙིང་རྗེ་ལས་འགྱུར་བར་སྣང་ཚུལ་ལོ། །
Enumeration Block 9:
གཉིས་པ་ས་བཅུར་རྒྱལ་སྲས་ཀྱི་ཡོན་ཏན་ངོས་བཟུང་བ་ལ་ལྔ། དང་པོ་སེམས་བསྐྱེད་སྐྱེས་པའི། སྤྱོད་པ་མཆོག་ལ་ཞུགས་པའི། ཕྱིར་མི་ལྡོག་པ་ཐོབ་པའི། སྐྱེ་བ་ཐ་མར་གྱུར་པའི་ཡོན་ཏན། དོན་གཉིས་འགྲུབ་པའི་ཁྱད་པར་བསྟན་པའོ། །
Enumeration Block 10:
གསུམ་པ་ཤིན་ཏུ་རྣམ་དག་གི་གནས་སྐབས་ནའང་འགྱུར་བ་མེད་པའི་ཚུལ་ལ་གཉིས། འགྱུར་མེད་ཀྱི་རྒྱུ་མཚན་མདོར་བསྟན་པ་དང། དེའི་དོན་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 11:
གཉིས་པ་ལ་གསུམ། སྐྱེ་སོགས་བྲལ་བའི་དམ་བཅའ་དང་རྟགས་བརྗོད། དེའི་དོན་བསྡུས་ཏེ་བཤད། རྟགས་སོགས་སུ་འཇོག་པའི་རྒྱུ་མཚན་བསྟན་པའོ། །དང་པོ་ལ་གཉིས། སོ་སོར་མདོར་བསྟན། སྦྱར་ཏེ་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 12:
སྤྱི་དོན་བརྒྱད་པ་ཡོན་ཏན་དབྱེར་མེད་པའི་དོན་བསྟན་པ་ལ་གཉིས། མིང་དོན་གྱི་སྒོ་ནས་མདོར་བསྟན། དེ་དག་གི་ངོ་བོ་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 13:
གཉིས་པ་ལ་གསུམ། མིང་གི་རྣམ་གྲངས་རྒྱས་བཤད། དོན་གྱི་ངོ་བོ་རྒྱས་བཤད། དེ་དག་དཔེ་ཡིས་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གཉིས། དོན་གྱི་དབང་གིས་མིང་བརྟགས་པ། དེ་རྣམས་དོན་དང་སྦྱར་བའོ། །
Enumeration Block 14:
གཉིས་པ་དོན་གྱི་ངོ་བོའི་རྒྱས་བཤད་ལ་གཉིས། གཉིས་མེད་ཀྱི་དོན་དང། ཐར་པའི་དོན་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 15:

Enumeration Block 17:

Enumeration Block 20:

Enumeration Block 21:
དཔེ་དོན་གཉིས་པ་ལ་གསུམ། དཔེ། དོན། སྦྱར་བཤད་དོ། །
Enumeration Block 22:

Enumeration Block 23:
དཔེ་དོན་བཞི་པ་ལ་གསུམ། དཔེ། དོན། སྦྱར་བཤད་དོ། །
Enumeration Block 24:

Enumeration Block 25:

Enumeration Block 26:

Enumeration Block 27:
དཔེ་དོན་བརྒྱད་པ་ལ་གསུམ། དཔེ། དོན། སྦྱར་བཤད་དོ། །
Enumeration Block 28:
དཔེ་དོན་དགུ་པ་ལ་གསུམ། དཔེ། དོན། སྦྱར་བཤད་དོ། །
Enumeration Block 29:
གསུམ་པ་དྲི་མ་སྦྱོང་ཚུལ་ལ་གསུམ། དྲི་མ་དགུ་བསྟན་པ། གང་ཟག་གང་གི་རྒྱུད་ལ་ཡོད་པ། དྲི་མའི་ཚུལ་རྒྱས་བཤད་དོ། །
Enumeration Block 30:
གསུམ་པ་དྲི་མ་སྦྱོང་བའི་ཚུལ་བསྟན་པ་ལ་བདུན། བག་ལ་ཉལ་གསུམ་གྱི་ཚུལ། ཀུན་ལྡང་དྲག་པོའི་ཉེས་པ། མ་རིག་བག་ཆགས་ཀྱི་སའི་སྐྱོན། ཐེག་པ་ཐུན་མོང་གི་མཐོང་སྤང་དང་སྒོམ་སྤང༌། ཁྱད་པར་ས་བདུན་གྱི་དྲི་མ། རྡོ་རྗེ་ལྟ་བུས་གཞོམ་བྱ། དོན་བསྡུ་བའོ། །
Enumeration Block 31:
བཞི་པ་ཇི་ལྟར་རྟོགས་པའི་རིམ་པ་ལ་གསུམ། དཔེ་དགུས་མཚོན་ཚུལ་མདོར་བསྟན་པ། དེའི་དོན་སོ་སོར་དབྱེ་བ། ཕྱེས་པའི་ངོ་བོ་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 32:
གསུམ་པ་རྒྱས་པར་བཤད་པ་ལ་བཞི། ཆོས་སྐུའི་དཔེ་དོན། དེ་བཞིན་ཉིད་ཀྱི་དཔེ་དོན། རིགས་ཀྱི་དཔེ་དོན། དེ་དག་དད་པས་རྟོགས་ཚུལ་ལོ། །དང་པོ་ལ་གཉིས། ཆོས་སྐུའི་རྣམ་དབྱེ་བསྟན་པ། དེ་དག་དཔེ་དང་སྦྱར་བའོ། །
Enumeration Block 33:
གསུམ་པ་རིགས་ཀྱི་དཔེ་དོན་ལ་གསུམ། རིགས་གཉིས་དཔེར་བསྟན། དེ་ལས་སྐུ་གསུམ་ཐོབ་ཚུལ་བཤད། དེ་རྣམས་དཔེ་དང་སྦྱར་བའོ། །

Enumeration Block 1:
བཞི་པ་ཇི་ལྟར་རྟོགས་པའི་རིམ་པ་ལ་གསུམ། དཔེ་དགུས་མཚོན་ཚུལ་མདོར་བསྟན་པ། དེའི་དོན་སོ་སོར་དབྱེ་བ། ཕྱེས་པའི་ངོ་བོ་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 2:
གསུམ་པ་རྒྱས་པར་བཤད་པ་ལ་བཞི། ཆོས་སྐུའི་དཔེ་དོན། དེ་བཞིན་ཉིད་ཀྱི་དཔེ་དོན། རིགས་ཀྱི་དཔེ་དོན། དེ་དག་དད་པས་རྟོགས་ཚུལ་ལོ། །དང་པོ་ལ་གཉིས། ཆོས་སྐུའི་རྣམ་དབྱེ་བསྟན་པ། དེ་དག་དཔེ་དང་སྦྱར་བའོ། །
Enumeration Block 3:
གསུམ་པ་རིགས་ཀྱི་དཔེ་དོན་ལ་གསུམ། རིགས་གཉིས་དཔེར་བསྟན། དེ་ལས་སྐུ་གསུམ་ཐོབ་ཚུལ་བཤད། དེ་རྣམས་དཔེ་དང་སྦྱར་བའོ། །
Enumeration Block 4:
ལྔ་པ་སྙིང་པོ་ཉིད་བསྟན་པ་ལ་གཉིས། ངོ་བོ་དང། སྟོང་མི་སྟོང་གི་ཚུལ་ལོ། །
Enumeration Block 5:
རྩ་བའི་བཞི་པ་ཁམས་བསྟན་པའི་དགོས་པ་བསྟན་པ་ལ་གཉིས། དྲིས་ལན་གྱི་མདོར་བསྟན། དེའི་དོན་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གཉིས། དྲི་བ་དང་ལན་ནོ། །
Enumeration Block 6:
གཉིས་པ་རྒྱས་བཤད་ལ་གསུམ། བཀའ་བར་པར་ཇི་ལྟར་བསྟན་པའི་དགོངས་པ། ཐ་མར་ཁམས་བསྟན་པའི་རྒྱུ་མཚན། དེ་རྒྱས་བཤད་དོ། །དང་པོ་ལ་གཉིས། མདོར་བསྟན། རྒྱས་བཤད་དོ། །
Enumeration Block 7:
གསུམ་པ་དེ་རྒྱས་པར་བཤད་པ་ལ་གཉིས། ཉེས་པ་ལྔ་ཇི་ལྟར་འབྱུང་ཚུལ། སྐྱོན་ལྔ་སྤངས་པས་ཡོན་ཏན་ཐོབ་ཚུལ་ལོ། །
Enumeration Block 8:
སྤྱི་དོན་གཉིས་པ་རྟོགས་པ་བྱང་ཆུབ་བསྟན་པ་ལ་གསུམ། བཤད་བྱ་དོན་གྱི་ངོ་བོ་མདོར་བསྟན། འཆད་ཚུལ་སྡོམ་དུ་བསྡུ། དེ་དག་སྦྱར་ཏེ་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 9:
གསུམ་པ་ལ་བདུན། ངོ་བོ་དང་རྒྱུ་རྒྱས་པར་བཤད་པ། འབྲས་བུ། ལས། ལྡན་པ། འཇུག་པ། རྟག་པ། བསམ་གྱིས་མི་ཁྱབ་པ་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གཉིས། དག་པ་འཐོབ་ཚུལ་མདོར་བསྟན། དེའི་དོན་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 10:
གཉིས་པ་རྒྱས་བཤད་ལ་བཞི། ངོ་བོ་ཉིད་དང། ཡོན་ཏན་ལྡན་པའི་ཚུལ་དང། སྒྲིབ་པའི་དོན་དང། དེ་བྲལ་བའི་རྒྱུའོ། །
Enumeration Block 11:
གཉིས་པ་འབྲས་བུ་རྒྱས་པར་བཤད་པ་ལ་གཉིས། དྲི་མེད་དཔེ་ཡིས་མདོར་བསྟན། དེའི་རྒྱུ་མཚན་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལའང་གཉིས། ཉོན་སྒྲིབ་གྲོལ་འབྲས་དང། ཤེས་སྒྲིབ་གྲོལ་འབྲས་སོ། །
Enumeration Block 12:
གཉིས་པ་རྒྱས་བཤད་ལ་གསུམ། མཉམ་གཞག་དང་རྗེས་ཐོབ་ཀྱིས་ཐོབ་པའི་འབྲས་བུ། དུག་གསུམ་དག་པའི་འབྲས་བུ། དོན་དཔེ་དགུ་དང་སྦྱར་བའོ། །
Enumeration Block 13:
གསུམ་པ་ལས་རྒྱས་པར་བཤད་པ་ལ་གཉིས༑དོན་གཉིས་འགྲུབ་ཚུལ་མདོར་བསྟན། དེའི་དོན་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གཉིས། ངོ་བོ་ཉིད་ཀྱི་ལས་དང། ཆོས་ཐམས་ཅད་ཀྱིས་དག་པའི་ལས། །
Enumeration Block 14:
གཉིས་པ་རྒྱས་བཤད་ལ་གསུམ། དོན་གཉིས་འགྲུབ་ཚུལ་རྣམ་དབྱེ་བཅས་སྦྱར་བསྟན། རང་དོན་ཕུན་ཚོགས་དང། གཞན་དོན་ཕུན་ཚོགས་ཁྱད་པར་དུ་བཤད་པའོ། །
Enumeration Block 15:
བཞི་པ་ལྡན་པའི་དོན་ལ་གཉིས། མིང་གི་རྣམ་གྲངས་མདོར་བསྟན། དེའི་དོན་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 16:
གཉིས་པ་རྒྱས་པར་བཤད་པ་ལ་གཉིས། ཡོན་ཏན་གང་ལ་ལྡན་ཚུལ་གྱི་མདོར་བསྟན། ལྡན་པའི་ཡོན་ཏན་ངེས་པར་བྱ་བའོ། །གཉིས་པ་ལའང་གཉིས། ཟབ་པའི་རྒྱུ་མཚན་རྒྱས་པར་བཤད་པ་དང། ཕྱི་མ་རྣམས་ཀྱི་རྒྱུ་མཚན་བཤད་པའོ། །དེའི་དང་པོ་ལ་གསུམ། བསམ་མི་ཁྱབ་ཚུལ་སྤྱིར་བསྟན། ཁྱད་པར་རྒྱས་པར་བཤད། རྒྱུ་མཚན་དཔེ་དང་སྦྱར་བའོ། །
Enumeration Block 17:
གཉིས་པ་ཕྱི་མ་རྣམས་ཀྱི་རྒྱུ་མཚན་བཤད་པ་ལ་གསུམ། མི་འགྱུར་བའི་ཡོན་ཏན། སྤངས་རྟོགས་ཀྱི་ཡོན་ཏན། དག་པའི་ཡོན་ཏན་བཤད་པའོ། །
Enumeration Block 18:
ལྔ་པ་འཇུག་པའི་དོན་ལ་གཉིས། མཚན་ཉིད་ཀྱི་རྣམ་གྲངས་མདོར་བསྟན། དེའི་དོན་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་བཞི། ངོ་བོ་གང་གིས་རྟོགས་པ་དང། ཆོས་སྐུ་ལོངས་སྐུ་སྤྲུལ་སྐུའི་ཁྱད་པར་མདོར་བསྟན་པའོ། །
Enumeration Block 19:
གཉིས་པ་དོན་རྒྱས་པར་བཤད་པ་ལ་གསུམ། ཐུན་མོང་གི་དབྱེ་བ། སོ་སོའི་རྣམ་གཞགདེ་དག་གི་དོན་བསྡུ་བའོ། །
Enumeration Block 20:
གཉིས་པ་རྣམ་བཞག་ལ་གསུམ། ངོ་བོ་ཆོས་སྐུ། ལོངས་སྤྱོད་རྫོགས་སྐུ། སྤྲུལ་པ་སྐུའི་རྣམ་བཞག་གོ ། དང་པོ་ལའང་གཉིས། མཚན་ཉིད་དང་ཡོན་ཏན་མདོར་བསྟན། དེ་དག་གི་ངོ་བོ་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 21:
གཉིས་པ་རྒྱས་བཤད་ལ་གཉིས། མཚན་ཉིད་ལྔ་བཤད་པ། ཡོན་ཏན་ལྔ་བཤད་པའོ། །
Enumeration Block 22:
གཉིས་པ་ལོངས་སྐུ་བཤད་པ་ལ་གསུམ། རྣམ་བཞག་རྒྱས་པར་བཤད་པ། ཆོས་ལྔ་བསྡུས་ཏེ་བསྟན་པ། ཁྱད་པར་རྐྱེན་ལས་སྣང་ཚུལ་ལོ། །
Enumeration Block 23:
གསུམ་པ་སྤྲུལ་སྐུའི་རྣམ་བཞག་ལ་གཉིས་མཆོག་གི་སྤྲུལ་སྐུས་མཛད་པ་བཅུ་གཉིས་སྟོན་ཚུལ། དེའི་བྱེད་ལས་གདུལ་བྱ་རིམ་གྱིས་འདྲེན་ཚུལ་ལོ། །
Enumeration Block 24:
གཉིས་པ་ལ་གསུམ། ཕལ་པ་ཐེག་དམན་ལ་འཇུག་ཚུལ། ཐེག་དམན་ཐེག་ཆེན་གྱིས་སྨིན་ཚུལ། ཐེག་ཆེན་རྣམ་གྲོལ་ལ་སྦྱོར་ཚུལ་ལོ། །
Enumeration Block 25:
གསུམ་པ་དོན་བསྡུ་བ་ལ་གཉིས། རྒྱུ་མཚན་དང་སྦྱར་ཏེ་གསུམ་དུ་བསྡུ་བ། གནས་ཚུལ་དང་སྦྱར་ཏེ་གཉིས་སུ་བསྡུ་བའོ། །
Enumeration Block 26:
དྲུག་པ་རྟག་པའི་དོན་བཤད་པ་ལ་གསུམ། རྒྱུ་མཚན་མདོར་བསྟན། དེ་དོན་རྒྱས་པར་བཤད། སྤྱིའི་དོན་བསྡུ་བའོ། །

Enumeration Block 1:
གཉིས་པ་རྣམ་བཞག་ལ་གསུམ། ངོ་བོ་ཆོས་སྐུ། ལོངས་སྤྱོད་རྫོགས་སྐུ། སྤྲུལ་པ་སྐུའི་རྣམ་བཞག་གོ ། དང་པོ་ལའང་གཉིས། མཚན་ཉིད་དང་ཡོན་ཏན་མདོར་བསྟན། དེ་དག་གི་ངོ་བོ་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 2:
གཉིས་པ་རྒྱས་བཤད་ལ་གཉིས། མཚན་ཉིད་ལྔ་བཤད་པ། ཡོན་ཏན་ལྔ་བཤད་པའོ། །
Enumeration Block 3:
གཉིས་པ་ལོངས་སྐུ་བཤད་པ་ལ་གསུམ། རྣམ་བཞག་རྒྱས་པར་བཤད་པ། ཆོས་ལྔ་བསྡུས་ཏེ་བསྟན་པ། ཁྱད་པར་རྐྱེན་ལས་སྣང་ཚུལ་ལོ། །
Enumeration Block 4:
གསུམ་པ་སྤྲུལ་སྐུའི་རྣམ་བཞག་ལ་གཉིས་མཆོག་གི་སྤྲུལ་སྐུས་མཛད་པ་བཅུ་གཉིས་སྟོན་ཚུལ། དེའི་བྱེད་ལས་གདུལ་བྱ་རིམ་གྱིས་འདྲེན་ཚུལ་ལོ། །
Enumeration Block 5:
གཉིས་པ་ལ་གསུམ། ཕལ་པ་ཐེག་དམན་ལ་འཇུག་ཚུལ། ཐེག་དམན་ཐེག་ཆེན་གྱིས་སྨིན་ཚུལ། ཐེག་ཆེན་རྣམ་གྲོལ་ལ་སྦྱོར་ཚུལ་ལོ། །
Enumeration Block 6:
གསུམ་པ་དོན་བསྡུ་བ་ལ་གཉིས། རྒྱུ་མཚན་དང་སྦྱར་ཏེ་གསུམ་དུ་བསྡུ་བ། གནས་ཚུལ་དང་སྦྱར་ཏེ་གཉིས་སུ་བསྡུ་བའོ། །
Enumeration Block 7:
དྲུག་པ་རྟག་པའི་དོན་བཤད་པ་ལ་གསུམ། རྒྱུ་མཚན་མདོར་བསྟན། དེ་དོན་རྒྱས་པར་བཤད། སྤྱིའི་དོན་བསྡུ་བའོ། །
Enumeration Block 8:
གཉིས་པ་རྒྱས་བཤད་ལ་གཉིས། གཟུགས་སྐུ་རྟག་པའི་རྒྱུ་བདུན། ཆོས་སྐུ་རྟག་པའི་རྒྱུ་གསུམ་བཤད་པའོ། །
Enumeration Block 9:
བདུན་པ་བསམ་མི་ཁྱབ་པའི་དོན་བཤད་པ་ལ་གཉིས། བསམ་མི་ཁྱབ་ཚུལ་མདོར་བསྟན་པ། དེའི་རྒྱུ་མཚན་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 10:
གཉིས་པ་རྒྱས་བཤད་ལ་གསུམ། གཏན་ཚིག་བརྒྱད་རིམ་པར་བཤད། རྒྱུ་དྲུག་གི་དོན་བསྡུ། དེ་རྟོགས་པར་དཀའ་བའི་ཚུལ་བཤད་པའོ། །
Enumeration Block 11:
སྤྱི་དོན་གསུམ་པ་དེའི་ཡན་ལག་ཡོན་ཏན་བཤད་པ་ལ་གཉིས། སྐུ་གཉིས་དང་སྦྱར་ཏེ་གྲངས་ཀྱི་དབྱེ་བ་མདོར་བསྟན། ཕྱེ་བའི་ཡོན་ཏན་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལའང་གཉིས། སྐུ་དང་ཡེ་ཤེས་ཕྱེ་སྟེ་བསྟན། དེ་དག་སོ་སོར་སྦྱར་བའོ། །
Enumeration Block 12:

Enumeration Block 18:

Enumeration Block 19:
གཉིས་པ་ལ་གཉིས། བྲལ་འབྲས་དང༌། སྨིན་འབྲས་བཤད་པའོ། །དེའི་དང་པོ་ལའང་བཞི། སྟོབས། མི་འཇིགས། མ་འདྲེས་པ་རྣམས་ཕྱེ་སྟེ་དཔེ་ཡིས་མཚོན་ཚུལ། བསྡུས་ཏེ་དབྱེ་བ་མེད་ཚུལ་ལོ། །དང་པོ་སྟོབས་ལའང་གཉིས། སོ་སོར་དང། ཐུན་མོང་གི་མཚོན་ཚུལ་ལོ། །
Enumeration Block 20:
གཉིས་པ་མི་འཇིགས་པའི་མཚོན་ཚུལ་ལ་གཉིས། མདོར་བསྟན། རྒྱས་བཤད་དོ། །
Enumeration Block 21:
གཉིས་པ་སྨིན་འབྲས་བཤད་པ་ལ་གཉིས། མཚན་རྣམས་སྐུ་གཉིས་ལ་གནས་ཚུལ། གཟུགས་སྐུ་ཟླ་བའི་དཔེས་མཚོན་ཚུལ་ལོ། །
Enumeration Block 22:
སྤྱི་དོན་བཞི་པ་བྱེད་པ་ཕྲིན་ལས་བཤད་པ་ལ་གསུམ། མདོར་བསྟན་པ། རྒྱས་པར་བཤད་པ། དཔེ་དང་སྦྱར་ཏེ་ཤིན་ཏུ་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གཉིས། ལྷུན་གྲུབ་ཀྱིས་མདོར་བསྟན། རྒྱུན་མི་འཆད་པའི་མདོར་བསྟན་ནོ། །
Enumeration Block 23:
གཉིས་པ་རྒྱས་བཤད་ལ་གཉིས། ལྷུན་གྲུབ་ཀྱི་དོན་བསྡུས་ཏེ་བསྟན། རྒྱུན་མི་འཆད་པའི་དོན་ཕྱེ་སྟེ་བཤད་པའོ། །དང་པོ་ལ་གཉིས། རྣམ་པར་མི་རྟོག་པ་དང། ཡུལ་དུས་མི་འགལ་བར་འཇུག་པའོ། །
Enumeration Block 24:
རྩ་བའི་གསུམ་པ་དཔེ་དང་སྦྱར་ཏེ་ཤིན་ཏུ་རྒྱས་པར་བཤད་པ་ལ་གཉིས། དཔེའི་དབྱེ་བ་མདོར་བསྟན་པ། དཔེ་དོན་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 25:
གཉིས་པ་རྒྱས་བཤད་ལ་གསུམ། སོ་སོའི་ངོ་བོ་དཔེ་དོན་སྦྱར། དགོས་པ་བརྗོད་དེ་སྐབས་དོན་བསྡུ། སླར་ཡང་བསྡུས་ཏེ་ཁྱད་པར་བཤད་པའོ། །དང་པོ་ལ་དགུསྐུ་རྣམ་འཕྲུལ་སྟོན་པ། གསུང་གདམས་ངག་བརྗོད་པ། ཐུགས་མཁྱེན་བརྩེས་ཁྱབ་ཚུལ། སྤྲུལ་པ་སྤྲོ་བ། ཡེ་ཤེས་འཇུག་ཚུལ། ཐུགས་ཀྱི་གསང་བ། གསུང་གི་གསང་བ། སྐུའི་གསང་བ། ཐུགས་རྗེ་འཇུག་ཚུལ་བཅས་ཀྱི་དཔེ་དོན་སྦྱར་བའོ། །དེའི་དང་པོ་ལ་ལྔ། དཔེ་བསྟན་པ། དོན་བཤད་པ། དཔེ་རྒྱས་བཤད། དོན་ངོས་གཟུང་བ། བསྡུས་ཏེ་སྐྱེ་འགག་མེད་ཚུལ་བསྟན་པའོ། །དང་པོ་ལའང་གསུམ། སྣང་ཚུལ། བྱེད་ལས། དོན་དུ་གྱུར་པའོ། །
Enumeration Block 26:
གཉིས་པ་དོན་བཤད་པ་ལ་གསུམ། སྣང་ཚུལ། དོན་གཉེར། མི་རྟོག་ཀྱང་དོན་བྱེད་པའོ། །
Enumeration Block 27:
གཉིས་པ་གསུང་གདམས་ངག་བརྗོད་པའི་དཔེ་སྦྱར་བ་ལ་དྲུགདཔེ་འགོད་པ། དོན་བསྟན་པ། དཔེ་དོན་གྱི་བྱེད་ལས། ཁྱད་པར་བརྗོད་པ། ཆོ་འཕྲུལ་གསུམ་དང་སྦྱར་བཤད། གསུང་གི་ནུས་པ་མི་འཇུག་པ་མི་འགལ་བའོ། །
Enumeration Block 28:
གསུམ་པ་ལ་གཉིས། རྒྱས་བཤད། དོན་བསྡུའོ། །

Enumeration Block 1:
གཉིས་པ་རྒྱས་བཤད་ལ་གསུམ། སོ་སོའི་ངོ་བོ་དཔེ་དོན་སྦྱར། དགོས་པ་བརྗོད་དེ་སྐབས་དོན་བསྡུ། སླར་ཡང་བསྡུས་ཏེ་ཁྱད་པར་བཤད་པའོ། །དང་པོ་ལ་དགུསྐུ་རྣམ་འཕྲུལ་སྟོན་པ། གསུང་གདམས་ངག་བརྗོད་པ། ཐུགས་མཁྱེན་བརྩེས་ཁྱབ་ཚུལ། སྤྲུལ་པ་སྤྲོ་བ། ཡེ་ཤེས་འཇུག་ཚུལ། ཐུགས་ཀྱི་གསང་བ། གསུང་གི་གསང་བ། སྐུའི་གསང་བ། ཐུགས་རྗེ་འཇུག་ཚུལ་བཅས་ཀྱི་དཔེ་དོན་སྦྱར་བའོ། །དེའི་དང་པོ་ལ་ལྔ། དཔེ་བསྟན་པ། དོན་བཤད་པ། དཔེ་རྒྱས་བཤད། དོན་ངོས་གཟུང་བ། བསྡུས་ཏེ་སྐྱེ་འགག་མེད་ཚུལ་བསྟན་པའོ། །དང་པོ་ལའང་གསུམ། སྣང་ཚུལ། བྱེད་ལས། དོན་དུ་གྱུར་པའོ། །
Enumeration Block 2:
གཉིས་པ་དོན་བཤད་པ་ལ་གསུམ། སྣང་ཚུལ། དོན་གཉེར། མི་རྟོག་ཀྱང་དོན་བྱེད་པའོ། །
Enumeration Block 3:
གཉིས་པ་གསུང་གདམས་ངག་བརྗོད་པའི་དཔེ་སྦྱར་བ་ལ་དྲུགདཔེ་འགོད་པ། དོན་བསྟན་པ། དཔེ་དོན་གྱི་བྱེད་ལས། ཁྱད་པར་བརྗོད་པ། ཆོ་འཕྲུལ་གསུམ་དང་སྦྱར་བཤད། གསུང་གི་ནུས་པ་མི་འཇུག་པ་མི་འགལ་བའོ། །
Enumeration Block 4:
གསུམ་པ་ལ་གཉིས། རྒྱས་བཤད། དོན་བསྡུའོ། །
Enumeration Block 5:
འདིར་ཤློ་ཀ་བཞིས་ཉི་ཚེ་བ་ཡིན་མིན། ཕན་མི་ཕན། བདེ་མི་བདེ། ངེས་པར་འབྱིན་མི་འབྱིན་རྒྱས་པར་བཤད་པའོ།
Enumeration Block 6:
གསུམ་པ་ཐུགས་མཁྱེན་བརྩེས་ཁྱབ་ཚུལ་དཔེ་སྦྱར་ལ་ལྔ། སྤྲིན་གྱི་དཔེ་དོན་མདོར་བསྟན། དེ་ཉིད་རྒྱས་པར་བཤད་པ། སྣོད་ཀྱི་འགྱུར་ཚུལ། འབད་མེད་དུ་འཇུག་པ། སྡུག་བསྔལ་སེལ་བའི་ཆོས་མཐུན་སྦྱར་བའོ། །
Enumeration Block 7:
གཉིས་པ་ལ་གཉིས། དཔེ་དོན་བསྟན་པ་དང། ཆོས་མཚུངས་ཀྱི་སྒོ་ནས་དོན་བཤད་པའོ། །
Enumeration Block 8:
བཞི་པ་འབད་མེད་དུ་འཇུག་པ་ལ་གཉིས། མདོར་བསྟན། རྒྱས་བཤད་དོ།
Enumeration Block 9:
གཉིས་པ་ལ་གཉིས། དཔེ་དོན་ཆོས་མཚུངས་སུ་སྦྱར་བ་དང། ལྟོས་པ་མེད་པའི་ཚུལ་ལོ། །
Enumeration Block 10:
ལྔ་པ་ལ་གསུམ། སྡུག་བསྔལ་སེལ་བ་དངོས། འགྱུར་བར་རྟོགས་པ། བདེན་བཞིའི་ཚུལ་མཐོང་བའོ།
Enumeration Block 11:
བཞི་པ་སྤྲུལ་པ་སྤྲོ་པའི་དཔེ་སྦྱར་ལ་བཞི། དཔེ་དོན་མདོར་བསྟན་པ། དེ་བཤད་པ། མཐོང་བའི་རྒྱུ་བསྟན་པ། སྤྲུལ་སྐུའི་མཛད་པ་བཅུ་གཉིས་བཤད་པའོ། །
Enumeration Block 12:
ལྔ་པ་ཡེ་ཤེས་འཇུག་ཚུལ་གྱི་དཔེ་སྦྱར་ལ་དྲུག ། ཡེ་ཤེས་འཇུག་མི་འཇུག་བསྟན་པ། དེ་འཇུག་པའི་བྱ་བ་བཤད་པ། ཡེ་ཤེས་སྤྲོ་བའི་ཚུལ། དུ་མར་འཇུག་ཚུལ། ཡེ་ཤེས་འཇུག་པའི་རིམ་པ། བྱེད་ལས་ཁྱད་པར་དུ་འཕགས་པའོ། །
Enumeration Block 13:
ལྔ་པ་ལ་གཉིས། མདོར་བསྟན། རྒྱས་བཤད། །
Enumeration Block 14:
དྲུག་པ་ལ་གཉིས། །དཔེ་ལས་འདས་པར་བསྟན་པ་དང། བྱེད་ལས་ཀྱི་ཁྱད་པར་དངོས། །
Enumeration Block 15:
དྲུག་པ་ཐུགས་ཀྱི་གསང་བའི་དཔེ་སྦྱར་བ་ལ་གསུམ། རྟོག་མེད་འདོད་རྒུ་སྒྲུབ་ཚུལ། འབད་མེད་རྟག་ཏུ་བཞུགས་ཚུལ། རྙེད་པར་དཀའ་བས་མཚུངས་པར་བསྟན་པའོ།
Enumeration Block 16:
གཉིས་པ་དགོས་པ་བརྗོད་དེ་སྐབས་དོན་བསྡུ་བ་ལ་གཉིས། དགོས་པ་དང་དཔེ་དོན་གྱི་དབྱེ་བ་དང། དཔེས་མཚོན་ཚུལ་ཁྱད་པར་དུ་བཤད་པའོ། །དང་པོ་ལ་བཞི། དགོས་པ་དང་ཉིང་དགོས་འགྲུབ་ཚུལ། དཔེ་དོན་བསྡུས་ཏེ་བསྟན་པ། དཔེ་གསུམ་དུ་སྦྱར་བ། སྐབས་ཀྱི་དོན་ལ་འབད་རྩོལ་མེད་ཚུལ་ལོ། །
Enumeration Block 17:
གཉིས་པ་དཔེས་མཚོན་ཚུལ་ཁྱད་པར་དུ་བཤད་པ་ལ་གཉིས་དཔེའི་དབྱེ་བ། དེ་དོན་དང་སྦྱར་ཏེ་བཤད་པའོ། །
Enumeration Block 18:
གསུམ་པ་སླར་ཡང་བསྡུས་ཏེ་ཁྱད་པར་དུ་བསྟན་པ་ལ་གཉིས། སྣང་ཡང་སྐྱེ་འཇིགས་མེད་ཚུལ། ཆོས་མཚུངས་ལས་ཁྱད་པར་འཕགས་པའི་ཚུལ་ལོ། །དང་པོ་ལ་གཉིས། དབང་པོའི་དཔེ་དང། རྒྱུན་མི་འཆད་པས་སྐྱེ་འཇིག་མེད་ཚུལ་ལོ། །
Enumeration Block 19:
གཉིས་པ་ཆོས་མཚུངས་ལས་ཁྱད་པར་འཕགས་ཚུལ་ལ་གཉིས། མདོར་བསྟན། རྒྱས་བཤད་དོ། །
Enumeration Block 20:
གསུམ་པ་བསྟན་བཅོས་ཡོངས་སུ་རྫོགས་པའི་བྱ་བ་ལ་གསུམ། ཕན་ཡོན་དང། ཇི་ལྟར་མཛད་པ་དང། བསྔོ་བ་དོན་བསྡུ་དང་བཅས་པའོ། །དང་པོ་ལ་ལྔ། བསམ་མི་ཁྱབ་ཀྱི་དོན་བརྗོད་པ། ཡོན་ཏན་མདོར་བསྟན་པ། སྦྱིན་སོགས་གསུམ་ལས་ཁྱད་པར་བཤད་པ། དེའི་རྒྱུ་མཚན་བརྗོད་པ། ཕན་ཡོན་ཤིན་ཏུ་རྒྱས་བཤད་དོ། །
Enumeration Block 21:
གསུམ་པ་ཁྱད་པར་བཤད་པ་ལ་གསུམ། སྦྱིན་པ། ཚུལ་ཁྲིམས། བསམ་གཏན་ལས་ཁྱད་པར་བཤད་པའོ།
Enumeration Block 22:
ལྔ་པ་ཕན་ཡོན་ཤིན་ཏུ་རྒྱས་བཤད་ལ་ལྔ། བྱང་ཆུབ་ཐོབ་པ་དང། བྱང་ཆུབ་ཀྱི་སེམས་བརྟན་པ། ཡོངས་སུ་རྫོགས་པའི་ཐོབ་པ། ཞར་ལ་ཚོགས་ཀྱི་ངེས་པ་བསྟན་པ། སྒྲིབ་པ་སྤོང་བའོ། །

Enumeration Block 1:
གསུམ་པ་བསྟན་བཅོས་ཡོངས་སུ་རྫོགས་པའི་བྱ་བ་ལ་གསུམ། ཕན་ཡོན་དང། ཇི་ལྟར་མཛད་པ་དང། བསྔོ་བ་དོན་བསྡུ་དང་བཅས་པའོ། དང་པོ་ལ་ལྔ། བསམ་མི་ཁྱབ་ཀྱི་དོན་བརྗོད་པ། ཡོན་ཏན་མདོར་བསྟན་པ། སྦྱིན་སོགས་གསུམ་ལས་ཁྱད་པར་བཤད་པ། དེའི་རྒྱུ་མཚན་བརྗོད་པ། ཕན་ཡོན་ཤིན་ཏུ་རྒྱས་བཤད་དོ། །
Enumeration Block 2:
གསུམ་པ་ཁྱད་པར་བཤད་པ་ལ་གསུམ། སྦྱིན་པ། ཚུལ་ཁྲིམས། བསམ་གཏན་ལས་ཁྱད་པར་བཤད་པའོ།
Enumeration Block 3:
ལྔ་པ་ཕན་ཡོན་ཤིན་ཏུ་རྒྱས་བཤད་ལ་ལྔ། བྱང་ཆུབ་ཐོབ་པ་དང། བྱང་ཆུབ་ཀྱི་སེམས་བརྟན་པ། ཡོངས་སུ་རྫོགས་པའི་ཐོབ་པ། ཞར་ལ་ཚོགས་ཀྱི་ངེས་པ་བསྟན་པ། སྒྲིབ་པ་སྤོང་བའོ། །
Enumeration Block 4:
ལྔ་པ་སྒྲིབ་པ་སྤོང་བ་ལ་གཉིས། སྤང་བྱ་སྒྲིབ་པ་ངོས་བཟུང་བ་དང། གཉེན་པོ་ཡེ་ཤེས་མཆོག་ཏུ་བསྟན་པའོ།
Enumeration Block 5:
གཉིས་པ་བསྟན་བཅོས་ཇི་ལྟར་མཛད་པ་ལ་དྲུག ། ཇི་ལྟར་མཛད་པའི་ཚུལ། གང་ལ་བརྟེན་ནས་མཛད་པ། རྒྱལ་བའི་བཀའ་ངོས་བཟུང་བ། དེ་དང་མཐུན་པ་ཐམས་ཅད་བླང་བྱར་བསྟན་པ། རྒྱལ་བའི་བཀའ་དང་མ་འགལ་བར་བསྟན་པ། འགལ་བའི་ཉེས་པ་བསྟན་པའོ། །
Enumeration Block 6:
དྲུག་པ་ལ་གསུམ། ཆོས་སྤོང་ངོས་བཟུང་བ། ཟབ་མོའི་ཆོས་མི་སྤོང་བའི་ངེས་པ། ཆོས་སྤོང་མཚམས་མེད་ལས་ལྕི་བར་བསྟན་པའོ། །
Enumeration Block 7:
དང་པོ་ལ་གཉིས། བརྒྱུད་པའི་རྒྱུ་སྤང་བར་གདམས་པ་དང། རྒྱུ་བཅུ་དང་བཅས་པའི་ཆོས་སྤོང་བ་དངོས་སོ། །
Enumeration Block 8:
གསུམ་པ་བསྔོ་བ་དོན་བསྡུ་དང་བཅས་པ་ལ་གསུམ། བསྔོ་བ་སྨོན་ལམ་དང་བཅས་པ་ཕན་ཡོན་གྱི་དོན་བསྡུ་བསྟན་པ། རྫོགས་པའི་ཚུལ་ལོ། །
Enumeration Block 9:
ཐེག་པ་ཆེན་པོ་རྒྱུད་བླ་མའི་བསྟན་བཅོས་འདི་ལ་དོན་གཉིས། མཚན་དང༌། གཞུང་གི་དོན་ནོ། །
Enumeration Block 10:

མི་སློབ་པ་འཇུག་ཚུལ་གཉིས་ལས།

Enumeration Block 1:
རྟག་པའི་དོན་ལ་གསུམ་སྟེ། བསྟན། བཤད། བསྡུ་བའོ། །
Enumeration Block 2:
གཉིས་པ་ལ་གཉིས་ཏེ། གཟུགས་སྐུ་དང༌། ཆོས་སྐུ་རྟག་པའི་རྒྱུའོ། །
Enumeration Block 3:
བསམ་གྱིས་མི་ཁྱབ་པའི་དོན་ལ་གསུམ་སྟེ། བསྟན། བཤད། བསྡུ་བའོ། །
Enumeration Block 4:
སངས་རྒྱས་ཀྱི་ཡོན་ཏན་ལ་བཞི་སྟེ། བཤད་བྱ་དགོད་པ། དེ་བཤད་པ། དེ་དག་མདོ་གང་ལ་བརྟེན་ནས་ཤེས་པའི་ཚུལ། མདོར་བསྡུས་ཏེ་ཆོས་མཐུན་ཁྱད་པར་དུ་བཤད་པའོ། །དང་པོ་ལ་བསྟན། བཤད་གཉིས་ལས།
Enumeration Block 5:
སངས་རྒྱས་ཀྱི་སྐུ་ལ་གཉིས་ཏེ། རང་དོན་དོན་དམ་པ་ཆོས་ཀྱི་སྐུ་དང་དེ་ལ་བརྟེན་པའི་གཞན་དོན་ཀུན་རྫོབ་པ་ཆོས་ཀྱི་སྐུ་ཉིད་དོ། །
Enumeration Block 6:
གཉིས་པ་ལ་གཉིས་ལས།
Enumeration Block 7:
རྒྱས་པར་བཤད་པ་ལ་གཉིས་ཏེ། བྲལ་བ་དང༌། རྣམ་སྨིན་གྱི་ཡོན་ཏན་བཤད་པའོ། །དང་པོ་ལ་གསུམ་སྟེ། སྟོབས་དང་མི་འཇིགས་པ་དང༌། སངས་རྒྱས་ཀྱི་ཆོས་མ་འདྲེས་པའོ། །དང་པོ་ལ་གཉིས་ཏེ། ངོ་བོ་དང༌། རྡོ་རྗེ་དང་ཆོས་མཐུན་པར་བསྟན་པའོ། །
Enumeration Block 8:
མི་འཇིགས་པ་ལ་གསུམ་སྟེ། སོ་སོའི་ངོ་བོ་དང༌། རྒྱུ་བྱེད་པ་དང༌། དཔེ་དང་སྦྱར་བའོ། །
Enumeration Block 9:
མ་འདྲེས་པ་ལ་གསུམ་སྟེ། ངོ་བོ་དང༌། དེ་སངས་རྒྱས་ཁོ་ན་ལ་ཡོད་པ། དཔེ་དང་སྦྱར་བའོ། །
Enumeration Block 10:
དང་པོ་ལ་བཞི་ལས།
Enumeration Block 11:
གཉིས་པ་རྣམ་སྨིན་གྱི་ཡོན་ཏན་ལ་གཉིས་ཏེ། ངོ་བོ་དང༌། དཔེ་དང་སྦྱར་བའོ། །
Enumeration Block 12:
བཞི་པ་ལ་གཉིས་ཏེ། བསྟན་པ་དང༌། བཤད་པའོ། །
Enumeration Block 13:
གཉིས་པ་ལ་གཉིས་ཏེ། བྲལ་བ་དང༌། རྣམ་སྨིན་གྱི་ཡོན་ཏན་གྱི་ཆོས་མཐུན་བཤད་པའོ། །དང་པོ་ལ་གཉིས་ཏེ། སོ་སོར་བཤད། དོན་བསྡུ་བའོ། །དང་པོ་ལ་གསུམ་སྟེ། སྟོབས་དང༌། མི་འཇིགས་པ་དང༌། མ་འདྲེས་པའི་ཆོས་མཐུན་ནོ། །
Enumeration Block 14:
གཉིས་པ་ལ། བསྟན། བཤད་གཉིས་ལས།
Enumeration Block 15:
ཕྲིན་ལས་ལ་གཉིས་ཏེ། ཕྲིན་ལས་ལྷུན་གྱིས་གྲུབ་ཅིང་རྒྱུན་མི་ཆད་པར་བསྟན་པ་དང༌། དཔེའི་སྒོ་ནས་དེ་ལ་མོས་པ་བསྐྱེད་པའོ། །དང་པོ་ལ་གཉིས་ཏེ། བཤད་བྱ་དགོད་པ་དང༌། དེ་བཤད་པའོ། །དང་པོ་ལ་གཉིས་ཏེ། ལྷུན་གྱིས་གྲུབ་པ་དང༌། རྒྱུན་མི་ཆད་པའོ། །
Enumeration Block 16:
གཉིས་པ་ལ་གཉིས་ཏེ། ལྷུན་གྱིས་གྲུབ་པ་དང༌། རྒྱུན་མི་ཆད་པའོ། །དང་པོ་ལ་གཉིས་ལས།
Enumeration Block 17:
གཉིས་པ་ལ་གསུམ་སྟེ། བསྟན། བཤད། བསྡུ་བའོ། །
Enumeration Block 18:
གཉིས་པ་ལ་གསུམ་སྟེ། དོན་དང༌། དཔེ་དང༌། ཆོས་མཐུན༌སྦྱར་བའོ། །
Enumeration Block 19:
དེ་ལ་མོས་པ་བསྐྱེད་པ་ལ་གསུམ་སྟེ། བསྟན། བཤད། བསྡུ་བའོ། །
Enumeration Block 20:
རྒྱས་པར་བཤད་པ་ལ་མདོར་བསྟན་གྱི་གོ་རིམ་བཞིན་དུ་དགུ་ལས། དང་པོ་སྐུ་བརྒྱ་བྱིན་དང་འདྲ་བ་ལ་གཉིས་ཏེ། རྣམ་རྟོག་མེད་པ་དང་། སྐྱེ་འགག་མེད་པའོ། །དང་པོ་ལ་གཉིས། དཔེ་དང༌། དོན་ནོ། །
Enumeration Block 21:
དང་པོ་ལ་གསུམ་སྟེ། ས་གཞི་དག་པ་ལ་ལྷའི་གཟུགས་བརྙན་མཐོང་བ། དེས་རྐྱེན་བྱས་ནས་ལྷར་སྐྱེ་བ། གཟུགས་བརྙན་ལ་རྟོག་པ་མེད་ཀྱང་གཞན་དོན་དུ་འགྱུར་ཚུལ་ལོ། །
Enumeration Block 22:
དོན་ལ་བཞི་སྟེ། སེམས་དག་པ་ལ་སངས་རྒྱས་ཀྱི་གཟུགས་བརྙན་སྣང་བ་དང༌། དེ་སངས་རྒྱས་ཀྱི་རྒྱུར་འགྱུར་བ་དང༌། སངས་རྒྱས་ཀྱི་གཟུགས་བརྙན་ལ་རྟོག་པ་མེད་ཀྱང་གཞན་དོན་བྱེད་པ་དང༌། གཟུགས་སྐུ་མཐོང་བ་ལ་བརྟེན་ནས་ཆོས་སྐུ་མཐོང་བའི་ཚུལ་ལོ། །
Enumeration Block 23:
གཉིས་པ་སྐྱེ་འགག་མེད་པ་ལ་གཉིས་ཏེ། དཔེ་དང༌། དོན་ནོ། །དང་པོ་ལ་གཉིས་ཏེ། སྐྱེ་འགག་ཏུ་སྣང་བའི་ཚུལ། སྣང་བའི་བྱེད་པ་པོའོ། །
Enumeration Block 24:
དོན་ལ་གསུམ་སྟེ། སྐུ་གཟུགས་སྣང་བའི་བྱེད་པ། རྐྱེན་སྐུ་གཟུགས་སྣང་བའི་ཚུལ། སེམས་ཀྱི་དབང་གིས་སྐྱེ་འགག་དུ་སྣང་བའོ། །
Enumeration Block 25:
གཉིས་པ་གསུང་ལྷའི་རྔ་དང་འདྲ་བ་ལ་གསུམ་སྟེ། ཆོས་ཀྱི་རྔ་དང་མཚུངས་པ། ལྷ་རྫས་ཀྱི་སིལ་སྙན་གཞན་དང་མི་མཚུངས་པ། རྒྱུད་དག་པ་ལ་ལྟོས་པའོ། །དང་པོ་ལ་གཉིས་ཏེ། བག་མེད་པ་ལས་སྐྱོབ་པ་དང༌། འཇིགས་པ་ལས་སྐྱོབ་པའོ། །དང་པོ་ལ་གསུམ་སྟེ། དཔེ་དོན་སོ་སོར་བཤད་པ། སྒྲ་ཐོས་པའི་རྒྱུ། ཐོས་པའི་བྱེད་པའོ། །

Enumeration Block 1:
དེ་ལ་མོས་པ་བསྐྱེད་པ་ལ་གསུམ་སྟེ། བསྟན། བཤད། བསྡུ་བའོ། །
Enumeration Block 2:
རྒྱས་པར་བཤད་པ་ལ་མདོར་བསྟན་གྱི་གོ་རིམ་བཞིན་དུ་དགུ་ལས། དང་པོ་སྐུ་བརྒྱ་བྱིན་དང་འདྲ་བ་ལ་གཉིས་ཏེ། རྣམ་རྟོག་མེད་པ་དང་། སྐྱེ་འགག་མེད་པའོ། །དང་པོ་ལ་གཉིས། དཔེ་དང༌། དོན་ནོ། །དང་པོ་ལ་གསུམ་སྟེ། ས་གཞི་དག་པ་ལ་ལྷའི་གཟུགས་བརྙན་མཐོང་བ། དེས་རྐྱེན་བྱས་ནས་ལྷར་སྐྱེ་བ། གཟུགས་བརྙན་ལ་རྟོག་པ་མེད་ཀྱང་གཞན་དོན་དུ་འགྱུར་ཚུལ་ལོ། །
Enumeration Block 3:
དོན་ལ་བཞི་སྟེ། སེམས་དག་པ་ལ་སངས་རྒྱས་ཀྱི་གཟུགས་བརྙན་སྣང་བ་དང༌། དེ་སངས་རྒྱས་ཀྱི་རྒྱུར་འགྱུར་བ་དང༌། སངས་རྒྱས་ཀྱི་གཟུགས་བརྙན་ལ་རྟོག་པ་མེད་ཀྱང་གཞན་དོན་བྱེད་པ་དང༌། གཟུགས་སྐུ་མཐོང་བ་ལ་བརྟེན་ནས་ཆོས་སྐུ་མཐོང་བའི་ཚུལ་ལོ། །
Enumeration Block 4:
གཉིས་པ་སྐྱེ་འགག་མེད་པ་ལ་གཉིས་ཏེ། དཔེ་དང༌། དོན་ནོ། །དང་པོ་ལ་གཉིས་ཏེ། སྐྱེ་འགག་ཏུ་སྣང་བའི་ཚུལ། སྣང་བའི་བྱེད་པ་པོའོ། །
Enumeration Block 5:
དོན་ལ་གསུམ་སྟེ། སྐུ་གཟུགས་སྣང་བའི་བྱེད་པ། རྐྱེན་སྐུ་གཟུགས་སྣང་བའི་ཚུལ། སེམས་ཀྱི་དབང་གིས་སྐྱེ་འགག་དུ་སྣང་བའོ། །
Enumeration Block 6:

Enumeration Block 15:

Enumeration Block 16:
དྲུག་པ་ཐུགས་ཀྱི་གསང་བ་ཡིད་བཞིན་གྱི་ནོར་བུ་དང་འདྲ་བ་ལ་གཉིས་ཏེ། སྐལ་ལྡན་ལ་འབད་མེད་དུ་དགོས་འདོད་སྩོལ་བ་དང༌། སྐལ་མེད་ཀྱིས་རྙེད་པར་དཀའ་བའོ། །དང་པོ་ལ་གཉིས་ཏེ། ཡུལ་མང་པོའི་བྱ་བ་སྒྲུབ་པ་དང༌། དུས་རྟག་ཏུ་སྒྲུབ་པའོ། །
Enumeration Block 17:
གསུམ་པ་དོན་བསྡུ་བ་ལ་གསུམ་སྟེ། དཔེ་དགུ་བསྟན་པའི་དགོས་པ། དཔེ་དོན་གྱི་ཆོས་མཐུན་བསྟན་པ། དཔེ་ལས་ཁྱད་པར་དུ་འཕགས་པའི་དོན་བསྟན་པའོ། །དང་པོ་ལ་བཞི་སྟེ། ཕྲིན་ལས་འབད་མེད་ལ་མོས་པ་བསྐྱེད་པའི་དོན་དུ་དཔེ་དགུ་བཀོད་པ། དེ་སྟོན་པའི་མདོའི་མཚན་གྱི་དགོས་པ་བསྟན་པ། དཔེ་དགུའི་དོན་བསྡུས་ཏེ་བསྟན་པ། ཕྲིན་ལས་འབད་མེད་རང་བཞིན་གྱི་རྟགས་ཀྱིས་སྒྲུབ་པའོ། །

Enumeration Block 1:
གསུམ་པ་དོན་བསྡུ་བ་ལ་གསུམ་སྟེ། དཔེ་དགུ་བསྟན་པའི་དགོས་པ། དཔེ་དོན་གྱི་ཆོས་མཐུན་བསྟན་པ། དཔེ་ལས་ཁྱད་པར་དུ་འཕགས་པའི་དོན་བསྟན་པའོ། །དང་པོ་ལ་བཞི་སྟེ། ཕྲིན་ལས་འབད་མེད་ལ་མོས་པ་བསྐྱེད་པའི་དོན་དུ་དཔེ་དགུ་བཀོད་པ། དེ་སྟོན་པའི་མདོའི་མཚན་གྱི་དགོས་པ་བསྟན་པ། དཔེ་དགུའི་དོན་བསྡུས་ཏེ་བསྟན་པ། ཕྲིན་ལས་འབད་མེད་རང་བཞིན་གྱི་རྟགས་ཀྱིས་སྒྲུབ་པའོ། །

Enumeration Block 6:
གསུམ་པ་དེ་དག་ལ་མོས་པའི་ཕན་ཡོན་ལ་གཉིས་ཏེ། བཤད་བྱ་དགོད་པ་དང༌། དེ་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གཉིས་ཏེ། མོས་པའི་ཡུལ་དང༌། དེ་ལ་མོས་པའི་བསོད་ནམས་སོ། །
Enumeration Block 7:
གཉིས་པ་ལ་གསུམ་ཏེ། བསྟན་པ་དང༌། བཤད་པ་དང༌། དེའི་འཐད་པའོ། །
Enumeration Block 8:
གཉིས་པ་ལ་གསུམ་སྟེ། སྦྱིན་པ་དང༌། ཚུལ་ཁྲིམས་དང༌། བསྒོམས་པ་ལས་བྱུང་བའི་བསོད་ནམས་ལས་ལྷག་པའོ། །
Enumeration Block 9:
གཉིས་པ་ལ་གཉིས་ཏེ། གནས་བཞི་ལ་མོས་པ་མྱུར་དུ་སངས་རྒྱས་ཐོབ་པའི་རྒྱུར་བསྟན་པ། ཐོས་པ་བསོད་ནམས་ཚོགས་ལས་ཁྱད་པར་དུ་འཕགས་པར་བསྟན་པའོ། །

Enumeration Block 10:
གཉིས་པ་ལ་གཉིས་ཏེ། ཁྱད་པར་དུ་བྱ་བའི་ཡུལ་དང་། ཁྱད་པར་དུ་འཕགས་པའི་རྒྱུ་མཚན་ནོ། །
དང་པོ་ལ་གཉིས་ཏེ། བསོད་ནམས་མཐར་ཕྱིན་པའི་རྒྱུ་ཐོས་པར༌བསྟན༌པ་དང༌། བསོད་ནམས་ཀྱི་ཚོགས་ཀྱི་རིགས་བསྡུ་བའོ། །
Enumeration Block 11:
མཐར་ཕྱིན་པའི་དོན་ལ་གཉིས་ཏེ། དངོས་དང༌། དོན་བསྡུ་བའོ། །དང་པོ་ལ་གསུམ་སྟེ། གསུང་རབ་ཇི་ལྟར་བཤད་པའི་ཚུལ། ཆོས་སྤོང་གི་ལས་སྤང་བ། གསུང་རབ་བཤད་པའི་བསོད་ནམས་བསྔོ་བའོ། །
དང་པོ་ལ་བཞི་སྟེ། རྒྱུ་དང་དགོས་ཆེད་བསྟན་པ་དང༌། ཚུལ་ཇི་ལྟར་བཤད་པ་དང༌། བཤད་བྱ་བཀའི་མཚན་ཉིད་དང་། དེ་དང་རྗེས་སུ་མཐུན་པའི་བསྟན་བཅོས་ཀྱང་བླང་བྱར་བསྟན་པའོ། །
Enumeration Block 12:
